1. 函数的概念与基本性质 对应关系 + 定义域

定义（函数）：设 D ⊆ ℝ 非空，若对每个 x ∈ D 按对应法则 f 都有唯一确定的 y 与之对应，称 f 为定义在 D 上的函数，记 y = f(x)，x 为自变量、y 为因变量。D 为定义域，值域 R = {f(x) : x ∈ D}。函数 = 定义域 + 对应法则 + 值域。
定理（函数的基本性质）：① 奇偶性：f(−x) = ±f(x)，奇函数图像关于原点对称、偶函数关于 y 轴对称；② 周期性：存在 T > 0 使 f(x+T) = f(x)；③ 单调性：x₁ < x₂ ⟹ f(x₁) ≤ f(x₂)（增）；④ 有界性：|f(x)| ≤ M。
例：sin x 是奇函数、周期 2π、有界；cos x 是偶函数；tan x 是奇函数、周期 π、无界。
定义（复合函数与反函数）：复合 (g∘f)(x) = g(f(x))（要求 f 的值域 ⊆ g 的定义域）。反函数 f⁻¹：若 f 单射，y = f(x) ⟺ x = f⁻¹(y)；单调函数必有反函数，且 f⁻¹ 与原函数单调性相同、图像关于 y = x 对称。
例：求 y = ln(x + √(x²+1)) 的反函数。
查看答案
答案：y = ln(x+√(x²+1)) ⟺ eʸ = x + √(x²+1)。利用 e⁻ʸ = 1/(x+√(x²+1)) = √(x²+1) − x，两式相减得 2x = eʸ − e⁻ʸ，故反函数 y = (eˣ − e⁻ˣ)/2 = sinh x（双曲正弦）。
易错警示：函数的定义域必须首先确定。√x、ln x、1/x 等限制常被忽略；复合函数的定义域是「内层值域 ∩ 外层定义域」再反解。

1.1 定义域的求法（深入）

定义（自然定义域）：使表达式有意义的一切实数构成的集合。常见限制： $$\sqrt[2n]{f(x)} \Rightarrow f(x)\ge 0;\quad \frac{1}{f(x)}\Rightarrow f(x)\neq 0;\quad \log_a f(x)\Rightarrow f(x)>0;\quad \tan f(x)\Rightarrow f(x)\neq \frac{\pi}{2}+k\pi$$
例 1：求 $y=\dfrac{1}{\sqrt{x-1}}+\ln(4-x^2)$ 的定义域。
查看解答
解：三个限制同时成立： $$x-1>0 \Rightarrow x>1;\qquad 4-x^2>0 \Rightarrow -2<x<2.$$ 取交集：$(1,2)$。
例 2：设 $f(x)$ 定义域为 $[0,1]$，求 $f(\ln x)$ 的定义域。
查看解答
解：内层 $\ln x$ 必须落在 $f$ 的定义域 $[0,1]$ 内：$0\le \ln x\le 1$，解得 $1\le x\le e$。

1.2 奇偶性、单调性的严格判定

定理（奇偶性判定）：先验定义域是否关于原点对称；不对称则既非奇也非偶。对称时计算 $f(-x)$： $$f(-x)=f(x)\ \text{偶};\qquad f(-x)=-f(x)\ \text{奇}.$$
关键步骤：① 定义域对称是前提（如 $y=\ln x$ 定义域 $(0,\infty)$ 不对称，谈不上奇偶）；② 计算 $f(-x)$ 后用恒等变形（因式分解、对数性质）凑出 $\pm f(x)$。
例 3：判断 $f(x)=\ln(x+\sqrt{1+x^2})$ 的奇偶性。
查看解答
解：定义域为 ℝ，关于原点对称。 $$f(-x)=\ln\!\left(-x+\sqrt{1+x^2}\right)=\ln\frac{1}{x+\sqrt{1+x^2}}=-\ln(x+\sqrt{1+x^2})=-f(x).$$ 故为奇函数。
例 4：证明 $f(x)=x^3+\sin x$ 在 $(-\infty,+\infty)$ 上严格递增。
查看解答
解：任取 $x_1<x_2$，$x_1^3<x_2^3$；又 $\sin x$ 严格递增区间需另证，但这里用 $f'(x)=3x^2+\cos x\ge 3x^2-1$ 在 $|x|\ge 1$ 恒正，小区间逐点验证亦可。基础方法：$x_2^3-x_1^3=(x_2-x_1)(x_2^2+x_1x_2+x_1^2)>0$（因括号内恒正），$\sin x_2-\sin x_1=2\cos\frac{x_1+x_2}{2}\sin\frac{x_2-x_1}{2}$ 符号不定，故严格递增需借助导数（见第二讲）。此处仅作单调性定义的训练。

1.3 反函数存在性与求法

定理（反函数存在定理）：若 $f$ 在区间 $I$ 上严格单调，则 $f$ 是从 $I$ 到 $f(I)$ 的一一对应，反函数 $f^{-1}$ 存在且与 $f$ 同单调性。
例 5：求 $y=\dfrac{e^x-e^{-x}}{2}$ 的反函数。
查看解答
解：$y=\sinh x$。令 $t=e^x>0$，$2y=t-\dfrac{1}{t}$，即 $t^2-2yt-1=0$，$t=y+\sqrt{y^2+1}$（取正根），故 $x=\ln(y+\sqrt{y^2+1})$。反函数 $y=\ln(x+\sqrt{x^2+1})$。

1.4 本节习题

习 1：求 $y=\arcsin\dfrac{x-1}{2}+\sqrt{4-x^2}$ 的定义域。
查看答案
答：$\left|\frac{x-1}{2}\right|\le 1\Rightarrow -1\le x\le 3$；$4-x^2\ge 0\Rightarrow -2\le x\le 2$。交集 $[-1,2]$。
习 2：判断 $f(x)=\dfrac{e^x-1}{e^x+1}$ 的奇偶性。
查看答案
答：$f(-x)=\frac{e^{-x}-1}{e^{-x}+1}=\frac{1-e^x}{1+e^x}=-f(x)$，奇函数。
习 3：设 $f(x)$ 定义域为 $[0,1]$，求 $f(2x-1)$ 的定义域。
查看答案
答：$0\le 2x-1\le 1\Rightarrow \frac{1}{2}\le x\le 1$。
习 4：求 $y=\sqrt[3]{x+1}$ 的反函数。
查看答案
答：$x=y^3-1$，反函数 $y=x^3-1$。

2.2 双曲函数与工程常用函数

定义（双曲函数）： $$\sinh x=\frac{e^x-e^{-x}}{2},\quad \cosh x=\frac{e^x+e^{-x}}{2},\quad \tanh x=\frac{\sinh x}{\cosh x}.$$ 恒等式：$\cosh^2 x-\sinh^2 x=1$，$(\sinh x)'=\cosh x$，$(\cosh x)'=\sinh x$。
双曲函数：cosh x 为悬链线（最低点 (0,1)）；tanh x 以 y = ±1 为水平渐近线

2.3 本节例题与习题

例 1：化简 $\arcsin(\sin\frac{3\pi}{4})$。
查看解答
解：$\frac{3\pi}{4}$ 不在主值区间 $[-\pi/2,\pi/2]$ 内。$\sin\frac{3\pi}{4}=\frac{\sqrt{2}}{2}=\sin\frac{\pi}{4}$，故 $\arcsin(\sin\frac{3\pi}{4})=\frac{\pi}{4}$。
例 2：求 $\lim_{x\to+\infty}\arctan x$ 与 $\lim_{x\to-\infty}\arctan x$。
查看解答
解：$\arctan x\to \frac{\pi}{2}$（$x\to+\infty$），$\arctan x\to -\frac{\pi}{2}$（$x\to-\infty$）。这是 $x\to\infty$ 时左右极限不等的典型。
习 1：计算 $\arccos(-\frac{1}{2})$。
查看答案
答：$\frac{2\pi}{3}$。
习 2：证明 $\sinh x$ 是奇函数，$\cosh x$ 是偶函数。
查看答案
答：$\sinh(-x)=\frac{e^{-x}-e^x}{2}=-\sinh x$；$\cosh(-x)=\frac{e^{-x}+e^x}{2}=\cosh x$。

3. 数列极限 精确的「无限逼近」

定义（数列极限 ε-N）：lim aₙ = A ⟺ 对任意 ε > 0，存在正整数 N，使 n > N 时 |aₙ − A| < ε。数列收敛的极限唯一。
定理（收敛数列的性质）：① 有界性：收敛数列必有界；② 保号性：极限 > 0 则足够项后 aₙ > 0；③ 夹逼定理：aₙ ≤ bₙ ≤ cₙ 且 aₙ→A、cₙ→A，则 bₙ→A；④ 四则运算：lim(aₙ±bₙ) = lim aₙ ± lim bₙ（分母极限非零时成立）。
证明要点（夹逼）：对 ε，N₁ 使 |aₙ−A|<ε、N₂ 使 |cₙ−A|<ε，取 N = max(N₁,N₂)，则 A−ε < aₙ ≤ bₙ ≤ cₙ < A+ε。
定理（单调有界定理）：单调递增且有上界的数列必收敛。
证明要点：用实数的完备性：上确界 sup{aₙ} = A 存在，且 A−ε 不是上界，故某项 > A−ε，之后各项在 (A−ε, A] 内。
例：证明 aₙ = (1+1/n)ⁿ 收敛。
查看答案
答案：先证单调：$\dfrac{a_{n+1}}{a_n}=\left[\dfrac{1+1/(n+1)}{1+1/n}\right]^n\cdot\dfrac{n+2}{n+1}\gt 1$（伯努利不等式）；再证有界：$a_n\lt 3$（二项展开放缩）。由单调有界定理收敛，极限记为 $e\approx 2.71828$。
易错警示：「无穷多个无穷小之和不一定无穷小」（n 项 1/n 求和 = 1）；「有界 × 无穷小 = 无穷小」但「有界 × 无界」不确定。

3.1 ε-N 定义的逐字解读

定义（数列极限的 ε-N 说法）： $$\lim_{n\to\infty}a_n=A \iff \forall \varepsilon>0,\ \exists N\in\mathbb{N}^+,\ \text{当 }n>N\text{ 时 }|a_n-A|<\varepsilon.$$ 四个要点：① $\varepsilon$ 任意小（是「任意给定」的，不是动点）；② $N$ 依赖 $\varepsilon$（通常 $N$ 随 $\varepsilon$ 减小而增大）；③ $n>N$ 强调「只要项数足够靠后」；④ $|a_n-A|<\varepsilon$ 而非 $\le$。

3.2 用 ε-N 证明极限（标准三步）

方法：① 把 $|a_n-A|$ 化简放大到 $C/n$ 之类；② 令其 $<\varepsilon$ 解出 $n$；③ 取 $N$ 为解的整数部分。
例 1：用 ε-N 证明 $\lim_{n\to\infty}\dfrac{2n+1}{n}=2$。
查看解答
解：任给 $\varepsilon>0$， $$\left|\frac{2n+1}{n}-2\right|=\frac{1}{n}<\varepsilon \iff n>\frac{1}{\varepsilon}.$$ 取 $N=\left\lceil\frac{1}{\varepsilon}\right\rceil$，则 $n>N$ 时原式成立。
例 2：用 ε-N 证明 $\lim_{n\to\infty}\dfrac{3n^2+n}{2n^2-1}=\dfrac{3}{2}$。
查看解答
解： $$\left|\frac{3n^2+n}{2n^2-1}-\frac{3}{2}\right|=\left|\frac{2n+3}{2(2n^2-1)}\right|.$$ 当 $n\ge 2$ 时 $2n+3\le 3n$，$2n^2-1\ge n^2$，故上式 $\le \frac{3n}{2n^2}=\frac{3}{2n}<\varepsilon$ 需 $n>\frac{3}{2\varepsilon}$。取 $N=\max(2,\lceil\frac{3}{2\varepsilon}\rceil)$。

3.3 收敛数列性质的严格证明

定理（唯一性）：收敛数列的极限唯一。
证明：设 $a_n\to A$ 且 $a_n\to B$，$A\neq B$。取 $\varepsilon=\frac{|A-B|}{3}>0$。$\exists N_1$ 使 $n>N_1$ 时 $|a_n-A|<\varepsilon$；$\exists N_2$ 使 $n>N_2$ 时 $|a_n-B|<\varepsilon$。取 $N=\max(N_1,N_2)$，则 $n>N$ 时 $|A-B|\le|A-a_n|+|a_n-B|<2\varepsilon=\frac{2|A-B|}{3}$，矛盾。
定理（保号性）：若 $\lim a_n=A>0$，则 $\exists N$ 使 $n>N$ 时 $a_n>0$。
证明：取 $\varepsilon=A/2>0$，$\exists N$ 使 $n>N$ 时 $|a_n-A|<A/2$，即 $a_n>A-A/2=A/2>0$。

3.4 夹逼定理与单调有界的应用

例 3：求 $\lim_{n\to\infty}\left(\dfrac{1}{\sqrt{n^2+1}}+\dfrac{1}{\sqrt{n^2+2}}+\cdots+\dfrac{1}{\sqrt{n^2+n}}\right)$。
查看解答
解：记和为 $S_n$。每项夹在 $\frac{1}{\sqrt{n^2+n}}$ 与 $\frac{1}{\sqrt{n^2+1}}$ 之间： $$\frac{n}{\sqrt{n^2+n}}\le S_n\le \frac{n}{\sqrt{n^2+1}}.$$ 两端分别 $\to 1$（$\frac{n}{\sqrt{n^2+n}}=\frac{1}{\sqrt{1+1/n}}\to 1$），由夹逼 $S_n\to 1$。
例 4：设 $a_1=\sqrt{2}$，$a_{n+1}=\sqrt{2+a_n}$，证明收敛并求极限。
查看解答
解：① 有界：归纳 $0<a_n\le 2$。② 递增：$a_{n+1}-a_n=\sqrt{2+a_n}-a_n=\frac{2+a_n-a_n^2}{\sqrt{2+a_n}+a_n}=\frac{(2-a_n)(1+a_n)}{\cdots}>0$。由单调有界定理收敛，设极限为 $A$，则 $A=\sqrt{2+A}$，$A^2-A-2=0$，$A=2$（舍去负根）。

3.5 本节习题

习 1：用 ε-N 证明 $\lim_{n\to\infty}\frac{1}{\sqrt{n}}=0$。
查看答案
答：$|\frac{1}{\sqrt{n}}-0|<\varepsilon\Rightarrow n>\frac{1}{\varepsilon^2}$，取 $N=\lceil 1/\varepsilon^2\rceil$。
习 2：求 $\lim_{n\to\infty}\frac{n!}{n^n}$。
查看答案
答：$0\le\frac{n!}{n^n}\le\frac{1}{n}$（每项 $\le 1$，第一项为 $1/n$），夹逼得 $0$。
习 3：求 $\lim_{n\to\infty}\sqrt[n]{n}$。
查看答案
答：令 $\sqrt[n]{n}=1+h_n$，$n=(1+h_n)^n\ge\frac{n(n-1)}{2}h_n^2$，$0\le h_n\le\sqrt{\frac{2}{n-1}}\to 0$，故极限 $1$。
习 4：设 $a_1=1$，$a_{n+1}=\frac{1}{2}(a_n+\frac{2}{a_n})$，证明收敛并求极限。
查看答案
答：归纳 $a_n\ge\sqrt{2}$（均值不等式）；$a_{n+1}-a_n=\frac{2-a_n^2}{2a_n}\le 0$ 递减；极限 $A$ 满足 $A=\frac{1}{2}(A+2/A)$，$A=\sqrt{2}$。

4. 函数极限 自变量的连续逼近

定义（函数极限 ε-δ）：$\lim_{x\to x_0}f(x)=A\iff$ 对任意 $\varepsilon>0$，存在 $\delta>0$，使 $0<|x-x_0|<\delta$ 时 $|f(x)-A|<\varepsilon$。注意：极限与 $f(x_0)$ 无关，甚至不要求 $f$ 在 $x_0$ 有定义。
定义（单侧极限）：左极限 $\lim_{x\to x_0^-}f(x)$（$x<x_0$）与右极限 $\lim_{x\to x_0^+}f(x)$。极限存在 $\iff$ 左右极限都存在且相等。$x\to\infty$ 的极限类似：$\lim f(x)=A\iff$ $\forall\varepsilon$ $\exists X$ 使 $|x|>X$ 时 $|f(x)-A|<\varepsilon$。
定理（极限运算法则）：lim(f±g) = lim f ± lim g；lim(fg) = lim f · lim g；lim(f/g) = lim f / lim g（lim g ≠ 0）。复合函数极限：lim g(x) = u₀ 且 g(x) ≠ u₀，则 lim f(g(x)) = f(u₀)（f 在 u₀ 连续时）。
例：lim (x²−1)/(x−1) = lim (x+1) = 2（x→1）——先消去零因子。
例：用 ε-δ 证明 $\lim_{x\to 3}(2x-1)=5$。
查看答案
答案：$|(2x-1)-5|=2|x-3|<\varepsilon$ 当 $|x-3|<\varepsilon/2$。取 $\delta=\varepsilon/2$ 即可。
易错警示：「0/0」型不能直接代入；先因式分解、有理化（乘共轭）、通分。例：$\lim_{x\to 0}\dfrac{\sqrt{x+1}-1}{x}=\lim_{x\to 0}\dfrac{1}{\sqrt{x+1}+1}=\dfrac{1}{2}$。

4.1 ε-δ 定义的逐字解读

定义（ε-δ 正式陈述）： $$\lim_{x\to x_0}f(x)=A \iff \forall\varepsilon>0,\ \exists\delta>0,\ \text{当 }0<|x-x_0|<\delta\text{ 时 }|f(x)-A|<\varepsilon.$$ 关键：$0<|x-x_0|$ 表示 $x\neq x_0$——极限关心「$x$ 靠近 $x_0$ 时 $f$ 的走向」，不在乎 $f(x_0)$ 本身。

4.2 用 ε-δ 证明极限（放缩法）

例 1：证明 $\lim_{x\to 2}(x^2-1)=3$。
查看解答
解：$|x^2-1-3|=|x^2-4|=|x-2||x+2|$。先限 $|x-2|<1$（即 $1<x<3$），则 $|x+2|<5$。于是只要 $|x-2|<\varepsilon/5$。取 $\delta=\min(1,\varepsilon/5)$。
例 2：证明 $\lim_{x\to 1}\dfrac{x^2-1}{x-1}=2$（注意 $x=1$ 处函数无定义）。
查看解答
解：$0<|x-1|<\delta$ 时 $\frac{x^2-1}{x-1}=x+1$（约去零因子），$|(x+1)-2|=|x-1|<\varepsilon$，取 $\delta=\varepsilon$。

4.3 左右极限与分段函数

定理：$\lim_{x\to x_0}f(x)=A\iff f(x_0^-)=f(x_0^+)=A$。
关键：分段函数在分段点必须分别算左右极限。$|x|$ 在 $0$ 处左极限 $-1$、右极限 $1$，极限不存在。
例 3：$f(x)=\begin{cases}x^2,&x<1\\ ax+b,&1\le x\le 2\\ 2x,&x>2\end{cases}$，求 $a,b$ 使 $f$ 在 $x=1,2$ 极限存在。
查看解答
解：$x\to 1^-$：$f=1$；$x\to 1^+$：$a+b$，需 $a+b=1$。$x\to 2^-$：$2a+b$；$x\to 2^+$：$4$，需 $2a+b=4$。联立 $a=3$，$b=-2$。

4.4 极限的性质（唯一性、局部保号、局部有界）

定理（局部保号性）：若 $\lim_{x\to x_0}f(x)=A>0$，则存在 $\mathring{U}(x_0)$ 使 $f(x)>0$。
证明：取 $\varepsilon=A/2$，$\exists\delta$ 使 $0<|x-x_0|<\delta$ 时 $|f(x)-A|<A/2$，$f(x)>A/2>0$。
定理（海涅定理——归结原则）：$\lim_{x\to x_0}f(x)=A\iff$ 对任何 $x_n\to x_0$（$x_n\neq x_0$），有 $f(x_n)\to A$。
用途：证明函数极限不存在——找两个趋于 $x_0$ 的数列使 $f$ 趋于不同值。例：$f(x)=\sin\frac{1}{x}$ 在 $x\to 0$，取 $x_n=\frac{1}{2n\pi+\pi/2}\to 0$，$f(x_n)=1$；取 $y_n=\frac{1}{2n\pi}\to 0$，$f(y_n)=0$，极限不存在。

5. 两个重要极限 必须背熟、会用

定理（第一重要极限）：$\lim_{x\to 0}\dfrac{\sin x}{x}=1$。
证明要点（几何夹逼）：单位圆中扇形面积 $\dfrac{x}{2}$ 夹在三角形 $\dfrac{\sin x}{2}$ 与 $\dfrac{\tan x}{2}$ 之间：$\sin x<x<\tan x$，除以 $\sin x$ 后取极限。
定理（第二重要极限）：$\lim_{x\to\infty}\left(1+\dfrac{1}{x}\right)^x=e$；等价 $\lim_{t\to 0}(1+t)^{1/t}=e$。
证明要点：对整数 $n$ 已证 $(1+1/n)^n\to e$；一般 $x$ 用夹逼夹在相邻整数之间。
定理（推广形式）：若 $u(x)\to 0$，则 $\lim(1+u)^{1/u}=e$；$\lim\dfrac{\sin u}{u}=1$。
例：$\lim(1+3x)^{1/x}=\left[\lim(1+3x)^{1/(3x)}\right]^3=e^3$。
例：求 $\lim_{x\to 0}\dfrac{1-\cos x}{x^2}$。
查看答案
答案：$1-\cos x=2\sin^2(x/2)$，原式 $=2\cdot\left[\dfrac{\sin(x/2)}{x/2}\right]^2\cdot\dfrac{1}{4}=\dfrac{1}{2}$。

5.1 第一重要极限的严格证明

定理：$\displaystyle\lim_{x\to 0}\frac{\sin x}{x}=1$。
证明（几何夹逼，$0<x<\pi/2$）： ① 单位圆内：$\triangle OAB$ 面积 $< $ 扇形 $OAB$ 面积 $< $ $\triangle OAT$ 面积。 $$\frac{1}{2}\sin x<\frac{1}{2}x<\frac{1}{2}\tan x\Rightarrow \sin x<x<\tan x.$$ ② 除以 $\sin x>0$：$1<\frac{x}{\sin x}<\frac{1}{\cos x}$，取倒数 $\cos x<\frac{\sin x}{x}<1$。 ③ $\lim_{x\to 0^+}\cos x=1$（由 $0\le 1-\cos x=2\sin^2\frac{x}{2}\le\frac{x^2}{2}\to 0$），夹逼得 $\frac{\sin x}{x}\to 1$。 ④ $x<0$ 时用 $\sin x/x$ 为偶函数，同理。

5.2 第二重要极限的严格证明

定理：$\displaystyle\lim_{x\to\infty}\left(1+\frac{1}{x}\right)^x=e$。
证明： ① 数列 $\left(1+\frac{1}{n}\right)^n$ 单调递增有上界（见 §3），极限记为 $e$。 ② 对实数 $x\to+\infty$：取 $n=\lfloor x\rfloor$，则 $n\le x<n+1$， $$\left(1+\frac{1}{n+1}\right)^n<\left(1+\frac{1}{x}\right)^x<\left(1+\frac{1}{n}\right)^{n+1}.$$ 左右两端都趋于 $e$（左端 $=\frac{(1+1/(n+1))^{n+1}}{1+1/(n+1)}\to e$；右端 $=(1+1/n)^n(1+1/n)\to e$），夹逼。 ③ $x\to-\infty$ 令 $x=-t$，$t\to+\infty$，$\left(1-\frac{1}{t}\right)^{-t}=\left(\frac{t}{t-1}\right)^t=\left(1+\frac{1}{t-1}\right)^t\to e$。

6. 无穷小与无穷大 阶的比较是求极限的利器

定义：极限为 0 的函数称无穷小（lim α = 0）；|f| 趋于 +∞ 称无穷大。无穷大是「无界且正负确定」的特殊情形。
定理（无穷小的比较）：设 $\lim\alpha=\lim\beta=0$：若 $\lim\dfrac{\beta}{\alpha}=0$ 则 $\beta$ 是 $\alpha$ 的高阶无穷小（$\beta=o(\alpha)$）；若 $\lim\dfrac{\beta}{\alpha}=c\ne 0$ 则同阶；若 $c=1$ 则等价（$\beta\sim\alpha$）。
核心结论：等价无穷小在乘除中可替换：$x\to 0$ 时 $\sin x\sim x$、$\tan x\sim x$、$\arcsin x\sim x$、$\ln(1+x)\sim x$、$e^x-1\sim x$、$1-\cos x\sim x^2/2$、$\sqrt{1+x}-1\sim x/2$。
易错警示：等价无穷小替换只允许在乘除因子中使用！加减中直接替换是高频错误：lim (tan x − sin x)/x³ 不能分别把 tan x、sin x 换成 x（会得 0，而真实答案是 1/2）。正确做法：提取 tan x(1−cos x) ~ x·x²/2。
例：求 $\lim_{x\to 0}\dfrac{e^{2x}-1}{\sin 3x}$。
查看答案
答案：$e^{2x}-1\sim 2x$，$\sin 3x\sim 3x$，原式 $=\dfrac{2}{3}$。

6.1 无穷小与极限的关系定理

定理：$\lim f(x)=A\iff f(x)=A+\alpha(x)$，其中 $\alpha(x)$ 是无穷小。
证明：$f(x)-A\to 0$ 即 $\alpha\to 0$，反之亦然。这是「极限」与「无穷小」互译的桥梁。
定理（有界量 × 无穷小）：若 $g$ 局部有界且 $\alpha\to 0$，则 $g\alpha\to 0$。
证明：$|g|\le M$，$|g\alpha|\le M|\alpha|\to 0$。例：$x\sin\frac{1}{x}\to 0$（$x\to 0$）。

6.3 等价无穷小替换定理与证明

定理：设 $\alpha\sim\alpha'$，$\beta\sim\beta'$ 且 $\lim\frac{\alpha'}{\beta'}$ 存在，则 $\lim\frac{\alpha}{\beta}=\lim\frac{\alpha'}{\beta'}$。
证明：$\frac{\alpha}{\beta}=\frac{\alpha}{\alpha'}\cdot\frac{\alpha'}{\beta'}\cdot\frac{\beta'}{\beta}$，两端因子都趋于 $1$，由乘法法则得证。
为什么加减不能换：替换原理要求被换部分是因子。$\tan x-\sin x=\sin x(\frac{1}{\cos x}-1)$，把 $\sin x$ 换成 $x$ 是因子替换（合法），但把两项分别换成 $x-x=0$ 就丢了高阶项 $x^3/2$。

定义（连续）：$f$ 在 $x_0$ 连续 $\iff\lim_{x\to x_0}f(x)=f(x_0)$，等价于「$\lim\Delta y=0$ 当 $\Delta x\to 0$」。$f$ 在区间上连续 $=$ 每点连续；左连续/右连续对应单侧。

7.1 连续的三种等价定义

定义：$f$ 在 $x_0$ 连续 ⟺ 下列任一： $$\lim_{x\to x_0}f(x)=f(x_0);\qquad \lim_{\Delta x\to 0}\Delta y=0;\qquad \forall\varepsilon>0,\exists\delta>0,\ |x-x_0|<\delta\Rightarrow|f(x)-f(x_0)|<\varepsilon.$$ 注意第三种定义与函数极限的 ε-δ 不同：连续要求 $|x-x_0|<\delta$（允许 $x=x_0$），而极限要求 $0<|x-x_0|<\delta$。

8. 闭区间上连续函数的性质 三大定理是分析学的基石

定理（有界性与最值定理）：f 在 [a,b] 上连续 ⟹ f 在 [a,b] 上有界且取到最大值、最小值。
注意：开区间不成立：f(x) = 1/x 在 (0,1) 无界；f(x) = x 在 (0,1) 无最值。
定理（介值定理）：f 在 [a,b] 连续，则 f 取遍 f(a) 与 f(b) 之间的一切值。特别地：f(a)f(b) < 0 则存在 c ∈ (a,b) 使 f(c) = 0（零点定理）。
证明要点：设 f(a) < y < f(b)，集合 {x : f(x) < y} 的上确界 c，由连续性 f(c) = y。
定理（一致连续性定理）：闭区间上的连续函数一致连续（δ 不依赖 x 的位置）。
证明要点：反证 + 波尔查诺-魏尔斯特拉斯（有界数列有收敛子列）。开区间不保证：1/x 在 (0,1) 不一致连续。
例：证明方程 x³ − 3x + 1 = 0 在 (0,1) 内有根。
查看答案
答案：f(0) = 1 > 0，f(1) = −1 < 0，零点定理 ⟹ 存在 c ∈ (0,1) 使 f(c) = 0。
例：证明 x = cos x 在 (0,1) 内有解。
查看答案
答案：令 f(x) = cos x − x：f(0) = 1 > 0，f(1) = cos 1 − 1 < 0，零点定理。

8.1 最值定理的严格陈述与反例

定理（最值定理）：若 $f$ 在 $[a,b]$ 上连续，则 $\exists \xi_1,\xi_2\in[a,b]$ 使 $$f(\xi_1)=\max_{[a,b]}f(x),\qquad f(\xi_2)=\min_{[a,b]}f(x).$$
证明思路（两点缺一不可）：① 先用确界原理：$f([a,b])$ 有上确界 $M$；② 反证若 $f(x)<M$ 对所有 $x$，则 $g(x)=\frac{1}{M-f(x)}$ 连续有界，但 $M$ 是上确界说明 $M-f(x)$ 可任意小，$g$ 无界，矛盾。故某点取到 $M$。下界同理。
两个条件缺一：「闭区间」与「连续」。$f(x)=\frac{1}{x}$ 在 $(0,1]$ 连续但无界；$f(x)=x$ 在 $(0,1)$ 连续但取不到最大最小。

8.2 介值定理与零点定理

定理（零点定理）：$f$ 在 $[a,b]$ 连续，$f(a)f(b)<0$，则 $\exists c\in(a,b)$ 使 $f(c)=0$。
证明：不妨 $f(a)<0<f(b)$。令 $S=\{x\in[a,b]:f(x)\le 0\}$，$S$ 非空有上界，设 $c=\sup S$。证 $f(c)=0$：若 $f(c)<0$，由连续附近仍负，$c$ 之后仍有零点使 $S$ 更大，矛盾；若 $f(c)>0$，附近仍正，则 $c$ 并非上确界，矛盾。故 $f(c)=0$。
定理（介值定理）：$f$ 在 $[a,b]$ 连续，$f(a)\neq f(b)$，则对任何介于 $f(a),f(b)$ 之间的值 $\mu$，$\exists c\in(a,b)$ 使 $f(c)=\mu$。
证明：令 $g(x)=f(x)-\mu$，则 $g(a)g(b)<0$，对 $g$ 用零点定理。

8.3 一致连续（Cantor 定理）

定义（一致连续）：$f$ 在区间 $I$ 一致连续 ⟺ $\forall\varepsilon>0,\exists\delta>0$（只依赖 $\varepsilon$），使对 $I$ 中任意两点 $x_1,x_2$，只要 $|x_1-x_2|<\delta$ 就有 $|f(x_1)-f(x_2)|<\varepsilon$。
与逐点连续的区别：逐点连续中 $\delta$ 可依赖 $x_0$；一致连续中 $\delta$ 对所有 $x$ 通用。
定理（Cantor）：闭区间 $[a,b]$ 上连续函数必一致连续。
证明思路（反证 + 列紧性）：假设不一致连续，则 $\exists\varepsilon_0>0$，对任意 $\delta=1/n$ 都有 $x_n,y_n$ 使 $|x_n-y_n|<1/n$ 但 $|f(x_n)-f(y_n)|\ge\varepsilon_0$。由 Bolzano–Weierstrass 定理 $\{x_n\}$ 有收敛子列 $x_{n_k}\to c\in[a,b]$，则 $y_{n_k}\to c$。$f$ 在 $c$ 连续，故 $f(x_{n_k})\to f(c)$、$f(y_{n_k})\to f(c)$，差趋于 $0$，与 $\ge\varepsilon_0$ 矛盾。

8.4 例题：零点定理的应用

例 1：证明 $x=a\sin x+b$（$a,b>0$）至少有一个正根。
查看解答
解：令 $f(x)=x-a\sin x-b$。$f(0)=-b<0$；$x=a+b+1$ 时 $f\ge(a+b+1)-a-b=1>0$。由零点定理在 $(0,a+b+1)$ 内有根。
例 2：设 $f$ 在 $[0,1]$ 连续，$f(0)=f(1)$，证明 $\exists c\in[0,1/2]$ 使 $f(c)=f(c+1/2)$。
查看解答
解：令 $g(x)=f(x)-f(x+1/2)$，$x\in[0,1/2]$。$g(0)=f(0)-f(1/2)$，$g(1/2)=f(1/2)-f(1)=f(1/2)-f(0)$，故 $g(0)g(1/2)\le 0$。若等号成立直接得；否则 $g(0)g(1/2)<0$，零点定理。
例 3：证明 $1/x$ 在 $(0,1)$ 不一致连续。
查看解答
解：取 $x_n=\frac{1}{n}$，$y_n=\frac{1}{n+1}$，$|x_n-y_n|=\frac{1}{n(n+1)}\to 0$，但 $|\frac{1}{x_n}-\frac{1}{y_n}|=1$ 不趋于 $0$。故不一致连续。

9a. 深度：实数完备性与确界原理 为什么极限理论必须建立在实数之上

定义（上确界） 设 $E\subset\mathbb{R}$ 非空。若 $\beta\in\mathbb{R}$ 满足：(i) $\forall x\in E,\ x\le\beta$；(ii) $\forall\varepsilon>0,\ \exists x_0\in E$ 使 $x_0>\beta-\varepsilon$，则称 $\beta$ 为 $E$ 的上确界，记 $\beta=\sup E$。
公理（确界原理） 非空有上界的实数集必有上确界；非空有下界的实数集必有下确界。
说明：这是实数集的完备性公理——有理数集 $\mathbb{Q}$ 不满足此性质（例如 $\{q\in\mathbb{Q}:q^2<2\}$ 在 $\mathbb{Q}$ 中无上确界）。确界原理等价于单调有界定理、区间套定理、有限覆盖定理、聚点定理、Cauchy 收敛准则，它们共同刻画实数的完备性。
定理（单调有界定理） 单调递增有上界的数列必收敛；单调递减有下界的数列必收敛。
证明：设 $\{a_n\}$ 递增有上界，由确界原理 $\beta=\sup\{a_n\}$ 存在。$\forall\varepsilon>0$，$\exists N$ 使 $a_N>\beta-\varepsilon$。由单调性，$n>N$ 时 $\beta-\varepsilon<a_N\le a_n\le\beta<\beta+\varepsilon$，即 $|a_n-\beta|<\varepsilon$。
例：用确界原理证明 $\sqrt{2}$ 存在。
解：令 $E=\{x>0:x^2<2\}$。$E$ 非空（$1\in E$）且有上界（$2$ 是上界）。设 $\beta=\sup E$。若 $\beta^2<2$，取 $n$ 使 $2n\beta+1<n(2-\beta^2)$，则 $(\beta+1/n)^2<2$，与 $\beta$ 是上界矛盾；若 $\beta^2>2$，类似可取 $n$ 使 $(\beta-1/n)^2>2$，与确界定义矛盾。故 $\beta^2=2$。

9b. 深度：一致连续与 Cantor 定理 连续与一致连续的真正区别

定义（一致连续） $f$ 在区间 $I$ 上一致连续，若 $\forall\varepsilon>0,\ \exists\delta>0$，使得对任意 $x_1,x_2\in I$，只要 $|x_1-x_2|<\delta$，就有 $|f(x_1)-f(x_2)|<\varepsilon$。
定理（Cantor 定理） 闭区间 $[a,b]$ 上的连续函数必一致连续。
证明（反证+致密性）：若 $f$ 不一致连续，则 $\exists\varepsilon_0>0$，$\forall n,\ \exists x_n,y_n\in[a,b]$，$|x_n-y_n|<1/n$ 但 $|f(x_n)-f(y_n)|\ge\varepsilon_0$。由 Bolzano–Weierstrass，$\{x_n\}$ 有收敛子列 $x_{n_k}\to x_0\in[a,b]$，则 $y_{n_k}\to x_0$。由连续性 $f(x_{n_k})\to f(x_0)$、$f(y_{n_k})\to f(x_0)$，故 $|f(x_{n_k})-f(y_{n_k})|\to0$，矛盾。
例：证明 $f(x)=1/x$ 在 $(0,1)$ 上连续但不一致连续。
解：连续性显然。不一致连续：取 $x_n=1/n$，$y_n=1/(n+1)$，则 $|x_n-y_n|=1/[n(n+1)]\to0$，但 $|f(x_n)-f(y_n)|=|n-(n+1)|=1\ge\varepsilon_0=1$。这说明开区间上连续未必一致连续——Cantor 定理要求闭区间。
定理 开区间 $(a,b)$ 上连续函数一致连续 $\iff$ $f(a+)$ 与 $f(b-)$ 都存在（有限）。此时可延拓为闭区间上的连续函数。

9c. 深度：Stolz 定理与 L’Hospital 法则 求极限的两大强力工具

定理（Stolz，$\cdot/\infty$ 型） 设 $\{b_n\}$ 严格递增且 $b_n\to+\infty$。若 $\lim_{n\to\infty}\dfrac{a_n-a_{n-1}}{b_n-b_{n-1}}=A$（$A$ 可为 $\pm\infty$），则 $\lim_{n\to\infty}\dfrac{a_n}{b_n}=A$。
证明思路：对 $A$ 有限的情形，由条件 $\forall\varepsilon>0,\ \exists N$，$n>N$ 时 $A-\varepsilon<\dfrac{a_n-a_{n-1}}{b_n-b_{n-1}}<A+\varepsilon$。累加得 $(A-\varepsilon)(b_n-b_N)<a_n-a_N<(A+\varepsilon)(b_n-b_N)$，除以 $b_n$ 并令 $n\to\infty$ 即得。
定理（L’Hospital 法则，$0/0$ 型） 设 $f,g$ 在 $x_0$ 的某去心邻域可导，$g'(x)\ne0$，$\lim f=\lim g=0$。若 $\lim\dfrac{f'(x)}{g'(x)}=A$，则 $\lim\dfrac{f(x)}{g(x)}=A$。
证明：补充定义 $f(x_0)=g(x_0)=0$。在 $[x_0,x]$（或 $[x,x_0]$）上应用 Cauchy 中值定理：$\dfrac{f(x)-f(x_0)}{g(x)-g(x_0)}=\dfrac{f'(\xi)}{g'(\xi)}$，$\xi$ 在 $x_0$ 与 $x$ 之间。令 $x\to x_0$，则 $\xi\to x_0$，故极限为 $A$。
例：用 Stolz 定理求 $\lim_{n\to\infty}\dfrac{1^k+2^k+\cdots+n^k}{n^{k+1}}$。
解：$a_n=\sum_{i=1}^n i^k$，$b_n=n^{k+1}$（严格递增趋于 $\infty$）。$a_n-a_{n-1}=n^k$，$b_n-b_{n-1}=n^{k+1}-(n-1)^{k+1}\sim(k+1)n^k$。故 $\lim\dfrac{a_n-a_{n-1}}{b_n-b_{n-1}}=\dfrac{1}{k+1}$，由 Stolz 定理原式 $=\dfrac{1}{k+1}$。

9d. 深度：一致连续与 Cantor 定理 连续还不够，要「均匀地」连续

定义（一致连续） $f:E\to\mathbb{R}$ 一致连续，若 $\forall\epsilon>0,\exists\delta>0$ 使 $|x-y|<\delta\Rightarrow|f(x)-f(y)|<\epsilon$（$\delta$ 与 $x,y$ 无关，仅依赖 $\epsilon$）。
定理（Cantor） 闭区间 $[a,b]$ 上的连续函数必一致连续。
证明：反证。若不一致连续，$\exists\epsilon_0>0$ 及 $x_n,y_n\in[a,b]$ 使 $|x_n-y_n|<1/n$ 但 $|f(x_n)-f(y_n)|\ge\epsilon_0$。由 Bolzano–Weierstrass，$x_n$ 有收敛子列 $x_{n_k}\to\xi$，则 $y_{n_k}\to\xi$。连续性给 $f(x_{n_k})\to f(\xi)$ 和 $f(y_{n_k})\to f(\xi)$，故 $|f(x_{n_k})-f(y_{n_k})|\to0$——与 $\ge\epsilon_0$ 矛盾。
定理（非闭区间反例） $f(x)=1/x$ 在 $(0,1]$ 连续但非一致连续。
证：取 $x_n=1/n$, $y_n=1/(n+1)$，$|x_n-y_n|\to0$ 但 $|f(x_n)-f(y_n)|=1\not\to0$。一致连续要求「$\delta$ 统一」，在靠近 0 的地方函数变得太陡。
例：判断 $f(x)=\sin(1/x)$ 在 $(0,1]$ 是否一致连续。
解：不一致连续。取 $x_n=\frac1{2n\pi}$, $y_n=\frac1{2n\pi+\pi/2}$，$|x_n-y_n|\to0$ 但 $|\sin(1/x_n)-\sin(1/y_n)|=|0-\sin(2n\pi+\pi/2)|=1$。函数在 0 附近振荡越来越快，无法找到统一的 $\delta$。

9e. 深度：函数项级数的一致收敛 什么时候和函数保持好性质

定义（一致收敛） 级数 $\sum f_n(x)$ 在 $E$ 上一致收敛到 $S(x)$，若部分和 $S_N=\sum_{n=1}^N f_n$ 满足 $\sup_{x\in E}|S_N(x)-S(x)|\to0$（$N\to\infty$）。
定理（Weierstrass 判别法） 若 $|f_n(x)|\le M_n$（$\forall x\in E$）且 $\sum M_n$ 收敛，则 $\sum f_n$ 在 $E$ 上一致收敛。
思路：$|S_N-S|=|\sum_{n>N}f_n|\le\sum_{n>N}M_n\to0$（余项控制），与 $x$ 无关。
定理（一致收敛保持连续性） 若 $f_n$ 连续且 $\sum f_n$ 一致收敛到 $S$，则 $S$ 连续。更一般地，逐项求极限合法：$\lim_{x\to a}S(x)=\sum\lim_{x\to a}f_n(x)$。
意义：非一致收敛可能破坏连续性——$\sum x^n$ 在 $[0,1)$ 内和 $1/(1-x)$ 连续，但在 $x=1$ 发散到 $\infty$，若延拓 $S(1)=\infty$ 则不连续。关键：$[0,1]$ 上不一致收敛。
例：判断 $\sum_{n=1}^\infty\frac{\sin nx}{n^2}$ 在 $\mathbb{R}$ 上的收敛性。
解：$|\sin nx/n^2|\le1/n^2$，$\sum 1/n^2$ 收敛，故 Weierstrass 判别法给一致收敛。和函数 $S(x)$ 连续。进一步，由一致收敛可逐项积分：$$\int_0^\pi S(x)\,dx=\sum_{n=1}^\infty\frac1{n^2}\cdot\frac{1-(-1)^n}{n}=2\sum_{k=1}^\infty\frac1{(2k-1)^3}=\frac{7}{4}\zeta(3)\approx2.104$$（仅奇 $n$ 项贡献，利用 $\sum_{k\ge1}(2k-1)^{-3}=\frac78\zeta(3)$）。

解：$\dfrac{\tan 3x}{x}=\dfrac{\tan 3x}{3x}\cdot 3\to 1\cdot 3=3$。
练习 21：证明当 $x\to 0$ 时 $\sqrt{1+x}-1\sim\dfrac{x}{2}$。
查看答案
解：$\lim_{x\to 0}\dfrac{\sqrt{1+x}-1}{x/2}=\lim_{x\to 0}\dfrac{2(\sqrt{1+x}-1)}{x}=\lim_{x\to 0}\dfrac{2x}{x(\sqrt{1+x}+1)}=\dfrac{2}{2}=1$，故二者等价。

能力提高（练习 22–31）

练习 22：求 $\lim_{x\to 0}\dfrac{\sqrt{1+x}-\sqrt{1-x}}{x}$。
查看答案
解：分子有理化，乘以 $\dfrac{\sqrt{1+x}+\sqrt{1-x}}{\sqrt{1+x}+\sqrt{1-x}}$：原式 $=\dfrac{2x}{x(\sqrt{1+x}+\sqrt{1-x})}=\dfrac{2}{\sqrt{1+x}+\sqrt{1-x}}\to 1$。
练习 23：求 $\lim_{x\to 1}\dfrac{x^3-1}{x-1}$。
查看答案
解：$x^3-1=(x-1)(x^2+x+1)$，约去 $x-1$ 后取极限 $=x^2+x+1\big|_{x=1}=3$。
练习 24：求 $\lim_{x\to 0}\dfrac{1-\cos x}{x\sin x}$。
查看答案
解：$1-\cos x\sim\dfrac{x^2}{2}$，$\sin x\sim x$，故原式 $\sim\dfrac{x^2/2}{x\cdot x}=\dfrac{1}{2}$。
练习 25：求 $\lim_{x\to\infty}\left(1+\dfrac{2}{x}\right)^x$。
查看答案
解：原式 $=\left[\left(1+\dfrac{2}{x}\right)^{x/2}\right]^2$，令 $t=x/2$，内层 $\to e$，故原式 $=e^2$。
练习 26：求 $\lim_{x\to 0}(1+3x)^{1/x}$。
查看答案
解：原式 $=\left[(1+3x)^{1/(3x)}\right]^3\to e^3$。
练习 27：求 $\lim_{n\to\infty}\left(\sqrt{n^2+n}-n\right)$。
查看答案
解：有理化：$\sqrt{n^2+n}-n=\dfrac{n}{\sqrt{n^2+n}+n}=\dfrac{1}{\sqrt{1+1/n}+1}\to\dfrac{1}{2}$。
练习 28：求 $\lim_{x\to 0}\dfrac{\ln(1+2x)}{\sin 3x}$。
查看答案
解：$x\to 0$ 时 $\ln(1+2x)\sim 2x$，$\sin 3x\sim 3x$，故原式 $\to\dfrac{2}{3}$。
练习 29：求函数 $f(x)=\dfrac{x^2-1}{x^2-3x+2}$ 的间断点并判断类型。
查看答案
解：$f(x)=\dfrac{(x-1)(x+1)}{(x-1)(x-2)}$。在 $x=1$ 处，$\lim_{x\to 1}f(x)=\dfrac{x+1}{x-2}\Big|_{x=1}=-2$ 存在，为可去间断点；在 $x=2$ 处，$x\to 2^{-}$ 时 $f\to-\infty$、$x\to 2^{+}$ 时 $f\to+\infty$，为无穷间断点（第二类）。
练习 30：设 $f(x)=\begin{cases}a+x^2,&x\le 0\\[2pt]\dfrac{\sin 2x}{x},&x>0\end{cases}$ 在 $x=0$ 处连续，求 $a$。
查看答案
解：$f(0)=a$，而 $\lim_{x\to 0^{+}}\dfrac{\sin 2x}{x}=2\lim_{x\to 0^{+}}\dfrac{\sin 2x}{2x}=2$。连续性要求 $f(0)=\lim_{x\to 0^{+}}f(x)$，故 $a=2$。
练习 31：设 $x_1=\sqrt{2}$，$x_{n+1}=\sqrt{2+x_n}$。证明数列收敛并求其极限。
查看答案
解：① 有上界：$x_1=\sqrt2<2$；若 $x_n<2$，则 $x_{n+1}=\sqrt{2+x_n}<\sqrt4=2$，归纳得 $x_n<2$。② 递增：$x_{n+1}>x_n\Leftrightarrow 2+x_n>x_n^2\Leftrightarrow(2-x_n)(x_n+1)>0$，由 $x_n<2$ 成立。由单调有界定理数列收敛，设极限为 $L$，则 $L=\sqrt{2+L}$，即 $L^2-L-2=0$，解得 $L=2$（舍去负根 $-1$）。

考研真题与综合（练习 32–37）

练习 32：已知 $x\to 0$ 时 $e^{x^2}-\cos x$ 与 $ax^b$ 是等价无穷小，求常数 $a,b$。
查看答案
解：展开到四阶：$e^{x^2}=1+x^2+\dfrac{x^4}{2}+o(x^4)$，$\cos x=1-\dfrac{x^2}{2}+\dfrac{x^4}{24}+o(x^4)$。相减得 $e^{x^2}-\cos x=\dfrac{3}{2}x^2+\dfrac{11}{24}x^4+o(x^4)\sim\dfrac{3}{2}x^2$。故 $a=\dfrac{3}{2},\ b=2$。
练习 33：求 $\lim_{x\to 0}(\cos x)^{1/x^2}$。
查看答案
解：这是 $1^\infty$ 型，取对数：$\ln L=\lim_{x\to 0}\dfrac{\ln\cos x}{x^2}$。由 $\cos x=1-\dfrac{x^2}{2}+o(x^2)$，得 $\ln\cos x\sim-\dfrac{x^2}{2}$，故 $\ln L=-\dfrac{1}{2}$，$L=e^{-1/2}=\dfrac{1}{\sqrt e}$。
练习 34：用夹逼定理求 $\lim_{n\to\infty}\left(\dfrac{1}{\sqrt{n^2+1}}+\dfrac{1}{\sqrt{n^2+2}}+\cdots+\dfrac{1}{\sqrt{n^2+n}}\right)$。
查看答案
解：括号内共 $n$ 项。分母越大分数越小，故 $\dfrac{n}{\sqrt{n^2+n}}\le S_n\le\dfrac{n}{\sqrt{n^2+1}}$。两端极限均为 $\displaystyle\lim_{n\to\infty}\dfrac{n}{n\sqrt{1+1/n}}=1$，由夹逼定理 $S_n\to 1$。
练习 35：证明方程 $x^5-3x=1$ 在区间 $(1,2)$ 内至少有一个实根。
查看答案
解：令 $g(x)=x^5-3x-1$，它在 $[1,2]$ 上连续。$g(1)=1-3-1=-3<0$，$g(2)=32-6-1=25>0$。由零点存在定理，至少存在一点 $\xi\in(1,2)$ 使 $g(\xi)=0$，即方程在 $(1,2)$ 内至少有一个实根。
练习 36：求函数 $f(x)=\dfrac{x}{\sin x}$ 的全部间断点并判断类型。
查看答案
解：$\sin x=0\Rightarrow x=k\pi$（$k\in\mathbb{Z}$）。在 $x=0$ 处 $\lim_{x\to 0}\dfrac{x}{\sin x}=1$，为可去间断点（补充定义 $f(0)=1$ 即连续）；在 $x=k\pi$（$k\ne 0$）处 $|f(x)|\to\infty$，为无穷间断点（第二类）。
练习 37：设 $x_1=1$，$x_{n+1}=\dfrac{1}{2}\left(x_n+\dfrac{2}{x_n}\right)$。证明数列收敛并求其极限。
查看答案
解：显然 $x_n>0$。由均值不等式 $x_{n+1}\ge\sqrt{x_n\cdot\dfrac{2}{x_n}}=\sqrt2$（$n\ge 2$），故有下界 $\sqrt2$；又 $x_{n+1}-x_n=\dfrac{2-x_n^2}{2x_n}\le 0$（因 $x_n\ge\sqrt2$），数列单调递减。由单调有界定理收敛，设极限为 $L$，则 $L=\dfrac12\left(L+\dfrac{2}{L}\right)$，解得 $L^2=2$，取正根 $L=\sqrt2$。
