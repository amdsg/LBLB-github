1. 基本概念与解的存在唯一性 方程的分类是解题第一步

定义（常微分方程）：含有未知函数及其导数的方程。阶数 = 最高阶导数的阶数。n 阶方程通解含 n 个任意常数；初值条件确定这些常数得特解。
定理（解的存在唯一性定理——皮卡）：y′ = f(x,y) 中 f 与 ∂f/∂y 在 (x₀,y₀) 附近连续，则初值问题在 x₀ 附近有唯一解。
证明要点：转化为积分方程 y(x) = y₀ + $\int f(t, y(t))\,dt$，用皮卡迭代 + 压缩映射（完备度量空间的不动点定理）。
易错警示：y′ = √y 过 (0,0) 有无穷多解（y = 0 与 y = (x/2)² 都满足）——因为 √y 在 0 处不可导，唯一性条件不满足。解方程时若除零会丢解。

1b. 微分方程的几何意义与解的结构 方向场、通解与初值

定义（微分方程的阶与解）：含未知函数 $y(x)$ 及其导数 $y',y'',\cdots,y^{(n)}$ 的方程 $F(x,y,y',\cdots,y^{(n)})=0$ 称常微分方程。最高阶导数 $n$ 称方程的阶。使方程成为恒等式的函数称解；含 $n$ 个独立任意常数的解称通解；由初值条件 $y(x_0)=y_0,\ y'(x_0)=y_1,\cdots$ 确定常数后的解称特解。
几何意义：$y'=f(x,y)$ 在每点 $(x,y)$ 给出一个斜率 $f(x,y)$，全体构成方向场。积分曲线是处处与方向场相切的曲线族；初值条件 $(x_0,y_0)$ 从曲线族中选出一条。
定理（一阶方程解的存在唯一性——皮卡）：若 $f(x,y)$ 与 $f_y(x,y)$ 在闭矩形域 $R=\{|x-x_0|\leq a,|y-y_0|\leq b\}$ 上连续，则初值问题 $$y'=f(x,y),\quad y(x_0)=y_0$$ 在 $|x-x_0|\leq h$（$h=\min(a,b/M)$，$M=\max_R|f|$）内存在唯一解。
证明思路（皮卡逐步逼近）：将方程化为等价积分方程 $y(x)=y_0+\int_{x_0}^{x}f(t,y(t))dt$，构造迭代序列 $y_0(x)\equiv y_0$、$y_{n+1}(x)=y_0+\int_{x_0}^{x}f(t,y_n(t))dt$，证明 $\{y_n\}$ 一致收敛到唯一不动点。这是压缩映射原理的经典应用。
警示：若 $f_y$ 不连续，唯一性可能失效。典型反例 $y'=\sqrt y$ 过 $(0,0)$ 有无穷多解：$y\equiv0$ 与 $y=x^2/4$ 均满足。解方程时两边除以含 $y$ 的因子要检查 $y\equiv0$ 是否丢解。
例 1b-1：验证 $y=Cx^3$ 是 $x y'=3y$ 的通解，并求满足 $y(1)=2$ 的特解。
查看解析
解析：$y'=3Cx^2$，$xy'=3Cx^3=3y$ ✓。$y(1)=C=2$，特解 $y=2x^3$。
例 1b-2：指出 $(y')^2+xy'+y=0$ 的阶数，并说明它是一阶方程。
查看解析
解析：最高阶为 $y'$，一阶。注意 $(y')^2$ 是一阶导数的平方，阶数仍为 1。
例 1b-3：验证 $y=C_1 e^x+C_2 e^{-x}$ 是 $y''-y=0$ 的通解。
查看解析
解析：$y'=C_1e^x-C_2e^{-x}$，$y''=C_1e^x+C_2e^{-x}=y$，故 $y''-y=0$。含两个独立常数，二阶方程，为通解。

2. 可分离变量与齐次方程 把变量分到两边

定理（可分离变量方程）：dy/dx = g(x)h(y) ⟹ ∫dy/h(y) = $\int g(x)\,dx$。
例：dy/dx = xy ⟹ ∫dy/y = $\int x \,dx$ ⟹ ln|y| = x²/2 + C ⟹ y = C $e^{x^{2}/2}$。
定理（齐次方程）：dy/dx = f(y/x)：令 u = y/x（即 y = ux），化为可分离变量：u + x du/dx = f(u)。
例：dy/dx = (x+y)/(x−y)：令 u = y/x，u + xu′ = (1+u)/(1−u)，分离后解出 u 再代回。
例：求 dy/dx = 2xy 满足 y(0) = 1 的特解。
查看答案
答案：y = C $e^{x^{2}}$，由 y(0) = C = 1 ⟹ y = $e^{x^{2}}$。

2b. 可化为变量可分离的方程 齐次与可化为齐次

定理（可分离变量方程的标准解法）：对 $\dfrac{dy}{dx}=g(x)h(y)$，分离变量得 $$\int\frac{dy}{h(y)}=\int g(x)\,dx.$$
注意：分离时 $h(y)\neq0$，要单独检查 $h(y)=0$ 的根是否为奇解（常数列解）。积分后得到隐式通解，必要时解出 $y$。
定理（齐次方程 $dy/dx=f(y/x)$）：令 $u=y/x$（即 $y=ux$），则 $dy/dx=u+x\,du/dx$，代入得 $u+x\,du/dx=f(u)$，分离变量： $$\frac{du}{f(u)-u}=\frac{dx}{x}.$$ 积分后回代 $u=y/x$。
推导：$y=ux$，两边对 $x$ 求导 $y'=u'x+u$，而原方程 $y'=f(u)$，故 $u'x=f(u)-u$。
定理（可化为齐次的方程）：对 $\dfrac{dy}{dx}=f\!\left(\dfrac{a_1x+b_1y+c_1}{a_2x+b_2y+c_2}\right)$，若行列式 $\Delta=\begin{vmatrix}a_1&b_1\\a_2&b_2\end{vmatrix}\neq0$，解方程组 $\begin{cases}a_1h+b_1k+c_1=0\\a_2h+b_2k+c_2=0\end{cases}$ 得 $(h,k)$，令 $X=x+h,\ Y=y+k$ 化为齐次；若 $\Delta=0$，令 $v=a_1x+b_1y$ 直接分离。
例 2b-1：解 $\dfrac{dy}{dx}=\dfrac{y}{\sqrt{x^2+1}}$。
查看解析
解析：分离 $dy/y=dx/\sqrt{x^2+1}$，积分 $\ln|y|=\ln|x+\sqrt{x^2+1}|+C$，即 $y=C(x+\sqrt{x^2+1})$。
例 2b-2：解 $\dfrac{dy}{dx}=\dfrac{y+x}{x-y}$（齐次）。
查看解析
解析：令 $u=y/x$，$u+xu'=\frac{1+u}{1-u}$，$xu'=\frac{1+u^2}{1-u}$，分离 $\frac{1-u}{1+u^2}du=\frac{dx}{x}$，积分 $\arctan u-\frac12\ln(1+u^2)=\ln|x|+C$，代回 $u=y/x$。
例 2b-3：解初值问题 $y'=\frac{y}{x},\ y(1)=2$。
查看解析
解析：齐次：$u+xu'=u\Rightarrow xu'=0$，$u=C$，$y=Cx$。$y(1)=C=2$，特解 $y=2x$。
例 2b-4：解 $y'=\frac{x-y+1}{x+y-3}$。
查看解析
解析：解 $\begin{cases}h-k+1=0\\h+k-3=0\end{cases}$ 得 $h=1,k=2$。令 $X=x-1,Y=y-2$，方程化为 $Y'=\frac{X-Y}{X+Y}$，齐次方程，再令 $u=Y/X$ 求解。
例 2b-5：求曲线族 $y=Cx^2$ 满足的微分方程。
查看解析
解析：消去 $C$：$y'=2Cx$，而 $C=y/x^2$，故 $y'=2y/x$，即 $xy'=2y$。

3. 一阶线性方程与伯努利方程 积分因子法

定理（一阶线性方程）：y′ + P(x)y = Q(x)。通解公式：y = $e^{-\int Pdx}$ [∫Q $e^{\int Pdx}$ dx + C]。
证明要点（积分因子）：乘 $e^{\int Pdx}$ 后左边 = [y $e^{\int Pdx}$]′，直接积分。解 = 齐次通解 + 非齐次特解。
定理（伯努利方程）：y′ + P(x)y = Q(x)yⁿ（n ≠ 0, 1）：令 z = $y^{1-n}$，化为 z′ + (1−n)Pz = (1−n)Q 线性方程。
证明要点：两边乘 $y^{-n}$：$y^{-n}$y′ + $Py^{1-n}$ = Q，而 ($y^{1-n}$)′ = (1−n)$y^{-n}$y′。
例：解 y′ + y = eˣ。
查看答案
答案：P = 1，积分因子 eˣ：[y eˣ]′ = e²ˣ ⟹ y eˣ = e²ˣ/2 + C ⟹ y = eˣ/2 + C $e^{-x}$。
例：解 y′ + y/x = y²（伯努利）。
查看答案
答案：令 z = y⁻¹：z′ − z/x = −1，线性方程：z = $e^{\int dx/x}$[∫(−1)$e^{-\int dx/x}$dx + C] = x(−ln x + C)，故 y = 1/[x(C − ln x)]。

3b. 一阶线性方程与伯努利方程深入 积分因子法的系统化

定理（一阶线性方程通解公式——正式推导）：方程 $y'+P(x)y=Q(x)$。 ① 齐次情形 $Q=0$：$dy/y=-Pdx$，得 $y=C\,e^{-\int P\,dx}$。 ② 非齐次情形：用积分因子 $\mu(x)=e^{\int P\,dx}$ 乘方程两边： $$e^{\int Pdx}y'+P e^{\int Pdx}y=Q e^{\int Pdx}\quad\Longleftrightarrow\quad\frac{d}{dx}\!\left(y e^{\int Pdx}\right)=Q e^{\int Pdx}.$$ 积分得 $y e^{\int Pdx}=\int Q e^{\int Pdx}dx+C$，即 $$y=e^{-\int Pdx}\!\left[\int Q(x)e^{\int Pdx}dx+C\right].$$
结构意义：通解 = 对应齐次通解 $Ce^{-\int Pdx}$ + 非齐次特解 $e^{-\int Pdx}\int Qe^{\int Pdx}dx$。
定理（伯努利方程）：$y'+P(x)y=Q(x)y^n$（$n\neq0,1$）。两边除以 $y^n$，令 $z=y^{1-n}$，则 $z'=(1-n)y^{-n}y'$，代入： $$\frac{1}{1-n}z'+Pz=Q\quad\Longleftrightarrow\quad z'+(1-n)Pz=(1-n)Q,$$ 化为一阶线性方程。
注意：$n=0$ 时已是线性方程；$n=1$ 时为可分离变量 $y'/y=Q-P$。
例 3b-1：解 $y'-\dfrac{2y}{x+1}=(x+1)^{5/2}$。
查看解析
解析：$P=-2/(x+1)$，$\mu=e^{\int -2/(x+1)dx}=(x+1)^{-2}$。乘之：$(y(x+1)^{-2})'=(x+1)^{1/2}$，积分 $y(x+1)^{-2}=\frac23(x+1)^{3/2}+C$，$y=(x+1)^2[\frac23(x+1)^{3/2}+C]$。
例 3b-2：解 $y'=\dfrac{1}{x+y}$（注意把 $x$ 当函数）。
查看解析
解析：改写为 $dx/dy=x+y$，即 $x'-x=y$，$P=-1$，$\mu=e^{-y}$，$(xe^{-y})'=ye^{-y}$，积分 $xe^{-y}=-(y+1)e^{-y}+C$，$x=Ce^y-y-1$。
例 3b-3：解伯努利方程 $y'-y=xy^2$。
查看解析
解析：$n=2$，令 $z=y^{-1}$，$z'+z=-x$。$\mu=e^x$，$(ze^x)'=-xe^x$，积分 $ze^x=-(x-1)e^x+C$，$z=Ce^{-x}-x+1$，$y=1/(Ce^{-x}-x+1)$。
例 3b-4：求 $y'=\dfrac{y}{2x-y}$ 的通解。
查看解析
解析：视为 $dx/dy=2x/y-1$，即 $x'-2x/y=-1$，$P=-2/y$，$\mu=y^{-2}$，$(xy^{-2})'=-y^{-2}$，积分 $xy^{-2}=1/y+C$，$x=y+Cy^2$。
例 3b-5：解初值问题 $xy'+y=e^x,\ y(1)=e$。
查看解析
解析：$(xy)'=e^x$，$xy=e^x+C$，$y=(e^x+C)/x$。$y(1)=e+C=e\Rightarrow C=0$，$y=e^x/x$。

4. 全微分方程 凑成某个函数的全微分

定义：P(x,y)dx + Q(x,y)dy = 0 若存在 F 使 dF = P dx + Q dy（即 Fₓ = P、Fᵧ = Q），称为全微分方程，通解 F(x,y) = C。
定理（全微分判别与求解）：P、Q 有连续偏导时，方程为全微分方程 ⟺ ∂P/∂y = ∂Q/∂x。求解：F = $\int P \,dx$ + φ(y)（把 φ 由 Fᵧ = Q 定出），或沿折线路径积分。
证明要点：Fₓᵧ = Fᵧₓ 即 Pᵧ = Qₓ——混合偏导相等的必要条件。
定理（积分因子）：非全微分方程有时可乘积分因子 μ(x,y) 化为全微分方程。若 (Pᵧ − Qₓ)/Q 只与 x 有关，则 μ = $e^{\int (Pᵧ-Q_{x})/Q dx}$；若 (Qₓ − Pᵧ)/P 只与 y 有关，则 μ = $e^{\int (Q_{x}-Pᵧ)/P dy}$。
例：y dx + x dy = 0 不是全微分（Pᵧ = 1 ≠ Qₓ = 1？——此处 Pᵧ = 1、Qₓ = 1 相等，实际是全微分：d(xy) = 0）。选例子：(x+y)dx + x dy = 0：Pᵧ = 1、Qₓ = 1，是全微分，F = x²/2 + xy。
例：解 (2x+y)dx + (x+2y)dy = 0。
查看答案
答案：Pᵧ = 1 = Qₓ ✓。F = $\int (2x+y)\,dx$ = x² + xy + φ(y)，Fᵧ = x + φ′(y) = x + 2y ⟹ φ′ = 2y ⟹ φ = y²。通解 x² + xy + y² = C。

4b. 全微分方程与积分因子 凑微分法

定理（全微分方程的充要条件）：设 $P(x,y),Q(x,y)$ 在单连通域 $D$ 内有连续一阶偏导，则 $Pdx+Qdy=0$ 为全微分方程 $\iff$ $\dfrac{\partial P}{\partial y}=\dfrac{\partial Q}{\partial x}$ 在 $D$ 内恒成立。
证明：若 $dF=Pdx+Qdy$，则 $F_x=P,F_y=Q$，由混合偏导连续 $P_y=F_{xy}=F_{yx}=Q_x$。反之，由曲线积分与路径无关，$F(x,y)=\int_{(x_0,y_0)}^{(x,y)}Pdx+Qdy$ 满足 $dF=Pdx+Qdy$。
定理（观察法求原函数）：利用常见全微分公式"凑"原函数 $F$： $x dy+y dx=d(xy)$；$\frac{x dy-y dx}{x^2}=d\!\left(\frac{y}{x}\right)$；$\frac{x dy-y dx}{x^2+y^2}=d\!\left(\arctan\frac{y}{x}\right)$；$\frac{x dx+y dy}{x^2+y^2}=\frac12 d\ln(x^2+y^2)$。
要点：把方程重新分组，使每组是某个已知函数的微分，凑成 $dF=0$，即 $F=C$。
定理（特殊积分因子）：若 $\dfrac{1}{Q}\!\left(\dfrac{\partial P}{\partial y}-\dfrac{\partial Q}{\partial x}\right)=\varphi(x)$ 仅为 $x$ 的函数，则积分因子 $\mu(x)=e^{\int\varphi(x)dx}$；若 $\dfrac{1}{P}\!\left(\dfrac{\partial Q}{\partial x}-\dfrac{\partial P}{\partial y}\right)=\psi(y)$ 仅为 $y$ 的函数，则 $\mu(y)=e^{\int\psi(y)dy}$。
证明：乘 $\mu$ 后要求 $(\mu P)_y=(\mu Q)_x$，展开 $\mu_y P+\mu P_y=\mu_x Q+\mu Q_x$。若 $\mu=\mu(x)$，$\mu_y=0$，得 $\mu' Q=\mu(P_y-Q_x)$，即 $\mu'/\mu=(P_y-Q_x)/Q$。
例 4b-1：解 $(x^3-3xy^2)dx+(y^3-3x^2y)dy=0$。
查看解析
解析：$P_y=-6xy=Q_x$ ✓。分项凑：$x^3dx+y^3dy-3xy(ydx+xdy)=0$，即 $d\!\left(\frac{x^4}{4}+\frac{y^4}{4}-\frac{3x^2y^2}{2}\right)=0$，通解 $x^4+y^4-6x^2y^2=C$。
例 4b-2：解 $(x+y)dx+(x-y)dy=0$。
查看解析
解析：$P_y=1=Q_x$ ✓。$F=\int(x+y)dx=\frac{x^2}{2}+xy+\varphi(y)$，$F_y=x+\varphi'=x-y$，$\varphi=-y^2/2$。通解 $x^2/2+xy-y^2/2=C$。
例 4b-3：求积分因子并解 $y dx-x dy=0$。
查看解析
解析：$P_y=1,Q_x=-1$，$P_y-Q_x=2$，$(P_y-Q_x)/P=2/y$ 仅与 $y$ 有关，$\mu=y^{-2}$。乘之：$(y dx-x dy)/y^2=0$，即 $d(x/y)=0$，$x/y=C$。
例 4b-4：解 $(2xy^2-y)dx+(y^2+x+y)dy=0$。
查看解析
解析：$P_y=4xy-1$，$Q_x=1$，$P_y-Q_x=4xy-2$。$(P_y-Q_x)/Q=(4xy-2)/(y^2+x+y)$ 不单一变量，分组凑：$2xy^2dx+y^2dy+(y-x)dy=0$，试 $\mu=1/y$：$2xy dx+y dy+(1-x/y)dy=0$，$d(x^2y)+d(y^2/2)+d(y-x\ln|y|)=0$。

5. 可降阶的高阶方程 三种降阶套路

定理（不显含 y 型）：y″ = f(x, y′)：令 p = y′，化为 p′ = f(x, p) 一阶方程。
例：y″ = 2x：p′ = 2x ⟹ p = x² + C₁ ⟹ y = x³/3 + C₁x + C₂。
定理（不显含 x 型）：y″ = f(y, y′)：令 p = y′，把 y 当自变量：y″ = p dp/dy，化为 p dp/dy = f(y, p)。
例：y″ = (y′)²：p dp/dy = p² ⟹ dp/p = dy ⟹ p = C₁eʸ ⟹ dy/dx = C₁eʸ ⟹ $e^{-y}$dy = C₁dx ⟹ y = −ln(C₂ − C₁x)。
例：解 y″ = y′ + x。
查看答案
答案：p′ = p + x ⟹ p′ − p = x ⟹ p = eˣ[∫x $e^{-x}$dx + C₁] = −x − 1 + C₁eˣ ⟹ y = −x²/2 − x + C₁eˣ + C₂。

5b. 可降阶高阶方程的三种类型 系统对比

类型换元降阶后方程
$y^{(n)}=f(x)$逐次积分积分 $n$ 次得通解
$y''=f(x,y')$（缺 $y$）令 $p=y'$，$p'=y''$$p'=f(x,p)$ 一阶方程
$y''=f(y,y')$（缺 $x$）令 $p=y'$，$y''=p\,dp/dy$$p\,dp/dy=f(y,p)$，$y$ 为自变量
定理（为什么缺 $x$ 型要用 $y''=p\,dp/dy$）：当方程不显含 $x$ 时，把 $p=y'$ 视为 $y$ 的函数 $p=p(y)$，则 $y''=\dfrac{dp}{dx}=\dfrac{dp}{dy}\cdot\dfrac{dy}{dx}=p\,\dfrac{dp}{dy}$，于是方程化为关于 $p(y)$ 的一阶方程。
易错点：缺 $x$ 型若仍用 $p'=y''$ 会出现三个变量 $x,y,p$，必须换用 $y$ 作自变量。
例 5b-1：解 $y''=x+\sin x$。
查看解析
解析：逐次积分：$y'=x^2/2-\cos x+C_1$，$y=x^3/6-\sin x+C_1x+C_2$。
例 5b-2：解 $y''=1+(y')^2$。
查看解析
解析：缺 $y$，令 $p=y'$：$p'=1+p^2$，$dp/(1+p^2)=dx$，$\arctan p=x+C_1$，$p=\tan(x+C_1)$，$y=-\ln|\cos(x+C_1)|+C_2$。
例 5b-3：解 $y y''-(y')^2=0$。
查看解析
解析：缺 $x$，令 $p=y'$，$y''=p dp/dy$：$yp dp/dy=p^2$。$p=0$ 得 $y=C$；$p\neq0$ 时 $dp/p=dy/y$，$p=C_1y$，$dy/dx=C_1y$，$y=C_2e^{C_1x}$。
例 5b-4：解初值问题 $y''=e^y,\ y(0)=0,\ y'(0)=0$。
查看解析
解析：缺 $x$，$p dp/dy=e^y$，$\frac12p^2=e^y+C_1$。初值 $p(0)=0,y(0)=0$ 得 $C_1=-1$，$p^2=2(e^y-1)$，$dy/dx=\sqrt{2(e^y-1)}$，$dx=dy/\sqrt{2(e^y-1)}$，积分得 $x=\ln(\sqrt{e^y}-1)-\ln(\sqrt{e^y}+1)+C_2$，$C_2=0$。

查看解析

6. 二阶线性方程解的结构 叠加原理

定义：y″ + P(x)y′ + Q(x)y = f(x)：f = 0 齐次、f ≠ 0 非齐次。
定理（齐次解的结构）：y₁、y₂ 是齐次方程的两个线性无关解（y₁/y₂ 非常数），则通解 y = C₁y₁ + C₂y₂。
证明要点：解空间是二维线性空间（由初值 y(x₀)、y′(x₀) 两组独立条件 + 唯一性）。
定理（非齐次解的结构）：非齐次方程通解 = 对应齐次方程通解 + 非齐次特解。
证明要点：两个非齐次解之差满足齐次方程。
定理（常数变易法）：设 y = u₁(x)y₁ + u₂(x)y₂，令 u₁′y₁ + u₂′y₂ = 0，则 u₁′y₁′ + u₂′y₂′ = f，解出 u₁′、u₂′ 后积分。
例：y″ + y = tan x：y₁ = cos x、y₂ = sin x，u₁′ = −sin x tan x、u₂′ = cos x tan x，积分得特解。

6b. 朗斯基行列式与线性解的结构 理论基础

定义（朗斯基行列式 Wronskian）：对 $n$ 个可导函数 $y_1,\cdots,y_n$，定义 $$W(y_1,\cdots,y_n)(x)=\begin{vmatrix}y_1&y_2&\cdots&y_n\\ y_1'&y_2'&\cdots&y_n'\\ \vdots&&&\vdots\\ y_1^{(n-1)}&\cdots&&y_n^{(n-1)}\end{vmatrix}.$$
意义：对二阶齐次线性方程 $y''+Py'+Qy=0$ 的两个解 $y_1,y_2$，$W\equiv0\iff y_1,y_2$ 线性相关（$y_1/y_2\equiv$ 常数）；$W\neq0\iff$ 线性无关。
定理（刘维尔公式）：对二阶齐次线性方程，$W(x)=W(x_0)e^{-\int_{x_0}^{x}P(t)dt}$。
推论：只要在一点 $W(x_0)\neq0$，则在整个区间 $W(x)\neq0$；$W$ 要么恒为 0 要么处处不为 0。
定理（二阶线性非齐次解的结构——正式陈述）：设 $y_1,y_2$ 是 $y''+P(x)y'+Q(x)y=0$ 的两个线性无关解，$y^*$ 是非齐次方程 $y''+P(x)y'+Q(x)y=f(x)$ 的一个特解，则非齐次通解为 $$y=C_1y_1+C_2y_2+y^*.$$
证明：① 叠加原理：$C_1y_1+C_2y_2$ 满足齐次方程；② 两非齐次解之差满足齐次方程，故任一非齐次解 $y$ 满足 $y-y^*\in$ 齐次解空间，即 $y-y^*=C_1y_1+C_2y_2$。
定理（解的叠加原理——右端可加）：若 $y_1^*$ 是 $L[y]=f_1$ 的特解、$y_2^*$ 是 $L[y]=f_2$ 的特解，则 $y_1^*+y_2^*$ 是 $L[y]=f_1+f_2$ 的特解。
例 6b-1：验证 $y_1=e^x,\ y_2=e^{2x}$ 是 $y''-3y'+2y=0$ 的线性无关解。
查看解析
解析：$W=\begin{vmatrix}e^x&e^{2x}\\e^x&2e^{2x}\end{vmatrix}=e^{3x}\neq0$，线性无关。
例 6b-2：已知 $y_1=x,\ y_2=x^2$ 是齐次方程的解，验证线性无关。
查看解析
解析：$W=\begin{vmatrix}x&x^2\\1&2x\end{vmatrix}=2x^2-x^2=x^2$，在 $x\neq0$ 时 $W\neq0$，线性无关（$y_1/y_2=1/x$ 非常数）。
例 6b-3：已知 $y''+y=\sec x$，对应齐次通解 $C_1\cos x+C_2\sin x$，用常数变易法求特解。
查看解析
解析：设 $y^*=u_1\cos x+u_2\sin x$，$W=\cos^2x+\sin^2x=1$。$u_1'=-\sin x\sec x=-\tan x$，$u_2'=\cos x\sec x=1$。积分 $u_1=\ln|\cos x|$，$u_2=x$。$y^*=\cos x\ln|\cos x|+x\sin x$。

7b. 特征方程法与欧拉方程 系统求解

定理（二阶常系数齐次方程通解总表）：对 $y''+py'+qy=0$，特征方程 $r^2+pr+q=0$：
判别式 $\Delta=p^2-4q$特征根通解
$\Delta>0$两不同实根 $r_1,r_2$$y=C_1e^{r_1x}+C_2e^{r_2x}$
$\Delta=0$重根 $r$$y=(C_1+C_2x)e^{rx}$
$\Delta<0$共轭复根 $\alpha\pm i\beta$$y=e^{\alpha x}(C_1\cos\beta x+C_2\sin\beta x)$
重根时 $xe^{rx}$ 为何是解：对 $y=e^{rx}$ 已得解，用降阶法（刘维尔公式）求第二个线性无关解 $y_2=y_1\int e^{-\int pdx}/y_1^2\,dx=e^{rx}\int e^{-px}/e^{2rx}dx$。重根时 $r=-p/2$，指数相消，$\int dx=x$，得 $y_2=xe^{rx}$。
定理（$n$ 阶常系数齐次方程）：$y^{(n)}+a_1y^{(n-1)}+\cdots+a_ny=0$，特征方程 $r^n+a_1r^{n-1}+\cdots+a_n=0$。每个 $k$ 重实根 $r$ 对应 $k$ 个解 $e^{rx},xe^{rx},\cdots,x^{k-1}e^{rx}$；每个 $k$ 重共轭复根 $\alpha\pm i\beta$ 对应 $2k$ 个解 $e^{\alpha x}\cos\beta x,xe^{\alpha x}\cos\beta x,\cdots,x^{k-1}e^{\alpha x}\cos\beta x$ 及正弦项。
定理（欧拉方程）：$x^2y''+pxy'+qy=0$（$x>0$）。令 $x=e^t$（$t=\ln x$），记 $D=d/dt$，则 $xD=D$、$x^2D^2=D(D-1)$，代入化为常系数方程 $$D(D-1)y+pDy+qy=0,\quad\text{即}\quad y_t''+(p-1)y_t'+qy=0.$$
推导：$dy/dx=(dy/dt)(dt/dx)=\frac1x dy/dt$，$x y'=Dy$。$y''=\frac{d}{dx}(Dy/x)=\frac1x\frac{d}{dt}(Dy/x)=\frac1{x^2}(D^2y-Dy)$，故 $x^2y''=D(D-1)y$。
例 7b-1：解 $y''+4y'+13y=0$。
查看解析
解析：$r^2+4r+13=0$，$r=-2\pm3i$，通解 $y=e^{-2x}(C_1\cos3x+C_2\sin3x)$。
例 7b-2：解 $y^{(3)}-3y''+3y'-y=0$。
查看解析
解析：$(r-1)^3=0$，三重根 $r=1$，通解 $y=(C_1+C_2x+C_3x^2)e^x$。

查看解析
解析：令 $x=e^t$：$D(D-1)y+Dy+y=0$，$D^2y+y=0$，$y=C_1\cos t+C_2\sin t$，回代 $t=\ln x$：$y=C_1\cos(\ln x)+C_2\sin(\ln x)$。

8. 二阶常系数非齐次方程 待定系数法

定理（f = $e^{λx}$Pₘ(x) 型）：y″ + py′ + qy = $e^{λx}$Pₘ(x)：设特解 y* = xᵏ $e^{λx}$ Qₘ(x)，其中 k 是 λ 作为特征根的重数（0、1 或 2）。

定理（叠加原理）：f = f₁ + f₂ 时特解 = 分别的特解之和。

8b. 待定系数法的两种标准类型 系统掌握

定理（类型 I：$f(x)=e^{\lambda x}P_m(x)$）：设 $\lambda$ 是特征方程 $\varphi(r)=r^2+pr+q=0$ 的 $k$ 重根（$k=0,1,2$），则非齐次方程 $y''+py'+qy=e^{\lambda x}P_m(x)$ 有形如 $$y^*=x^k e^{\lambda x} Q_m(x)$$ 的特解，其中 $Q_m(x)$ 是与 $P_m(x)$ 同次（$m$ 次）的待定多项式。
推导：设 $y^*=e^{\lambda x}Q(x)$，代入方程得 $e^{\lambda x}[Q''+(2\lambda+p)Q'+(\lambda^2+p\lambda+q)Q]=e^{\lambda x}P_m$，即 $\varphi(\lambda)Q+\varphi'(\lambda)Q'+Q''=P_m$。若 $\varphi(\lambda)\neq0$（$k=0$）取 $Q=Q_m$；若 $\varphi(\lambda)=0,\varphi'(\lambda)\neq0$（$k=1$）取 $Q=xQ_m$；若均为 0（$k=2$）取 $Q=x^2Q_m$。
定理（类型 II：$f(x)=e^{\alpha x}[P_l(x)\cos\beta x+Q_n(x)\sin\beta x]$）：设 $\alpha+i\beta$ 是特征方程的 $k$ 重根，令 $m=\max(l,n)$，则特解形如 $$y^*=x^k e^{\alpha x}[R_m^{(1)}(x)\cos\beta x+R_m^{(2)}(x)\sin\beta x].$$
说明：用欧拉公式把三角函数化为复指数 $e^{(\alpha+i\beta)x}$，套用类型 I，再取实部/虚部合并。
右端 $f(x)$$k$ 的取法特解形式
$e^{\lambda x}P_m(x)$$\lambda$ 是特征根重数$x^k e^{\lambda x}Q_m(x)$
$e^{\alpha x}\cos\beta x$$\alpha+i\beta$ 是否特征根$x^k e^{\alpha x}(A\cos\beta x+B\sin\beta x)$
$e^{\alpha x}\sin\beta x$同上同上
$P_m(x)$（即 $\lambda=0$）0 是否特征根$x^k Q_m(x)$
易错警示：① $k$ 是"重数"——单根 $k=1$、二重根 $k=2$；② 类型 II 中即使 $f$ 只含余弦，特解也要同时设 $A\cos\beta x+B\sin\beta x$（不能只设一个）；③ 右端是两项之和时分别求特解再相加。

解析：特征根 $r=3,-1$，齐次通解 $C_1e^{3x}+C_2e^{-x}$。$\lambda=0$ 非特征根，设 $y^*=ax+b$。代入 $-3ax-2a-3b=3x+1$：$a=-1,\ b=1/3$。$y^*=-x+1/3$。

9e. 深度：稳定性理论初步 解会不会「跑掉」

定义（Lyapunov 稳定） $\dot x=f(x)$ 的平衡点 $x^*$ 稳定，若 $\forall\epsilon>0,\exists\delta>0$ 使 $|x_0-x^*|<\delta\Rightarrow|\phi_t(x_0)-x^*|<\epsilon$（$\forall t\ge0$）。渐近稳定还要求 $\phi_t(x_0)\to x^*$。
定理（线性化判据） 设 $f\in C^1$, $x^*$ 为平衡点。$A=Df(x^*)$。 ① $A$ 所有特征值实部 $<0$ $\Rightarrow$ $x^*$ 渐近稳定； ② $A$ 有特征值实部 $>0$ $\Rightarrow$ $x^*$ 不稳定； ③ $A$ 有纯虚特征值且无正实部 $\Rightarrow$ 线性化无法判断（临界情形）。
思路：解 $\approx e^{At}(x_0-x^*)$，$e^{At}$ 衰减 $\Leftrightarrow$ 特征值实部负。严格证明用 Gronwall 不等式控制非线性项 $O(|x-x^*|^2)$。
定理（Lyapunov 函数法） 若存在 $V$ 在 $x^*$ 正定、$\dot V=\nabla V\cdot f$ 负定，则 $x^*$ 渐近稳定。
意义：临界情形（线性化失效）用 $V$ 判断。阻尼摆 $\ddot\theta+\sin\theta+\gamma\dot\theta=0$，取 $V=\frac12\dot\theta^2+1-\cos\theta$，$\dot V=-\gamma\dot\theta^2\le0$——稳定（非严格负定，用 LaSalle 不变性原理进一步得渐近稳定）。
例：判断 $\dot x=x(1-x)$ 的平衡点稳定性。
解：平衡点 $x^*=0$ 与 $x^*=1$。在 $x^*=0$：$f'(0)=1>0$——不稳定。在 $x^*=1$：$f'(1)=-1<0$——渐近稳定。解 $x(t)=\frac{x_0e^t}{1-x_0+x_0e^t}$ 验证：$x_0<1$ 时 $x\to1$；$x_0>1$ 也 $\to1$；$x_0=0$ 留在 0（不稳定平衡）。Logistic 增长模型。

9f. 深度：边值问题与 Sturm–Liouville 理论 从初值到边值

定义（边值问题） 二阶 ODE $y''+p(x)y'+q(x)y=\lambda r(x)y$ 配边界 $y(a)=y(b)=0$（或导数边界）。与初值不同，边值问题可能无解或多解。
定理（Sturm–Liouville） SL 方程 $(py')'+qy+\lambda ry=0$（$p>0,r>0$）配适当边界有： ① 特征值 $\lambda_1<\lambda_2<\cdots\to+\infty$ 全实； ② 特征函数 $\{y_n\}$ 关于权 $r$ 正交：$\int_a^b r\,y_my_n=0$（$m\ne n$）； ③ $\{y_n\}$ 在 $L^2_r$ 中完备。
思路：SL 算子 $L=-(py')'/r$ 自伴（$\int uLv=\int vLu$），自伴算子特征值实、特征函数正交。完备性需要紧自伴算子谱分解（Hilbert 的梦想之一）。
定理（振动比较定理 Sturm） 若 $q_1(x)\le q_2(x)$，$y_1''+q_1y_1=0$ 的解 $y_1$ 的相邻零点间至少有 $y_2''+q_2y_2=0$ 的解的一个零点。
意义：「$q$ 越大振荡越快」——这给出特征值排序 $\lambda_n\uparrow$ 的几何直觉。$q=\lambda$（常数）时 $\sqrt\lambda$ 越大频率越高，零点越密。
例：求 $y''+\lambda y=0$, $y(0)=y(\pi)=0$ 的特征值与特征函数。
解：通解 $y=A\sin(\sqrt\lambda x)+B\cos(\sqrt\lambda x)$。$y(0)=0$ 给 $B=0$。$y(\pi)=A\sin(\sqrt\lambda\pi)=0$ 给 $\sqrt\lambda=n$（$n=1,2,\dots$），即 $\lambda_n=n^2$。特征函数 $y_n=\sin(nx)$。这正是 Fourier 正弦展开的基础——热传导方程分离变量法中出现。

9b. 二阶方程建模：振动与电路 物理背景完整

定理（弹簧振动方程）：质量为 $m$ 的物体挂在弹簧上，受弹力 $-kx$、阻尼 $-cx'$、外力 $F(t)$，由牛顿第二定律： $$m x''+c x'+k x=F(t).$$ ① 无阻尼自由振动 $x''+\omega_0^2x=0$（$\omega_0=\sqrt{k/m}$）：$x=A\cos(\omega_0 t+\varphi)$，周期 $T=2\pi/\omega_0$。 ② 有阻尼自由振动：$c>0$ 时解指数衰减；$c<2\sqrt{mk}$ 欠阻尼振荡衰减，$c=2\sqrt{mk}$ 临界阻尼，$c>2\sqrt{mk}$ 过阻尼非振荡。 ③ 受迫振动：外力 $F(t)=F_0\cos\omega t$，当驱动频率 $\omega=\omega_0$ 时发生共振，振幅随 $t$ 线性增长（$x\propto t\sin\omega_0 t$）。
共振的数学：$x''+\omega_0^2x=F_0\cos\omega_0t$，$\alpha+i\beta=i\omega_0$ 是特征根（单根），特解 $x^*=At\sin\omega_0t$，振幅 $\propto t$。
定理（RLC 串联电路）：由基尔霍夫电压定律 $L q''+R q'+\frac1C q=E(t)$（$q$ 为电容电荷），电流 $i=q'$。令 $i=q'$ 得 $L i''+R i'+\frac1C i=E'(t)$。直流稳态 $E=E_0$ 时 $i\to0$（电容开路）。

9a. 深度：解的存在唯一性定理（Picard 迭代） 为什么常微分方程的解存在且唯一

Picard–Lindelöf 定理 考虑初值问题 $y'=f(x,y)$，$y(x_0)=y_0$。若 $f$ 在矩形 $R:\{|x-x_0|\le a,\ |y-y_0|\le b\}$ 上连续，且关于 $y$ 满足 Lipschitz 条件：$\exists L>0$ 使 $|f(x,y_1)-f(x,y_2)|\le L|y_1-y_2|$，则在 $|x-x_0|\le h$ 上存在唯一解，其中 $h=\min(a,b/M)$，$M=\max_R|f|$。
证明（Picard 迭代）：构造迭代序列 $y_{n+1}(x)=y_0+\int_{x_0}^x f(t,y_n(t))dt$，$y_0(x)\equiv y_0$。用 Lipschitz 条件归纳证明 $|y_{n+1}-y_n|\le\frac{M L^n}{(n+1)!}|x-x_0|^{n+1}$，故 $\sum(y_{n+1}-y_n)$ 一致收敛，极限函数 $y(x)$ 满足积分方程，即微分方程的解。唯一性由 Gronwall 不等式推出。
Gronwall 不等式 若 $u(x)\le C+\int_{x_0}^x\lambda(t)u(t)dt$（$C\ge0$，$\lambda\ge0$），则 $u(x)\le C\exp\left(\int_{x_0}^x\lambda(t)dt\right)$。
例：用 Picard 迭代求 $y'=x+y$，$y(0)=0$ 的前几项。
解：$y_0(x)=0$。$y_1=\int_0^x(t+0)dt=x^2/2$。$y_2=\int_0^x(t+t^2/2)dt=x^2/2+x^3/6$。$y_3=x^2/2+x^3/6+x^4/24$。归纳得 $y_n=\sum_{k=2}^{n+1}\frac{x^k}{k!}$，极限 $y=e^x-x-1$（验证：$y'=e^x-1=x+y$）。

9c. 深度：线性方程组的基本解矩阵 高阶线性方程的矩阵化处理

线性方程组 $\mathbf{y}'=A(x)\mathbf{y}+\mathbf{f}(x)$，其中 $\mathbf{y}=(y_1,\dots,y_n)^T$，$A(x)$ 为 $n\times n$ 矩阵。齐次方程 $\mathbf{y}'=A(x)\mathbf{y}$ 的 $n$ 个线性无关解构成基本解矩阵 $\Phi(x)$。
定理 齐次线性方程组的通解为 $\mathbf{y}=\Phi(x)\mathbf{C}$，$\mathbf{C}\in\mathbb{R}^n$。非齐次通解为 $\mathbf{y}=\Phi(x)\mathbf{C}+\mathbf{y}_p$，其中特解 $\mathbf{y}_p=\Phi(x)\int\Phi^{-1}(x)\mathbf{f}(x)dx$（常数变易法）。
Wronski 行列式 $n$ 个解 $\mathbf{y}_1,\dots,\mathbf{y}_n$ 的 Wronski 行列式 $W(x)=\det[\mathbf{y}_1,\dots,\mathbf{y}_n]$。Liouville 公式：$W(x)=W(x_0)\exp\left(\int_{x_0}^x\mathrm{tr}\,A(t)dt\right)$。
说明：$W(x)$ 要么恒为 0（解线性相关），要么恒不为 0（解线性无关）——这由 Liouville 公式保证，因为指数函数永不为 0。
例：求 $y''+y=0$ 的基本解矩阵。
解：化为方程组：$y_1=y$，$y_2=y'$，则 $\mathbf{y}'=\begin{pmatrix}0&1\\-1&0\end{pmatrix}\mathbf{y}$。两个线性无关解 $\mathbf{y}_1=(\cos x,-\sin x)^T$，$\mathbf{y}_2=(\sin x,\cos x)^T$。基本解矩阵 $\Phi(x)=\begin{pmatrix}\cos x&\sin x\\-\sin x&\cos x\end{pmatrix}$，$W(x)=\cos^2x+\sin^2x=1$。

9d. 深度：稳定性与 Lyapunov 直接方法 不求解也能判断解的行为

定义（Lyapunov 稳定） 自治系统 $\mathbf{x}'=\mathbf{f}(\mathbf{x})$ 的平衡点 $\mathbf{x}_0$（$\mathbf{f}(\mathbf{x}_0)=0$）称为 Lyapunov 稳定，若 $\forall\varepsilon>0,\ \exists\delta>0$，使 $\|\mathbf{x}(0)-\mathbf{x}_0\|<\delta$ 时 $\|\mathbf{x}(t)-\mathbf{x}_0\|<\varepsilon$（$\forall t>0$）。若还满足 $\lim_{t\to\infty}\|\mathbf{x}(t)-\mathbf{x}_0\|=0$，称渐近稳定。
Lyapunov 直接方法 若存在正定函数 $V(\mathbf{x})$（$V(\mathbf{x}_0)=0$，$V(\mathbf{x})>0$ 当 $\mathbf{x}\ne\mathbf{x}_0$）使得 $\dot{V}=\nabla V\cdot\mathbf{f}\le0$，则 $\mathbf{x}_0$ 稳定；若 $\dot{V}<0$（$\mathbf{x}\ne\mathbf{x}_0$），则渐近稳定。
直觉：$V$ 像「能量」。$\dot{V}\le0$ 意味着能量不增，解被「困」在等势面 $V=C$ 内；$\dot{V}<0$ 则能量持续衰减，解最终趋于平衡点。
例：判断 $\ddot{x}+\dot{x}+x=0$ 零解的稳定性。
解：令 $x_1=x$，$x_2=\dot{x}$，方程组 $\dot{x}_1=x_2$，$\dot{x}_2=-x_1-x_2$。取 $V=x_1^2+x_2^2$（正定）。$\dot{V}=2x_1x_2+2x_2(-x_1-x_2)=-2x_2^2\le0$，稳定。进一步用 Lasalle 不变集原理或直接求解（特征根 $-1/2\pm i\sqrt{3}/2$ 负实部），可得渐近稳定。

答案：设 $x(t)$ 为含盐量，$dx/dt=3\cdot2-3\cdot(x/100)=6-0.03x$。分离 $dx/(6-0.03x)=dt$，$x=200+Ce^{-0.03t}$。$x(0)=50$，$C=-150$，$x=200-150e^{-0.03t}$。
补充练习 14：解 $y''+y=\sin^2x$。
查看答案
答案：$\sin^2x=\frac{1-\cos2x}{2}$。对常数 $1/2$：设 $A$，$A=1/2$。对 $-\cos2x/2$：$2i$ 非根，设 $B\cos2x$，$(-4+1)B=-1/2$，$B=1/6$。$y^*=1/2+\frac16\cos2x$。
补充练习 15：降落伞下落问题：质量 $m$，阻力 $kv$，初速 0，求速度与位移。
查看答案
答案：$m dv/dt=mg-kv$，分离 $dv/(mg-kv/m)=dt$，$v=mg/k(1-e^{-kt/m})$。位移 $x=mg/k\,t-\frac{m^2g}{k^2}(1-e^{-kt/m})$。终极速度 $mg/k$。
