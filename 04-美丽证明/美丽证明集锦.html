美丽证明集锦 √

数学家说「美」，通常指：最少的前提、最意外的连接、最干净的收束。这里收集的证明，值得一年读一遍。

「数学的证明就像诗——有的只是正确，有的美得令人屏息。」（常引戈弗雷·哈代）

经典九证

1. 素数有无穷多个（欧几里得，约公元前 300 年）

结论：素数的个数是无限的。

  1. 假设素数只有有限多个：p₁, p₂, …, pₖ。
  2. 构造 N = p₁·p₂·…·pₖ + 1。
  3. N 除以任何 pᵢ 都余 1，所以 N 不被任何「已知素数」整除。
  4. 但 N > 1，必有素因子 q。这个 q 不在列表里——矛盾。

为何美：一个「更大的数」没有用任何新工具，只是把已有的素数乘起来再加一，就逼出了一个新素数。两千年后仍在教科书第一页。

2. √2 是无理数（古希腊，反证法的教科书案例）

结论：不存在整数 p, q（q ≠ 0）使 (p/q)² = 2。

  1. 假设 √2 = p/q，其中 p/q 是最简分数（p、q 互素）。
  2. 两边平方：2q² = p²，所以 p² 是偶数，p 是偶数，写 p = 2m。
  3. 代回：2q² = 4m²，即 q² = 2m²，所以 q 也是偶数。
  4. p、q 都是偶数，与「互素」矛盾。故 √2 无理。

为何美：从「假设它有理」出发，只用了「偶数的平方是偶数」这一件事，就把假设碾成粉末。传说发现者因此被扔进了海里。

3. 立方和 = 和的平方：无字证明

无字证明：1³ + 2³ + … + n³ = (1 + 2 + … + n)²。每一圈「L 形」的面积恰好是 k³。

结论：1³ + 2³ + … + n³ = [n(n+1)/2]²。这也许是「看到的证明」里最美的一幅。

4. 高斯求和：1 + 2 + … + n = n(n+1)/2

结论：1 + 2 + … + 100 = 5050（高斯 9 岁时的「速算」）。

  1. 把数列正着写一遍，再倒着写一遍：S = 1+2+…+n；S = n+(n−1)+…+1。
  2. 两式相加：2S = (n+1) 出现 n 次，即 2S = n(n+1)。
  3. 于是 S = n(n+1)/2。

为何美：没有算任何一列加法，只把数列「折叠」，答案自己跳出来。配对的思想是组合数学的种子。

5. 欧拉恒等式：$e^{iπ}$ + 1 = 0

结论：e、i、π、1、0——五个最重要的常数，一个式子全装下。

展开证明（幂级数路线）
  1. 指数函数的幂级数：eˣ = 1 + x + x²/2! + x³/3! + x⁴/4! + …
  2. 代入 x = iθ，按 i² = −1 整理实部与虚部：
  3. 实部 = 1 − θ²/2! + θ⁴/4! − … = cos θ；虚部 = θ − θ³/3! + θ⁵/5! − … = sin θ。
  4. 故 $e^{iθ}$ = cos θ + i·sin θ；取 θ = π：$e^{iπ}$ = −1。

为何美：三角函数的圆、指数函数的增长、虚数的旋转——被幂级数这一条暗线焊在一起。费曼称它为「我们最卓越的珍宝」。

6. 巴塞尔问题：1 + 1/4 + 1/9 + … = π²/6

结论：Σ 1/n² = π²/6 ≈ 1.6449。π 出现在与圆毫无关系的级数里。

展开证明（欧拉 1735 的启发式论证）
  1. 把 sin x 写成「无穷多项式」：sin x / x = 1 − x²/6 + x⁴/120 − …
  2. sin x 的零点在 x = ±π, ±2π, ±3π, …，类比因式分解：
  3. sin x / x = (1 − x²/π²)(1 − x²/4π²)(1 − x²/9π²)…
  4. 展开右端，x² 项的系数 = −(1/π² + 1/4π² + 1/9π² + …)；与左端系数 −1/6 比较：
  5. −(1/π²)Σ1/n² = −1/6，得 Σ1/n² = π²/6。

（欧拉当时省略了严格性，但答案正确；后来黎曼 ζ 函数与魏尔斯特拉斯因子分解定理补全了地基。）

为何美：从「零点」反推「系数」，把多项式直觉大胆搬到无穷情形——这是「启发式 = 真理探测器」的完美标本。

7. 康托尔对角线：实数比整数多

结论：|N| < |R|——0 和 1 之间的实数都数不完。

  1. 假设 (0,1) 内所有实数可排成列表：r₁, r₂, r₃, …
  2. 构造新数 d：第 n 位小数取「不等于 rₙ 第 n 位」的数字（如遇 5 取 6，否则取 5）。
  3. d 与每个 rₙ 都在第 n 位不同，所以 d 不在列表中——矛盾。

为何美：一条对角线同时是「构造」和「反驳」。它让你第一次看见：无穷也有大小，且一个大得吓人。

8. 几何级数：1/2 + 1/4 + 1/8 + … = 1

无字证明：正方形的一半 + 四分之一 + 八分之一……最终覆盖整个正方形。

9. 费马小定理的组合证明（进阶）

结论：p 为素数、p ∤ a 时，$a^p$ − a 被 p 整除，即 $a^p$ ≡ a (mod p)。

  1. 想象用 a 种颜色的珠子串项链，长度为 p（不考虑旋转对称）。
  2. 总项链数 = $a^p$。其中「全部同色」的有 a 条。
  3. 其余 $a^p$ − a 条：因为 p 是素数，旋转 p 次必然产生 p 个不同的项链（无更小周期）。
  4. 所以 $a^p$ − a 是 p 的倍数。

为何美：一条数论定理，被「数项链」数出来。同一个计数，两种视角——这就是组合证明的魅力。

补充：六个令人叫绝的证明

10. 巴塞尔问题（欧拉，1734）

结论：$\sum_{n=1}^\infty\frac{1}{n^2}=\frac{\pi^2}{6}$。

欧拉大胆地把 $\frac{\sin x}{x}$ 当作「无穷次多项式」，用其零点 $\pm\pi,\pm2\pi,\dots$ 写出乘积展开：

$$\frac{\sin x}{x}=\prod_{n=1}^\infty\left(1-\frac{x^2}{n^2\pi^2}\right).$$

另一方面 $\frac{\sin x}{x}=1-\frac{x^2}{6}+\frac{x^4}{120}-\cdots$。比较 $x^2$ 系数：$-\frac{1}{6}=-\frac{1}{\pi^2}\sum\frac{1}{n^2}$，得证。

为何美：把有限多项式的因式分解「想当然」地推广到无穷——欧拉的直觉跨越了严谨性，一个世纪后被 Weierstrass 严格化。

11. 布劳威尔不动点定理（拓扑方法）

结论：连续映射 $f:B^n\to B^n$（闭球到自身）必有不动点。

证明（反证）：若 $f(x)\ne x$ 对所有 $x$，则从 $f(x)$ 向 $x$ 作射线交球面 $S^{n-1}$ 于 $r(x)$。$r:B^n\to S^{n-1}$ 是连续收缩映射（$r|_{S^{n-1}}=\mathrm{id}$）。但拓扑学证明：$n$ 维球到其边界不存在连续收缩——矛盾。

为何美：「搅拌咖啡后总有一点没动」——用纯拓扑证明了分析事实，是「软分析」胜过「硬估计」的典范。

12. 算术-几何均值不等式（反向归纳法）

结论：对 $a_i>0$，$\frac{a_1+\cdots+a_n}{n}\ge\sqrt[n]{a_1\cdots a_n}$。

证明（柯西）：先证 $n=2^k$ 时成立（对 $k$ 归纳，每步用 $\frac{a+b}{2}\ge\sqrt{ab}$）。对一般 $n$，取 $2^m>n$，令 $a_{n+1}=\cdots=a_{2^m}=A$（算术平均），则 $2^m$ 元 AGM 给出 $A\ge(a_1\cdots a_n A^{2^m-n})^{1/2^m}$，化简得 $A\ge G$。

为何美：先跳到「容易的」$2^k$，再用「后退」覆盖所有 $n$——反向归纳是数学归纳法的优雅变体。

13. 毕克定理（格点多边形面积）

结论：顶点在格点上的简单多边形面积 $A=I+\frac{B}{2}-1$，$I$ 为内部格点数，$B$ 为边界格点数。

证明思路：(1) 对格点三角形用鞋带公式+Pick 验证；(2) 两个相邻多边形合并时，$A$ 相加，$B$ 减 2（公共边两个端点各算一次），$I$ 加公共边内点数，公式守恒；(3) 任意格点多边形可剖分为格点三角形。

为何美：面积这种「连续量」居然只由离散的格点计数决定，是离散与连续的神奇桥梁。

14. $\sqrt{2}$ 是无理数（几何证明，古希腊）

结论：$\sqrt{2}\notin\mathbb{Q}$。

证明：设正方形 $ABCD$ 边长为 $a$，对角线 $AC=b$。若 $b/a=m/n$ 既约。在 $AC$ 上取 $E$ 使 $CE=CB=a$，则 $AE=b-a$。过 $E$ 作 $AC$ 垂线交 $AB$ 于 $F$，则 $AEF$ 也是等腰直角三角形，$AF=AE=b-a$，$FB=AB-AF=2a-b$。得更小的等腰直角三角形，边长 $b-a$ 与 $2a-b$，且 $\frac{b-a}{2a-b}=\frac{b}{a}$。无限递降——矛盾。

为何美：不用任何代数，仅用直尺圆规作图和「无限递降」就证明了无理数的存在，震撼了古希腊毕达哥拉斯学派。

15. 欧拉公式 $V-E+F=2$（多面体）

结论：凸多面体顶点数 $V$、棱数 $E$、面数 $F$ 满足 $V-E+F=2$。

证明（柯西）：去掉一个面并把多面体展开到平面，需证 $V-E+F=1$。反复执行：(a) 若有不属于任何三角形的面，加一条对角线——$E$、$F$ 各 +1，$V-E+F$ 不变；(b) 若只剩三角形，逐个去掉边界三角形。去一个边界三角形时，若去掉 1 棱 1 面则 $V-E+F$ 不变，若去 2 棱 1 顶点 1 面也不变。最后剩 1 个三角形：$V=3,E=3,F=1$，$V-E+F=1$。

为何美：拓扑不变量的鼻祖——不关心形状大小，只关心「连接关系」，开启了拓扑学的大门。
