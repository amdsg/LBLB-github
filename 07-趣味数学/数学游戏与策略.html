数学游戏与策略 N

游戏是数学的游乐场：尼姆游戏的必胜策略藏在二进制里，猜数字靠信息论，三门问题挑战直觉。这里既可玩，也能学会「必赢」的思考方式。

「数学游戏的精髓：先想清楚『后手能不能抄作业』——那是确定性的第一课。」

经典游戏里的数学 每个游戏都对应一个数学原理

尼姆游戏（Nim）

若干堆石子，双方轮流取（至少一颗，可从任一堆取任意颗），取走最后一颗者胜。必胜策略：把堆大小写成二进制，异或（nim-sum）为 0 时后手必胜。

a ⊕ b ⊕ c = 0 ⇒ 当前为必败态

猜数字（二分）

1 到 100 猜一个数，每次被告知大了/小了：最多 log₂100 ≈ 7 次。信息量 = 每次提问最多二分不确定性。

次数 ≥ ⌈log₂N⌉

三门问题

三扇门后一辆车，主持人知道车在哪、总开一扇羊门。换门胜率 2/3，不换 1/3——条件概率的著名反直觉。

P(换赢) = 2/3

100 囚徒问题

100 个囚徒各找自己的号码，每人最多开 50 个抽屉。随机策略胜率 (1/2)¹⁰⁰，而循环策略胜率 ≈ 31%——意外地高。

循环分解的胜率 > 1 − ln 2

公平分割

两个人分蛋糕：我切你选。n 个人怎么办？「一刀切」递归法（Dubins–Spanier）或「最后一个削减者」都能做到无嫉妒。

无嫉妒分割总存在

取石子变体

每次只能取 1~3 颗、取最后一颗胜：总数是 4 的倍数时后手必胜——「周期策略」的原型。

模 4 = 0 ⇒ 必败态

博弈与策略：从必败态到演化稳定 8 个可交互实验 · 规则 / 原理 / 公式

威佐夫博弈 黄金比

两堆石子：可从某一堆取任意颗，或从两堆取同样多颗，取最后一颗者胜。必败态恰为 (⌊kφ⌋, ⌊kφ²⌋)，其中 φ=(1+√5)/2。

φ=(1+√5)/2≈1.618，P=(⌊kφ⌋,⌊kφ²⌋)

巴什博弈 模 (m+1)

一堆 n 颗，每次取 1~m 颗，取最后一颗胜。必败态是 n ≡ 0 (mod m+1)。必胜法：每次取走 n mod (m+1) 颗，把 (m+1) 的倍数留给对手。

取走 r = n mod (m+1)

海盗分金 倒推法

n 个海盗按资历提案，≥半数通过；否则提案者喂鱼，由下一位提案。理性倒推：提案者只需 ⌈n/2⌉ 票，用 1 金收买「上一轮将得 0」的海盗。

需 ⌈n/2⌉ 票

囚徒困境（重复） 以牙还牙

单次博弈中背叛是占优策略；但重复博弈里 Tit-for-Tat 可维持合作。维持合作需折扣因子 δ > (T−R)/(T−P)。

T=5,R=3,P=1,S=0 ⇒ δ>1/2

井字棋 Minimax 最优必和

3×3 连三子为胜。Minimax 递归：己方取最大分、对手取最小分。估值函数：胜=+10−步数，负=−(10−步数)，和=0。

$v(s)=\max_{a}\min_{a'}v(s')$

汉诺塔 2ⁿ−1

3 柱 n 盘，大盘不能压小盘，一次移一盘。递归：把上面 n−1 盘移到中转，移最大盘，再把 n−1 盘移到目标。

H(n)=2H(n−1)+1 ⇒ H(n)=2ⁿ−1

2048 贪心 角位启发式

4×4 滑动合并相同数字。工程上常用贪心：最大牌固定在一角，盘面沿该行/列单调递减，避免把大牌逼到中间。

score≈角位奖励+单调相邻奖励

双骰概率表 均匀分布

两颗骰子共 36 种等可能结果。点数和 s 的组合数 N(s)：N(7)=6 最大，P(7)=1/6；两端 2、12 各 1 种。

P(s)=N(s)/36

谜题与算法策略：从搜索到不变量 8 个算法 · 规则 / 原理 / 公式

数独 约束满足

9×9 拉丁方，每行、每列、每个 3×3 宫各含 1–9。唯一余数：某格候选数只剩 1 个即填入；排除法：某数字在某行/列/宫只剩一个位置可放。候选数 = {1..9} 去掉所在行、列、宫已出现的数。

$C(r,c)=\{1,\dots,9\}\setminus(R_r\cup C_c\cup B_{\rm box})$

骑士巡逻 Warnsdorff

马步 (±1,±2)/(±2,±1) 走遍 64 格各一次。Warnsdorff 规则：每步走向「未访邻居中、后续出路最少」的格子——先堵死边角，是贪心搜索里少有的几乎必成启发式。

$v=\arg\min_{u\notin V}|N(u)\setminus V|$

欧拉路径 / 一笔画 奇点判定

无向图能一笔画 ⇔ 连通且奇度顶点数为 0（起点=终点，成回路）或 2（从一奇点起、另一奇点止）。哥尼斯堡七桥四块陆地全是奇度，故无解。

$\#\{v:\deg(v)\ \text{为奇}\}\in\{0,2\}$

图着色 色数 χ(G)

相邻顶点必须异色。色数 χ(G) 是最少颜色数；按顺序贪心着色即可做到 χ≤Δ+1（Brooks 定理）。平面图（地图）由四色定理至多 4 色。

$\chi(G)\le \Delta(G)+1$，平面图 $\chi\le 4$

蒙提霍尔模拟器 大数定律

换门胜率 2/3 是理论值。真跑 N 次换、N 次不换，经验频率随 N 增大逼近 2/3 与 1/3——大数定律把直觉钉在地上。

$\lim_{N\to\infty}\frac{W_{\rm swap}(N)}{N}=\frac23$

二十问（最优提问） 信息熵

每次是/否回答最多消除 1 bit 不确定性。最优提问永远把区间对半切，使剩余熵最小；猜中 [1,N] 必问 ⌈log₂N⌉ 次。

$Q\ge\lceil\log_2 N\rceil$，每问 $\approx1$ bit

N 皇后 回溯剪枝

n×n 放 n 个皇后，同行/列/对角线不互吃。逐行试放，用列集合与两条对角线（r−c、r+c）集合剪枝；无路即回退上一行换列。

冲突 $\Leftrightarrow$ 同列 或 $r_i-c_i=r_j-c_j$ 或 $r_i+c_i=r_j+c_j$

切蛋糕（无嫉妒） 公平分割

两人「我切你选」即无嫉妒：切者自认两半相等，选者挑大的。三人 Selfridge–Conway 协议在有限步内做到每人都觉得自己不比别人少。

两人：切者使 $v(L)=v(R)=\tfrac12\Rightarrow$ 各得 $\ge\tfrac12$

① 数独：唯一余数 / 排除法

先点一个空格，再点 1–9 填数。「唯一余数」：算出某格候选集，若只剩 1 个候选就该填它——这是人类解数独最常用的第一招。灰格是题目给定，不能改。

② 骑士巡逻（Warnsdorff 启发）

Warnsdorff：每步走向「未访邻居中、后续出路最少」的格子。数字是访问顺序。

③ 欧拉路径 / 一笔画（奇点判定）

统计每个顶点度数（连了几条边）：奇度点标红。奇度点为 0 或 2 才能一笔画；有 2 个奇点时必须从其中一个出发。

④ 图着色（相邻不同色）

先在下面选一支色笔，再点顶点上色；相邻顶点同色即冲突（边变红）。贪心按顶点顺序，取邻居没用过的第一色。

⑤ 蒙提霍尔模拟器（多次试验看胜率）

换门与不换门各跑 N 次并统计胜率。N 越大，两条经验频率越贴近 2/3 与 1/3。

⑥ 二十问：最优提问（信息熵）

你心里想一个 1–100 的数，AI 用「对半切」最优策略来猜，你只需回答大了/小了/对了。

AI 猜：50　第 0 问　剩余不确定性 6.6 bit

区间每次减半，剩余不确定性 = log₂(区间长度) bit。理论上 ⌈log₂100⌉=7 问必中；最优提问就是让每一问砍掉一半不确定性。

⑦ N 皇后回溯可视化

逐行试放，用列集合与两条对角线（r−c、r+c）剪枝。放不下去就回退到上一行换列（红格=刚回退的位置）。

⑧ 切蛋糕：两人「我切你选」 / 三人无嫉妒

两人：A 自认两半价值相等（切点在 0.5），B 按自己的估值挑大的。于是 A、B 各自都觉得拿到了 ≥ 1/2——这就是「无嫉妒」。

补充：更多数学游戏与策略

Nim 游戏与异或和策略

$n$ 堆石子，两人轮流从某一堆取任意颗，取最后一颗者胜。设各堆石子数为 $a_1,\dots,a_n$，则先手必胜当且仅当 $a_1\oplus a_2\oplus\cdots\oplus a_n\ne0$（$\oplus$ 为二进制异或）。

证明：若异或和 $S\ne0$，取最高位上 $S$ 为 1 的位，找到该位为 1 的堆 $a_i$，将其变为 $a_i\oplus S$（变少），新异或和为 0。若异或和为 0，任何操作都使其非 0。终态（全 0）异或和为 0，故异或和为 0 是必败态。

蒙提霍尔问题（三门问题）

三扇门后一车两羊。你选一扇，主持人开另一扇有羊的门，问你换不换？

答案：换！换后中奖概率 $2/3$，不换 $1/3$。

证明：初始选错概率 $2/3$（选到羊）。主持人开另一扇羊门后，你选错时换必中，选对时换必错。故换的胜率 $=$ 初始选错率 $=2/3$。

15 谜题的奇偶性不变量

$4\times4$ 滑块拼图，15 块带 1 空位。一个排列可达当且仅当逆序数 + 空位所在行（从下数）为偶数。

证明：每次移动改变逆序数奇偶性 + 空位行奇偶性，其和的奇偶性不变。
