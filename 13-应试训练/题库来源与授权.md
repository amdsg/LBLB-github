# 题库来源、权利归属与发布决定

本文件回答三个问题：这些题目**从哪来**、**权利归谁**、**为什么默认不发布**。

> **一句话**：真题题目正文与试卷 PDF **默认不进入本仓库**（被 `.gitignore` 排除）。
> 文件仍在你磁盘原处，本地所有页面照常工作；但 `git add` 不会收录。
> 原因是逐项核查后确认——**没有任何权利方给出可再分发的授权**。
>
> 核对哪些会发布：`python tools/check_tracked.py`

---

## 一、权利归属（已核查）

| 材料 | 著作权人 | 依据 |
| --- | --- | --- |
| 考研统考试卷（数学一/二/三） | **教育部考试中心** | 属《著作权法》第十一条「法人作品」：由其组织编制、代表其意志创作、并承担责任 |
| 全国大学生数学竞赛（CMC）试题 | **中国数学会 / 全国大学生数学竞赛工作组** | 初赛与决赛均由工作组统一命题 |
| 各高校期中、期末试题 | **各高校** | — |
| 专升本真题 | **各省教育考试院** | — |

**《著作权法》第五条不适用于试题。** 该条免除保护的是「法律、法规，国家机关的决议、决定、
命令和其他具有立法、行政、司法性质的文件」——试题不在其列。学界虽有「公产说」主张，
主流实务观点认定试题构成作品、由命题机构享有权利。

**司法参考**：胡浩波诉教育部考试中心案（[2008] CNBJIPC 353）确认考试中心使用他人作品属
「国家机关为执行公务在合理范围内使用」，由考试中心承担责任——从侧面印证其权利主体地位。

## 二、授权链条核查：确实不存在

关键是：**不是「找不到授权」，而是「权利方从未授权」**。三条独立证据：

1. **开源仓库作者自己声明无法授权。** 考研数二 408 题的来源仓库 `apoisonsa/math2-compose`
   在项目说明中写明：「提示使用方自行评估原题合理使用」。
2. **第三方竞赛资料站自己声明只是分享。** 大学生数学竞赛网页面底部：
   「本站信息搜集整理自互联网，信息版权归原作者所有，本站仅作分享！」
3. **官方渠道未提供再分发许可。** 中国数学会官网、全国大学生数学竞赛官网、教育部
   「中国大学生在线」、各高校数学院系网站均**没有**给出试卷的开放许可。官方题库的正式
   出版物是科学出版社《全国大学生数学竞赛参赛指南》，属商业出版物。

### 对开源许可证的更正

曾一度认为「这些题来自 MIT / CC 授权的仓库，所以可以再分发」——**这个判断是错的**：

> 开源许可证（MIT、CC BY-NC-SA 等）覆盖的是**仓库作者自己创作的部分**：代码、编排、
> 转录工作。它对仓库内**他人试卷的原文没有效力**——作者无权把不属于自己的东西授权给你。
> 上面第 1 条证据正是作者本人对此的明确表态。

## 三、平台层面的实际后果

GitHub 的版权投诉处理流程（据 GitHub 官方 DMCA 文档）：

1. 权利人提交下架通知 → 通知被**公开**在 `github.com/github/dmca`
2. **若只有部分内容被指侵权，GitHub 会先给仓库所有者约 24 小时自行删除或修改该部分**
   （不是直接封禁整个仓库）
3. 未处理才禁用访问；所有者可提交反通知，内容可能在 10–14 天后恢复

检索**未发现**针对中文试卷／教材在 GitHub 上被实际下架的公开先例
（注意：英文搜索引擎对中文投诉记录覆盖有限，不能据此认定「不会被投诉」）。

**结论**：风险「低但非零」，且一旦被投诉，责任与后果由仓库所有者承担。

## 四、本仓库发布什么

### 发布（`git add` 收录，约 12 MB）

| 内容 | 说明 |
| --- | --- |
| `14-自测题库` 234 题 | 本库编写，答案经 sympy 逐题验证，无权利瑕疵 |
| `15-应试实战` 页面框架 | 读题库并筛选、渲染；题库缺失时降级为**试卷目录** |
| `11-数学家/数学家名录.html` | 10,000 人事实性名录（姓名/生卒/国籍/出处） |
| 12 个主题讲义、36 个可视化、同济高数 8 讲 | 本库编写 |
| `试卷清单.js` | 试卷**元数据**：标题、年份、分类、文件名——不含题目正文 |
| `_papers*.json` | 来源清单：原始出处 URL、页数——不含题目正文 |
| 本文件 | 来源与权利归属说明 |

元数据属**事实性信息**（标题、年份、出处 URL），不受著作权保护，可安全发布。

### 不发布（被 `.gitignore` 排除，约 449 MB）

| 内容 | 排除理由 |
| --- | --- |
| 题目正文转录（`真题卷.js`、`题库-汇总.js` 等 10 个文件、约 12 MB） | 转录的是受保护试题的表达 |
| 试卷 PDF 原件（732 个、约 435 MB） | 复制原件，性质最接近侵权 |

**本地使用完全不受影响**：文件仍在 `13-应试训练/123/` 原处，
`05-真题模拟卷.html`（417 套整卷）与 `06-真实单题训练.html`（12,858 道单题）照常工作。

### 如果你确认自己有权发布

```bash
git add -f 13-应试训练/123/真题卷.js      # 强制单个文件
git add -f 13-应试训练/123/考研/          # 强制整个目录
```

请同时保留本文件与仓库中的免责声明。若日后收到投诉，删掉这些路径即可恢复合规状态。
