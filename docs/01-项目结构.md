## 页面写法

### 单文件优先

除 `00-总览`、`13-应试训练` 的若干页面外，绝大多数页面是**自包含的单文件 HTML**：
样式写在 `<head>` 的 `<style>` 里，交互逻辑写在页面底部的 `<script>` 里，
不引用任何本地 CSS/JS 文件（MathJax 除外）。这样做的原因：

- 双击即可打开，不依赖服务器，也不怕相对路径出错；
- 单页内容可以整段复制、迁移或单独分享；
- 没有构建步骤，改完刷新即可看到效果。

### 公共约定

各页面共享同一套视觉语言，便于阅读时保持连贯：

| 约定 | 说明 |
| --- | --- |
| 配色变量 | 在 `:root` 中定义 `--paper`（纸色背景）、`--ink`（正文）、`--line`（分隔线）、`--blue`/`--gold`/`--red`/`--green`（语义色） |
| 字体 | 标题用 `Georgia` / `Noto Serif SC`，正文用 `Times New Roman` / `Noto Sans SC`，数学用 MathJax 自带字体 |
| 语义块 | `.def`（定义）、`.thm`（定理）、`.proof`（证明）、`.ex`（例题）等类名在各讲义页中含义一致 |
| 屏幕适配 | `<meta name="viewport">` 齐全；可视化页的画布监听窗口尺寸变化，宽度自适应 |
| 安全头 | 页面通过 `<meta http-equiv>` 设置了 CSP、`X-Content-Type-Options`、`X-Frame-Options` 与 referrer 策略 |

### 公式渲染

公式用 LaTeX 语法写在 `$...$`（行内）或 `$$...$$`（行间）中，由 MathJax 在浏览器端排版。

页面中引入 MathJax 的写法（相对路径，注意层级）：

```html
<!-- 内容分区页面（00–12）：引用根目录 assets/ -->
<script src="../assets/mathjax/es5/tex-svg.js" async></script>

<script src="../assets/mathjax/es5/tex-svg.js" async></script>
```

两种构建的分工：

| 构建 | 版本 | 渲染方式 | 使用页面 |
| --- | --- | --- | --- |
| `assets/mathjax/` | MathJax 3.2.2 | SVG（矢量，缩放不失真） | 00–12 各页面，以及 13 区的 00/05/06/07 |


> **移动文件时请保持目录层级不变。** 公式能否渲染取决于 `../assets/...` 相对路径是否成立。
> 若确实要调整目录，需同步修改所有页面中的 MathJax `<script src>`。

### 无 MathJax 时的降级

各页面在 MathJax 加载失败时会显示一条提示条，公式退化为 LaTeX 源码显示，页面其余部分仍可正常使用。
`13-应试训练` 的三个数据页面还会额外检测题库数据是否缺失并给出说明。

## 自测题库的生成流程

`14-自测题库/` 里的页面不是手写的，而是从 `tools/bank/` 的数据生成的。流程刻意做成
「先验证、后生成」，避免把没验算过的答案写进页面：

```
tools/bank/*.py            每道题：题干 / 答案 / 详解 / 一个 sympy 断言
        │
        ├─ tools/verify_bank.py    逐题求值断言，输出通过数与失败清单
        │
        └─ tools/build_bank.py     生成前再验一次 → 全部通过才写 HTML
```

每道题在页面上的「详解」下方都会印出它对应的验证表达式，例如
`eq(limit((1-cos(x))/x**2, x, 0), Rational(1,2))`，读者可以自行复核，
也可以直接跑 `python tools/verify_bank.py` 复现整轮验证。

断言语义由 `bank_kit.py` 提供：`zero(e)` 判断表达式化简为 0（依次尝试普通化简、展开、
三角化简、化指数形式、约分，都不行再做数值抽查）、`eq(a,b)` 判断两者相等、
`diverges(s)` 判断级数发散（`is_convergent() is False`，比 `doit()` 更可靠）、
`eq_in(s, closed, x)` 用于含参幂级数——这类 `doit()` 会返回带收敛条件的 `Piecewise`，
无法直接比较，改为在收敛域内取一点做数值比对。
