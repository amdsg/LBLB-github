1. 复数与复平面 数轴的二维扩展

定义（复数）：z = x + iy（x、y 实，i² = −1）。加法向量式、乘法旋转式：z₁z₂ 的模 = 模之积，辐角 = 辐角之和。极坐标 z = $re^{iθ}$。
定理（代数基本定理的复分析证明）：非常数复多项式必有根。
证明要点：若 P(z) 无根，1/P 整函数且有界（模在无穷远处趋于 0），刘维尔定理 → 常数，矛盾。复分析「免费」给出代数的核心定理。
例：(1+i)² = 2i；(1+i)⁴ = −4；z = $e^{iπ/3}$ = 1/2 + i√3/2 是 6 次单位根 z⁶ = 1。

2. 解析函数与柯西-黎曼方程 「可导」在复平面上的含义

定义（解析）：f: U → ℂ 在 U 上解析（全纯），若每点复可导：lim (f(z+h)−f(z))/h 存在（h → 0 沿任意方向）。
定理（柯西-黎曼方程）：f = u + iv 在点 (x,y) 复可导 ⟺ u、v 可微且 uₓ = vᵧ、uᵧ = −vₓ。
证明要点：复导数沿实方向 = uₓ + ivₓ，沿虚方向 = vᵧ − iuᵧ，两条路径必须相等。
定理（解析函数与调和函数）：解析函数的实部、虚部都是调和函数（Δu = 0），且互为共轭调和。
证明要点：对 C-R 方程再求导：uₓₓ = vₓᵧ = vᵧₓ = −uᵧᵧ。
例：f(z) = z̄（共轭）处处不可导——C-R 方程 uₓ = 1 ≠ vᵧ = −1。f(z) = z² 处处可导（u = x²−y², v = 2xy，uₓ = 2x = vᵧ ✓）。

3. 初等解析函数 指数函数是复分析的引擎

定理（复指数）：$e^z$ = eˣ(cos y + i sin y)。欧拉公式 $e^{iθ}$ = cos θ + i sin θ 是它的特例。
证明要点：用幂级数定义 $e^z$ = Σ zⁿ/n!，分离实虚部，或验证 C-R 方程。
定理（复对数）：Log z = ln|z| + i Arg z（主值 Arg ∈ (−π, π]）。
注意：对数在负实轴上有「割线」——绕原点一圈后辐角跳 2πi，Log 不是单值的（需要黎曼面）。
定理（复幂）：z^α = $e^{α Log z}$。三角函数 sin z = ($e^{iz}$ − $e^{-iz}$)/(2i)。
推论：复正弦无界（|sin iy| 指数增长）——复数域上「有界」的概念与实数域完全不同（刘维尔定理）。
例：$i^i$ = $e^{i Log i}$ = $e^{i·(ln 1 + iπ/2)}$ = $e^{-π/2}$ ≈ 0.208——虚数的虚数次幂是实数！

4. 柯西积分定理与公式 解析函数的「面积守恒」

定理（柯西积分定理）：f 在单连通域 U 上解析，则对 U 内任何闭路 γ：∮ f dz = 0。
证明要点（格林定理版）：∮ f dz = ∮ (u dx − v dy) + i∮ (v dx + u dy)，C-R 方程使两个被积式都成为恰当微分，积分为 0。
定理（柯西积分公式）：f(a) = (1/2πi) ∮ f(z)/(z−a) dz。
证明要点：挖掉 a 的小圆，圆上 f(z)/(z−a) ≈ f(a)/(z−a)，而 ∮ 1/(z−a) dz = 2πi。解析函数由边界值「决定」内部——这是强得惊人的性质。
定理（导数公式与刘维尔定理）：f⁽ⁿ⁾(a) = (n!/2πi) ∮ f(z)/(z−a)ⁿ⁺¹ dz；有界整函数必为常数。
推论：解析函数无穷可微（实函数可导一次未必可导两次！）；代数基本定理、最大模原理都来自这里。
例：$\oint _{|z|=2}$ $e^z$/(z−1) dz = 2πi·e¹ = 2πie——柯西公式直接算出。

5. 幂级数与洛朗展开 解析函数的泰勒级数永远收敛

定理（泰勒展开）：解析函数在其收敛圆盘内等于它的泰勒级数。
证明要点：柯西公式 + 几何级数展开 1/(z−a) = Σ ((z−z₀)/(a−z₀))ⁿ，逐项积分。
定义（孤立奇点分类）：z₀ 是 f 的孤立奇点：可去奇点（洛朗展开无负幂项）、极点（有限个负幂项）、本性奇点（无穷多个负幂项）。
定理（皮卡定理）：本性奇点邻域内，f 取遍所有复数值（至多除外一个）。
例：$e^{1/z}$ 在 z = 0 是本性奇点：当 z → 0 沿实轴 $e^{1/z}$ → +∞，沿负实轴 → 0——每个方向极限不同，且几乎所有值都被取到。
例：sin z/z³ 在 0 处有 2 阶极点；sin z/z 有可去奇点（定义 f(0)=1 后解析）；$e^{1/z}$ 本性奇点。

6. 留数定理 把积分变成「数奇点」

定义（留数）：Res(f, z₀) = 洛朗展开中 1/(z−z₀) 的系数 a₋₁。极点处可用公式：一阶极点 Res = lim (z−z₀)f(z)；m 阶极点 Res = 1/(m−1)! lim dᵐ⁻¹/dzᵐ⁻¹ [(z−z₀)ᵐ f(z)]。
定理（留数定理）：∮ f dz = 2πi Σ Res(f, 内部奇点)。
证明要点：变形回路绕每个孤立奇点的小圆，柯西定理把总积分拆成各小圆积分之和，每个小圆积分 = 2πi × 留数。
定理（算实积分的围道法）：$\int _{0}^\infty R(x) \,dx$ 型积分：取上半圆围道，验证圆弧部分趋于 0，留数定理给出结果。
例：$\int _{0}^\infty 1/(1+x^{2}) \,dx$ = π/2——1/(1+z²) 在上半平面有一阶极点 z = i，留数 1/(2i)，2πi·1/(2i) = π，取一半 = π/2。
例：计算 $\int _{0}^\infty 1/(1+x^{4}) \,dx$。
查看答案
答案：上半平面的极点 z = $e^{iπ/4}$、$e^{i3π/4}$，留数求和 × 2πi，得 π√2/4。

7. 保角映射 解析映射保持角度

定理（保角性）：f′ ≠ 0 的解析映射局部保持角度与定向。
证明要点：f(z+h) ≈ f(z) + f′(z)h——局部是「旋转 + 缩放」，角度自然不变。
定理（黎曼映射定理）：任何单连通真开子域（≠ ℂ）都共形等价于单位圆盘。
证明要点：考虑一族归一化的共形映射，用蒙泰尔定理（正规族）取极限——存在性用泛函分析，但构造很难，无一般公式。
定理（经典保角映射）：w = z² 把象限映为半平面；w = (z−1)/(z+1) 把右半平面映为圆盘；w = Log z 把角形域映为带形。
应用：流体力学、静电场的位势问题——复杂区域上的调和函数问题映射到圆盘/半平面求解再映回。
例：w = $e^z$ 把水平带 {0 < Im z < π} 映为上半平面。

9a. 深度：柯西积分公式与高阶导数 从一个公式推出解析函数的全部性质

定理（Cauchy 积分公式） 设 $f$ 在简单闭曲线 $\gamma$ 所围区域 $D$ 内解析、在 $\bar D$ 上连续，$a \in D$，则 $$f(a) = \frac{1}{2\pi i}\oint_\gamma \frac{f(z)}{z-a}\,dz.$$ 更一般地，$f$ 在 $a$ 处无穷次可导，且 $$f^{(n)}(a) = \frac{n!}{2\pi i}\oint_\gamma \frac{f(z)}{(z-a)^{n+1}}\,dz.$$
证明思路： 在 $a$ 处挖一个半径 $\varepsilon$ 的小圆 $C_\varepsilon$。由柯西积分定理，沿外边界 $\gamma$ 的积分等于沿 $C_\varepsilon$ 的积分（方向相反）。令 $z = a + \varepsilon e^{i\theta}$，则 $$\frac{1}{2\pi i}\oint_{C_\varepsilon} \frac{f(z)}{z-a}\,dz = \frac{1}{2\pi}\int_0^{2\pi} f(a+\varepsilon e^{i\theta})\,d\theta \to f(a) \quad (\varepsilon\to 0),$$ 由 $f$ 在 $a$ 处连续。高阶公式由对 $a$ 求导（积分号下求导合法，因为被积函数对 $a$ 连续可微）得到。
例：计算 $\displaystyle \oint_{|z|=2} \frac{e^{z}}{(z-1)^3}\,dz$。 这里 $f(z) = e^z$，$a=1$ 在圆内。由 $n=2$ 公式： $$\oint \frac{e^z}{(z-1)^3}\,dz = \frac{2\pi i}{2!} f''(1) = \pi i \cdot e = \pi e i.$$
验证：$f'(z)=e^z$，$f''(z)=e^z$，$f''(1)=e$，故结果 $\pi e i$。无需展开洛朗级数，一个公式直接算完。

9b. 深度：解析函数与柯西-黎曼方程 「可导」与「调和」之间的桥梁

定义（解析） $f = u + iv$ 在开集 $D$ 内解析，若它在 $D$ 内每点复可导（导数 $f'(z) = \lim_{h\to 0} (f(z+h)-f(z))/h$ 存在，与 $h$ 趋近方向无关）。
定理（C-R 方程的等价刻画） $f = u+iv$ 在 $D$ 内解析当且仅当 $u, v$ 在 $D$ 内连续可微且满足 $$u_x = v_y, \qquad u_y = -v_x.$$ 此时 $u, v$ 都是调和函数（$\Delta u = u_{xx}+u_{yy}=0$，$\Delta v=0$），且互为共轭调和。
证明思路： 必要性：$h \to 0$ 沿实轴时 $f'(z) = u_x + i v_x$；沿虚轴时 $f'(z) = -i(u_y + i v_y) = v_y - i u_y$。两式相等即得 $u_x = v_y$、$v_x = -u_y$。 充分性：由 C-R 与 $u,v$ 连续可微，$f(z+h) - f(z) = f'(z) h + o(|h|)$ 沿任意方向成立（实微分的可微性叠加 C-R），故复导数存在。调和性由 C-R 交叉求导：$u_{xx} = v_{yx} = -u_{yy}$。
例：检验 $f(z) = z^2 = (x^2-y^2) + i(2xy)$ 是否解析。 $u = x^2 - y^2$，$v = 2xy$。$u_x = 2x = v_y$；$u_y = -2y = -v_x$（$v_x = 2y$）。C-R 成立，故 $z^2$ 处处解析，$f'(z) = u_x + i v_x = 2x + i2y = 2z$。
反例：$f(z) = \bar z = x - iy$：$u_x = 1 \neq v_y = -1$，不满足 C-R，故处处不解析——尽管它实可微。

9a. 深度：留数定理与实积分计算 把无穷积分变成「数极点」

定理（留数定理） 若 $f$ 在简单闭曲线 $C$ 内除有限个奇点 $a_1,\dots,a_n$ 外解析，则 $$\oint_C f(z)\,dz = 2\pi i\sum_k\mathrm{Res}(f,a_k).$$ 留数 $\mathrm{Res}(f,a)=\frac{1}{(m-1)!}\lim_{z\to a}\frac{d^{m-1}}{dz^{m-1}}[(z-a)^m f(z)]$（$m$ 阶极点）。
思路：在每极点挖小圆，由 Cauchy 公式各圆积分为 $2\pi i\,\mathrm{Res}$，外围大圆积分 = 内圆之和。
例：计算 $I=\int_{-\infty}^{\infty}\frac{dx}{1+x^2}$。
解：取半圆围道，$f=1/(1+z^2)$ 在上半平面极点 $z=i$（一阶）。$\mathrm{res}=\frac{1}{2i}$。$\oint=2\pi i\cdot\frac{1}{2i}=\pi$。半圆弧上积分 $\to0$（$|f|\sim1/R^2$），故 $I=\pi$。

9b. 深度：共形映射与 Riemann 映射定理 任何「好看的」单连通域都能映到圆盘

定义（共形映射） 全纯且单射的映射 $f:U\to V$（导数非零），保持角度与定向。
定理（Riemann 映射定理） 任意单连通开域 $U\subsetneq\mathbb{C}$（边界多于一点）存在共形双射 $f:U\to\mathbb{D}$（单位圆盘）。
思路：用正规族（Montel 定理）取逼近映射的紧致极限；唯一性由 Schwarz 引理给出（至三点规约自由度）。
例（上半平面 → 圆盘） $f(z)=\frac{z-i}{z+i}$ 把上半平面 $\mathbb{H}\to\mathbb{D}$，$i\mapsto0$。这是 Cayley 变换——也出现在微分几何与量子力学。

9c. 深度：解析延拓与自然边界 一个函数能延拓多远？

定义（解析延拓） 若 $f$ 在 $U$ 解析，$g$ 在 $V\supset U$ 解析且 $g|_U=f$，称 $g$ 是 $f$ 的解析延拓。延拓（若存在）至 $V$ 唯一（恒等定理）。
定理（自然边界） 存在单位圆盘内解析函数，不能延拓过任何边界点——单位圆 $|z|=1$ 是其「自然边界」。
例（Lacunary 级数） $f(z)=\sum z^{n!}$ 在 $|z|<1$ 收敛，但 $|z|=1$ 每点都是奇点（单位根稠密）——这是 Hadamard 间隙定理的标准例子。

9d. 深度：黎曼映射定理 所有真单连通域都和圆盘等价

定义（共形映射） 全纯双射 $f:\Omega_1\to\Omega_2$ 称共形映射。局部共形 $\Leftrightarrow$ $f'(z)\ne0$（保角保向）。
定理（黎曼映射定理 1851） 设 $\Omega\subsetneq\mathbb{C}$ 为单连通开域。存在双射全纯 $f:\Omega\to\mathbb{D}:=\{|z|<1\}$。
思路：① 用变分法（Riemann 的原始想法）或 ② 用正规族（Osgood–Carathéodory–Koebe）。关键引理：$\mathcal F=\{f:\Omega\to\mathbb{D}$ 单射全纯$\}$ 非空（先去掉一点）且 $\sup|f'|$ 的极值函数由 Schwarz 引理强制为双射。Montel 定理保证紧性。
定理（边界对应） 若 $\partial\Omega$ 为简单闭曲线，$f$ 可延拓为 $\bar\Omega\to\bar{\mathbb D}$ 的同胚（Carathéodory）。边界自由度由 3 实参数给出（PSL(2,R) 模掉自同构）。
意义：这是「单连通 = 圆盘」的几何化形式。多连通域需要更复杂的「环面/环域」分类（Koebe–Andreev–Thurston）。
例：求上半平面 $\mathbb H$ 到 $\mathbb D$ 的共形映射。
解：$f(z)=\frac{z-i}{z+i}$，$f(i)=0$, $f(0)=-1$, $f(\infty)=1$，把 $\mathbb R\cup\{\infty\}$（$\partial\mathbb H$）映到单位圆。Möbius 变换是 $\mathrm{PSL}(2,\mathbb R)$ 的全部自同构。

9e. 深度：亚纯函数与留数定理的应用 数积分和的终极工具

定义（留数） $f$ 在孤立奇点 $a$ 处 Laurent 展开 $f(z)=\sum_{n=-\infty}^\infty c_n(z-a)^n$，$\mathrm{Res}(f,a)=c_{-1}$。等价地 $\mathrm{Res}(f,a)=\frac1{2\pi i}\oint f\,dz$（绕 $a$ 的小围道）。
定理（留数定理） 若 $f$ 在闭曲线 $\gamma$ 内部除有限奇点 $a_1,\dots,a_n$ 外全纯，则 $$\oint_\gamma f(z)\,dz = 2\pi i\sum_{k=1}^n\mathrm{Res}(f,a_k).$$
思路：在每 $a_k$ 周围作互不相交小圆 $\gamma_k$，多连通域 Cauchy 给 $\oint_\gamma=\sum\oint_{\gamma_k}$，每项 $=2\pi i\,\mathrm{Res}$。
定理（实积分计算） 形如 $\int_{-\infty}^{\infty}\frac{P(x)}{Q(x)}dx$（$\deg Q\ge\deg P+2$）可通过上半平面围道计算： $$\int_{-\infty}^{\infty} = 2\pi i\sum_{\Im a_k>0}\mathrm{Res}(P/Q,a_k).$$
关键：大半圆弧 $\to0$（由 $|f|=O(R^{-2})$ 与长度 $\pi R$），只剩实轴贡献。
例：计算 $\int_0^\infty\frac{dx}{1+x^4}$。
解：$z^4=-1$ 的根为 $e^{i\pi/4},e^{3i\pi/4},e^{5i\pi/4},e^{7i\pi/4}$，上半平面极点 $z_1=e^{i\pi/4}$, $z_2=e^{3i\pi/4}$。简单极点留数 $\mathrm{Res}(f,z_k)=\frac1{4z_k^3}=-\frac{z_k}{4}$（用 $z_k^4=-1$）。$$z_1+z_2=\frac{1+i}{\sqrt2}+\frac{-1+i}{\sqrt2}=i\sqrt2,\quad\sum\mathrm{Res}=-\frac{i\sqrt2}{4}.$$故 $\int_{-\infty}^{\infty}\frac{dx}{1+x^4}=2\pi i\bigl(-\frac{i\sqrt2}{4}\bigr)=\frac{\pi}{\sqrt2}$；被积函数为偶函数，$\int_0^\infty=\frac{\pi}{2\sqrt2}$。验证：Beta 函数 $\frac14 B(\frac14,\frac34)=\frac14\cdot\frac{\pi}{\sin(\pi/4)}=\frac{\pi}{2\sqrt2}$。

查看答案

查看答案
答案：极点 z = 2i，留数 1/(4i)，2πi·1/(4i) = π/2，一半 = π/4。

查看答案

练习 8：求把带状域 $\{0<\mathrm{Im}\,z<\pi\}$ 映到上半平面的共形映射。
查看答案
答案：$f(z)=e^z$：带状域 → 上半平面（$e^{x+iy}=e^x(\cos y+i\sin y)$，$y\in(0,\pi)$ 时 $\sin y>0$）。
练习 9：为什么 $\sum z^{n!}$ 的自然边界是 $|z|=1$？
查看答案
答案：单位根稠密：每个单位根 $e^{2\pi ip/q}$ 都是奇点（$\sum$ 在 $n!$ 含因子 $q$ 时发散）；单位根在 $|z|=1$ 稠密，故自然边界。
练习 10：用留数定理计算 $\int_0^{2\pi}\frac{d\theta}{2+\cos\theta}$。
查看答案
答案：令 $z=e^{i\theta}$，则 $\cos\theta=(z+z^{-1})/2$，$d\theta=dz/(iz)$，$$\oint\frac{dz/(iz)}{2+(z+z^{-1})/2}=\frac2i\oint\frac{dz}{z^2+4z+1}.$$极点 $z=-2\pm\sqrt3$，仅 $z_0=-2+\sqrt3$ 在单位圆内，留数 $\frac1{2z_0+4}=\frac1{2\sqrt3}$，故积分 $=\frac2i\cdot2\pi i\cdot\frac1{2\sqrt3}=\frac{2\pi}{\sqrt3}$（即一般公式 $\int_0^{2\pi}\frac{d\theta}{a+b\cos\theta}=\frac{2\pi}{\sqrt{a^2-b^2}}$，$a>|b|$）。
练习 11：上半平面 $\mathbb H$ 的自同构群是什么？
查看答案
答案：$\mathrm{PSL}(2,\mathbb R)$ 作用 $z\mapsto\frac{az+b}{cz+d}$，$ad-bc=1$。$\mathrm{Aut}(\mathbb H)\cong\mathrm{PSL}(2,\mathbb R)$——与 $\mathrm{Aut}(\mathbb D)\cong\mathrm{PSU}(1,1)$ 通过 Cayley 变换等价。
练习 12：用留数定理计算 $\int_0^{2\pi}\frac{d\theta}{5+3\cos\theta}$。
查看答案
答案：令 $z=e^{i\theta}$，$5+3\cos\theta=\frac{3z^2+10z+3}{2z}$，故 $I=\frac2i\oint\frac{dz}{3z^2+10z+3}$。极点 $z=\frac{-5\pm4}{3}$，即 $-1/3$ 与 $-3$，仅 $z_0=-1/3$ 在单位圆内。留数 $\frac1{6z_0+10}=\frac1{-2+10}=\frac18$，故 $I=\frac2i\cdot2\pi i\cdot\frac18=\frac{\pi}{2}$（与公式 $2\pi/\sqrt{5^2-3^2}=2\pi/4=\pi/2$ 一致）。
