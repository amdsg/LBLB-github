1. 极限：分析的地基 把「趋于」变成精确陈述

定义（函数极限 ε-δ）：$\lim_{x\to a}f(x)=L$ 当且仅当：对任意 ε > 0，存在 δ > 0，使 0 < |x−a| < δ 时 |f(x)−L| < ε。极限不是「到达」，而是「任意逼近」。
定义（序列极限）：lim aₙ = L ⟺ 对任意 ε > 0 存在 N 使 n > N 时 |aₙ − L| < ε。
定理（夹逼定理）：若 aₙ ≤ bₙ ≤ cₙ 且 aₙ→L、cₙ→L，则 bₙ→L。
证明要点：由 ε 定义直接比较 |bₙ−L| ≤ max(|aₙ−L|, |cₙ−L|)。
定理（重要极限）：$\lim_{x\to 0}\dfrac{\sin x}{x}=1$；$\lim_{n\to\infty}(1+\dfrac{1}{n})^n=e$。
证明要点：前者用扇形面积夹逼（几何面积 sin x < x < tan x）；后者用二项展开与单调有界定理。
例：求 $\lim_{n\to\infty}n\cdot\sin(1/n)$。
查看答案
答案：令 t = 1/n → 0，原式 = lim sin t / t = 1。

2. 连续与中值定理 连续 = 图像一笔画

定义（连续）：f 在 a 连续 ⟺ lim f(x) = f(a)。在区间上每点连续称连续函数。
定理（介值定理）：f 在 [a,b] 连续，则 f 取遍 f(a) 与 f(b) 之间的一切值。
证明要点：用完备性：考虑集合 {x : f(x) < y} 的上确界 c，连续保证 f(c) = y。
定理（极值定理）：闭区间上的连续函数有最大值与最小值。
证明要点：先用「有界性引理」（反证 + 波尔查诺-魏尔斯特拉斯），再取最值。
定理（中值定理 / 拉格朗日）：f 在 [a,b] 连续、(a,b) 可导，则存在 c 使 f′(c) = (f(b)−f(a))/(b−a)。
证明要点：构造 g(x) = f(x) − 割线函数，g 在端点相等，由罗尔定理 g′(c) = 0。
定理（罗尔定理的推论）：f′ = 0 则 f 常数；f′ > 0 则 f 严格增。
应用：中值定理是「导数信息 → 函数整体信息」的桥梁：泰勒余项、洛必达法则都靠它。
例：证明方程 x³ − 3x + 1 = 0 在 (0,1) 内有根。
查看答案
答案：f(0) = 1 > 0，f(1) = −1 < 0，介值定理 → 存在 c ∈ (0,1) 使 f(c) = 0。

3. 导数与应用 变化率的局部线性化

定义（导数）：$f'(a)=\lim_{h\to 0}\dfrac{f(a+h)-f(a)}{h}$。几何意义：切线斜率；物理意义：瞬时变化率。
定理（求导法则）：(fg)′ = f′g + fg′（乘积）；(f/g)′ = (f′g − fg′)/g²（商）；链式法则 (f∘g)′ = f′(g(x))g′(x)。
证明要点：乘积法则用「加一项减一项」的技巧；链式法则用微分形式 d(f∘g) = f′(g)dg。
定理（洛必达法则）：若 lim f = lim g = 0（或 ±∞）且 lim f′/g′ 存在，则 lim f/g = lim f′/g′。
证明要点：柯西中值定理：f/g = f′(c)/g′(c) 对某个中间点 c 成立。
定理（极值判定）：f′(c) = 0 且 f″(c) > 0 → 局部极小；f″(c) < 0 → 局部极大。
证明要点：二阶导符号 = 一阶导单调性 = 函数的凹凸性。
例：求 f(x) = x²e^(−x) 的极值。
查看答案
答案：f′ = $e^{-x}$(2x − x²) = 0 → x = 0 或 2。f″ = $e^{-x}$(2 − 4x + x²)：f″(0) = 2 > 0 极小 f(0)=0；f″(2) = e⁻²(2−8+4) = −2e⁻² < 0 极大 f(2) = 4e⁻²。

4. 积分与微积分基本定理 求和与求导互为逆运算

定义（黎曼积分）：把区间分成小段，用矩形面积逼近曲线下面积：$\int _a^b$ f = lim Σ f(ξᵢ)Δxᵢ（当分划细度 → 0）。
定理（微积分基本定理）：① F(x) = $\int _a^x$ f(t)dt 满足 F′ = f；② $\int _a^b$ f = F(b) − F(a)（F 为任意原函数）。
证明要点：① 用中值定理：F(x+h)−F(x) = f(c)·h；② 两边同取导数的「面积=净变化」解读：∫ f = 总变化量。
定理（换元与分部积分）：$\int f(g(x))g′(x)\,dx$ = $\int f(u)\,du$；$\int u \,dv$ = uv − $\int v \,du$。
证明要点：分部积分就是乘积法则的积分版：(uv)′ = u′v + uv′ → ∫ uv′ = uv − ∫ u′v。
例：求 $\int _{0}^π x \cos x \,dx$。
查看答案
答案：分部积分：u=x, dv=cos x dx → ∫ = [x sin x]₀^π − $\int \sin x \,dx$ = 0 − (−cos x)|₀^π = cos π − cos 0 = −2。

5. 级数与收敛 无穷和什么时候「算得清」

定义（级数收敛）：Σ aₙ 收敛 ⟺ 部分和 Sₙ = a₁+…+aₙ 收敛。
定理（比较判别法 / 比值判别法）：Σ aₙ 与 Σ bₙ 正项比较：若 aₙ ≤ bₙ 且 Σbₙ 收敛则 Σaₙ 收敛；比值 lim aₙ₊₁/aₙ < 1 收敛，> 1 发散。
例：Σ 1/n² 收敛（与 1/n(n+1) 比较，而后者裂项求和 = 1）；Σ 1/n 发散（调和级数，按 1/2 的块分组证明）。
定理（交错级数判别法）：Σ (−1)ⁿbₙ（bₙ 单调趋于 0）收敛，且余项 ≤ 首项。
证明要点：部分和的奇偶子列单调有界（莱布尼茨判别法）。
定理（黎曼重排定理）：条件收敛级数可重排成任意和。
证明要点：正项部分发散到 +∞、负项部分发散到 −∞，交替取项即可逼近任意目标——「和」依赖于次序。
例：Σ (−1)ⁿ/n = ln 2 条件收敛；重排后可以等于任何数。

6. 泰勒展开与幂级数 用多项式逼近一切

定理（泰勒定理）：f 在 a 附近 n+1 次可导，则 f(x) = Σ_{k=0}^n f⁽ᵏ⁾(a)/k! (x−a)ᵏ + Rₙ，余项 Rₙ = f⁽ⁿ⁺¹⁾(c)/(n+1)! (x−a)ⁿ⁺¹。
证明要点：反复用中值定理或积分型余项（Rₙ = $\int _a^x$ f⁽ⁿ⁺¹⁾(t)(x−t)ⁿ/n! dt）。
定理（经典展开）：eˣ = Σ xⁿ/n!；sin x = Σ (−1)ⁿx²ⁿ⁺¹/(2n+1)!；cos x = Σ (−1)ⁿx²ⁿ/(2n)!；1/(1−x) = Σ xⁿ（|x|<1）。
推论：欧拉公式 $e^{iθ}$ = cos θ + i sin θ——把 iθ 代入 eˣ 的展开并分离实虚部。这是数学中最著名的公式之一。
定理（巴塞尔问题）：Σ 1/n² = π²/6。
证明要点（欧拉，非严格版）：把 sin x / x 看作「多项式」用根展开：sin x/x = ∏(1 − x²/(n²π²))，比较 x² 系数：−1/6 = −Σ 1/(n²π²)。严格化由柯西 1841 年完成。
例：用泰勒展开求 e 的近似：e = 1 + 1 + 1/2! + 1/3! + … 前 8 项 ≈ 2.71828（误差 < 1/8! ≈ 2.5×10⁻⁵）。

7. 实数与无穷：完备性 分析学的地基是「没有洞」的数轴

定义（完备性）：实数的每个上界集合都有最小上界（上确界原理）——数轴没有「洞」。有理数不满足：√2 的截断序列没有有理数极限。
定理（戴德金分割 / 康托尔构造）：实数可由有理数构造：戴德金用分割、康托尔用有理数柯西列的等价类。
意义：√2、π、e 这些「数」第一次有了严格定义——实数完备性是微积分严格化的基础。
定理（康托尔对角线）：实数不可数。
证明要点：假设 [0,1] 可数列出，把每个数写成十进制展开，对角线取第 n 位并 +1（避开 0.999… 问题用 9 不进位），构造出不在此列的数——矛盾。这是人类第一次证明「无穷也有大小」。
定理（康托尔-伯恩斯坦定理）：若 |A| ≤ |B| 且 |B| ≤ |A|，则 |A| = |B|。
推论：[0,1] 与 ℝ 等势（连续统势 c）；有理数与整数等势（可数）；连续统假设（ℵ₁ = c？）独立于 ZFC——哥德尔与科恩 1963 年证明不可判定。
例：整数与偶数的个数「一样多」（双射 n ↦ 2n）——希尔伯特旅馆的数学依据。

8. 测度与傅里叶分析 从「可积」到「可测」

定义（勒贝格测度与积分）：把「长度」推广到复杂集合（可测集），积分按「值分层」求和而非按「自变量分段」。黎曼不可积的狄利克雷函数（有理数=1，无理数=0）勒贝格可积（=0）。
定理（勒贝格控制收敛定理）：若 fₙ → f 且 |fₙ| ≤ g（g 可积），则 ∫fₙ → ∫f。
意义：「极限与积分交换」在温和条件下合法——这是测度论给分析的礼物，概率论的大数定律严格化全靠它。
定理（傅里叶级数）：足够好的周期函数可展开为三角函数和：f(x) = a₀/2 + Σ(aₙ cos nx + bₙ sin nx)，系数由正交性 ∫ cos·cos 得到。
收敛：光滑函数一致收敛；狄利克雷条件（分段单调）逐点收敛到平均值；连续函数在 L² 意义收敛。去傅里叶可视化看圆周运动画出方波。
例：方波的傅里叶展开 f(x) = (4/π)(sin x + sin 3x/3 + sin 5x/5 + …) 在跳跃点收敛到 0（吉布斯现象：过冲约 9%）。

9. 深度专题：实数完备性六大基本定理互证 分析的地基是「没有洞」

六大等价命题： ① 确界原理：$\mathbb R$ 中非空有上界集合必有上确界； ② 单调有界定理：单调有界数列必收敛； ③ 闭区间套定理：$[a_n,b_n]\supseteq[a_{n+1},b_{n+1}]$ 且 $b_n-a_n\to 0$，则交集恰为一点； ④ 有限覆盖定理（Heine–Borel）：闭区间的任一开覆盖有有限子覆盖； ⑤ 聚点定理（Bolzano–Weierstrass）：有界无限集必有聚点； ⑥ Cauchy 收敛准则：$\{x_n\}$ 收敛 $\iff$ 它是 Cauchy 列。
定理：以上六条在 $\mathbb R$ 上两两等价（以 $\mathbb R$ 的戴德金构造或确界原理为出发点）。
典型互证链：确界原理 $\Rightarrow$ 闭区间套——取所有 $a_n$ 的上确界 $\xi$，可验证 $\xi\in\cap[a_n,b_n]$ 且唯一。闭区间套 $\Rightarrow$ 聚点定理——将含无限多点的闭区间二分，保留含无限多点的半段，得到区间套，其公共点即聚点。聚点定理 $\Rightarrow$ Cauchy 准则——Cauchy 列必有界，故有收敛子列；由 Cauchy 条件整列收敛。Cauchy 准则 $\Rightarrow$ 确界原理——用上确界的逼近序列构造 Cauchy 列，其极限即确界。
例：用闭区间套证明「介值定理」。设 $f$ 在 $[a,b]$ 连续，$f(a)<0<f(b)$。记 $c=(a+b)/2$：若 $f(c)=0$ 则结束；若 $f(c)<0$ 取 $[c,b]$，否则取 $[a,c]$。反复二分得到区间套 $[a_n,b_n]$，长度 $\to 0$，且 $f(a_n)<0<f(b_n)$。由闭区间套存在 $\xi$，$a_n\to\xi\leftarrow b_n$；由连续性 $f(\xi)=\lim f(a_n)\le 0$ 且 $f(\xi)=\lim f(b_n)\ge 0$，故 $f(\xi)=0$。
对照：这个证明在 $\mathbb Q$ 上失败——二分点可能是 $\sqrt2$ 这类「洞」，区间套没有公共点。这就是为什么分析必须建立在 $\mathbb R$ 上。
例：Heine–Borel 的反例方向。覆盖 $(0,1)$ 的开区间族 $\{(1/n,1):n\ge 2\}$ 没有有限子覆盖——因为任取 $n$ 个区间，其最左端点为 $1/n_{\max}>0$，靠近 $0$ 的点漏出。对比 $[0,1]$ 被同类族加 $(-\varepsilon,\varepsilon)$ 覆盖，则必有有限子覆盖。区别正是「开」与「闭」：紧性在 $\mathbb R$ 中等价于「有界闭」。

10. 深度专题：一致收敛与极限换序 什么时候 $\int$ 与 $\lim$ 可交换

定义（逐点收敛 vs 一致收敛）：$f_n\to f$ 逐点收敛指 $\forall x,\forall\varepsilon,\exists N(x,\varepsilon)$；一致收敛指 $N$ 不依赖 $x$： $$\sup_{x\in D}|f_n(x)-f(x)|\to 0.$$
定理（连续性保持）：若 $f_n$ 在 $D$ 上连续且 $f_n\rightrightarrows f$，则 $f$ 在 $D$ 上连续。
证明思路：$\varepsilon/3$ 论证。固定 $x_0$，取 $n$ 使 $\sup|f_n-f|<\varepsilon/3$（一致收敛），再取 $\delta$ 使 $|f_n(x)-f_n(x_0)|<\varepsilon/3$（连续性），则 $|f(x)-f(x_0)|<\varepsilon$。逐点收敛不够：$f_n(x)=x^n$ 在 $[0,1]$ 逐点收敛到不连续函数 $f(1)=1$、$f(x)=0\,(x<1)$。
定理（逐项积分）：若 $f_n$ 在 $[a,b]$ 上 Riemann 可积且 $f_n\rightrightarrows f$，则 $f$ 可积且 $$\lim_{n\to\infty}\int_a^b f_n(x)\,dx = \int_a^b f(x)\,dx = \int_a^b \lim_{n\to\infty}f_n(x)\,dx.$$
证明思路：$|\int f_n - \int f|\le (b-a)\sup|f_n-f|\to 0$。一致收敛是充分条件；对单调收敛可用 LEBESGUE 控制收敛定理放宽到逐点 + 控制函数。
定理（逐项微分）：若 $f_n$ 在 $[a,b]$ 上可导、$f_n'$ 连续、$f_n'$ 一致收敛到 $g$，且某点 $f_n(x_0)$ 收敛，则 $f_n$ 一致收敛到可导 $f$ 且 $f'=g$。注意：条件在导数列上，不在函数列上。
例：逐项积分与逐项求导的对照。$f_n(x)=\dfrac{\sin nx}{\sqrt n}$ 在 $\mathbb R$ 上一致收敛到 $f\equiv 0$（$\sup|f_n|\le 1/\sqrt n$），故 $\int_0^\pi f_n = (1-\cos n\pi)/\sqrt n\cdot(1/n)$ 趋于 $0=\int_0^\pi 0$。但若逐项求导：$f_n'(x)=\sqrt n\cos nx$，它不一致收敛，且 $f_n'(0)=\sqrt n\to\infty$，而 $f'(0)=0$——逐项求导失败。
结论：积分对一致收敛「宽容」，求导必须验证导数列本身一致收敛。
例：Weierstrass 判别法定理的应用。证明 $\sum_{n=1}^\infty \dfrac{\sin nx}{n^2}$ 在 $\mathbb R$ 上一致收敛。因 $\left|\frac{\sin nx}{n^2}\right|\le \frac1{n^2}$，而 $\sum 1/n^2$ 收敛，由 M-判别法函数项级数一致收敛。每项连续，故和函数连续；逐项积分合法。

11. 深度：勒贝格测度与积分 让「可测集」成为分析的新地基

定义（$\sigma$-代数与测度） 集 $X$ 上的 $\sigma$-代数 $\mathcal{M}$ 对可数并、补封闭；测度 $\mu:\mathcal{M}\to[0,\infty]$ 满足 $\mu(\bigcup E_i)=\sum\mu(E_i)$（不交并）。$\mathbb{R}^n$ 上的勒贝格测度延拓「区间体积」至极大类可测集。
定理（控制收敛定理） 若 $f_n\to f$ a.e. 且 $|f_n|\le g$（$g$ 可积），则 $$\lim\int f_n = \int\lim f_n = \int f.$$
思路：由 Fatou 引理 $\int f\le\liminf\int f_n$ 与 $\int(-f)\le\liminf\int(-f_n)$ 双向夹逼。这是勒贝格积分相对黎曼积分的决定性优势——极限与积分可交换的条件由「控制」给出。
例：枚举 $\mathbb{Q}\cap[0,1]=\{q_1,q_2,\dots\}$，定义 $f_n=\mathbf{1}_{\{q_1,\dots,q_n\}}$。则 $f_n\to\mathbf{1}_\mathbb{Q}$ 处处，$\int f_n=0$ 对所有 $n$，但 $\int\mathbf{1}_\mathbb{Q}=0$——控制收敛定理成立（被 $g=1$ 控制）。黎曼积分在 $\mathbf{1}_\mathbb{Q}$ 上根本不存在。

12. 深度：傅里叶变换与不确定性原理 信号在时频两个域里不能同时太窄

定义（傅里叶变换） $\hat f(\xi)=\int_{-\infty}^{\infty}f(x)e^{-2\pi i x\xi}\,dx$（$f\in L^1$）。反演公式 $f(x)=\int\hat f(\xi)e^{2\pi ix\xi}\,d\xi$ 在 $\hat f\in L^1$ 时几乎处处成立。
定理（Plancherel） $\|f\|_{L^2}=\|\hat f\|_{L^2}$；$\widehat{fg}=\hat f*\hat g$；$\widehat{f*g}=\hat f\cdot\hat g$。
注：这把卷积（难）变成乘法（易）——工程与纯数都依赖这条「时域卷积 = 频域乘积」。
定理（Heisenberg 不确定性原理） 对 $f\in L^2(\mathbb{R})$，$\|f\|_2=1$，记位置/动量方差 $\sigma_x^2=\int x^2|f|^2$、$\sigma_\xi^2=\int\xi^2|\hat f|^2$，则 $$\sigma_x\,\sigma_\xi\ge\frac{1}{4\pi}.$$ 等号成立当且仅当 $f$ 为高斯函数 $Ce^{-\pi ax^2}$。
思路：由 $\widehat{xf}=\frac{i}{2\pi}\partial_\xi\hat f$ 与柯西–施瓦茨 $\|xf\|\cdot\|f'\|\ge\frac12\|f\|^2$ 即得。物理诠释：粒子位置与动量不能同时精确——量子力学的数学基石。

13. 深度：Banach 不动点定理 在收缩映射里反复迭代，必收敛

定义（收缩映射） 完备度量空间 $(X,d)$ 上的映射 $T:X\to X$ 是压缩系数 $q<1$ 的收缩，若 $d(Tx,Ty)\le q\,d(x,y)$ 对所有 $x,y$ 成立。
定理（Banach 不动点 / 压缩映射原理） 收缩映射 $T$ 在 $X$ 上恰有一个不动点 $x^*$，且对任意 $x_0$，迭代 $x_{n+1}=T(x_n)$ 收敛到 $x^*$，速度 $$d(x_n,x^*)\le\frac{q^n}{1-q}\,d(x_0,x_1).$$
证明：先估 $d(x_n,x_{n+1})\le q^n d(x_0,x_1)$；用三角不等式与几何级数收敛得 $\{x_n\}$ 是柯西列；完备性给极限 $x^*$；连续性（$T$ 李普希茨）给 $T(x^*)=x^*$；唯一性由 $d(x^*,y^*)\le q\,d(x^*,y^*)\Rightarrow d=0$。
例：皮卡迭代解 ODE 初值问题 $y'=f(t,y),\,y(0)=y_0$。
解：等价于积分方程 $y(t)=y_0+\int_0^t f(s,y(s))\,ds$。若 $f$ 关于 $y$ 李普希茨（系数 $L$）且 $T$ 定义为右式映射，则在小区间上 $T$ 是收缩映射（$q=L\cdot T_0<1$）——皮卡迭代必收敛到唯一解。这是 ODE 存在唯一性定理的现代证明。

14. 深度：傅里叶分析与 Plancherel 定理 把函数拆成波

定义（傅里叶变换） 对 $f\in L^1(\mathbb{R})$，$\hat f(\xi)=\int_{-\infty}^{\infty}f(x)e^{-2\pi i x\xi}\,dx$。反演公式 $f(x)=\int\hat f(\xi)e^{2\pi i x\xi}\,d\xi$ 在 $\hat f\in L^1$ 时 a.e. 成立。
定理（Plancherel） $\mathcal F: L^1\cap L^2\to L^2$ 是等距（$\|\hat f\|_2=\|f\|_2$），延拓为 $L^2(\mathbb{R})\to L^2(\mathbb{R})$ 的酉同构。
思路：核 $K(x,y)=\mathrm{sinc}$ 满足 $\int K(x,t)K(y,t)\,dt=K(x,y)$（正交投影）；用 $g*f$ 卷积逼近，极化等式把内积关系从范数推出。
定理（Poisson 求和公式） 适当条件下 $\sum_{n\in\mathbb{Z}}f(n)=\sum_{n\in\mathbb{Z}}\hat f(n)$。
意义：这是「函数的采样」与「频谱的周期化」的对偶。由此可导出 $\theta$ 函数变换 $\theta(t)=t^{-1/2}\theta(1/t)$——这是模形式理论的物理直觉。
例：计算 $f(x)=e^{-\pi x^2}$ 的傅里叶变换。
解：$\hat f(\xi)=e^{-\pi\xi^2}$——高斯是傅里叶变换的不动点。证：$\hat f'(\xi)=-2\pi\xi\hat f(\xi)$ 配 $\hat f(0)=1$ 解出 $\hat f=e^{-\pi\xi^2}$。这推出测不准原理等号在 Gaussian 取到。

15. 深度：索伯列夫空间与弱导数 把「导数」放宽到不可导的函数

定义（弱导数） $u\in L^1_{\mathrm{loc}}(\Omega)$ 有 $\alpha$ 阶弱导数 $v$，若对所有 $\varphi\in C_c^\infty(\Omega)$ 有 $$\int_\Omega u\,D^\alpha\varphi\,dx = (-1)^{|\alpha|}\int_\Omega v\,\varphi\,dx.$$ 记 $v=D^\alpha u$。直觉：分部积分把导数「转移」到测试函数上。
定义（索伯列夫空间） $W^{k,p}(\Omega)=\{u\in L^p:\,D^\alpha u\in L^p,\,|\alpha|\le k\}$，范数 $\|u\|_{W^{k,p}}^p=\sum_{|\alpha|\le k}\|D^\alpha u\|_p^p$。$p=2$ 时 $H^k=W^{k,2}$ 是 Hilbert 空间。
定理（Sobolev 嵌入） 若 $kp>n$ 则 $W^{k,p}(\mathbb{R}^n)\hookrightarrow C^0(\mathbb{R}^n)$（Hölder 连续）。更精确地 $W^{k,p}\hookrightarrow L^q$ 对 $\frac1q=\frac1p-\frac{k}{n}$（$kp<n$ 时）。
思路：用 Gagliardo–Nirenberg 不等式 $\|u\|_{L^{p^*}}\le C\|Du\|_{L^p}$，$p^*=np/(n-p)$（临界 Sobolev 指数）。临界情形 $kp=n$ 失效但 Trudinger 替代为指数可积。
定理（Poincaré 不等式） 有界区域 $\Omega$ 上 $\|u-\bar u\|_{L^p}\le C\|Du\|_{L^p}$（$\bar u$ 为均值）。这给出 $W^{1,p}/\mathbb{R}$ 的离散谱，是椭圆算子的核心估计。
思路：紧嵌入 $W^{1,p}\hookrightarrow\hookrightarrow L^p$ + 反证法（否则可构造矛盾序列）。
例：阶梯函数 $u=\mathbf 1_{[0,\infty)}$ 在 $\mathbb{R}$ 上的弱导数。
解：$\int u\varphi'=-\int_{0}^{\infty}\varphi' = \varphi(0)=\int\delta_0\varphi$，故 $Du=\delta_0$（Dirac 测度）——不在 $L^1_{\mathrm{loc}}$ 中，故 $u\notin W^{1,1}_{\mathrm{loc}}$。但若用磨光核逼近，可定义 $H^{-1}$ 等负范数空间。

16. 练习与自测

练习 1：用 ε-δ 证明 $\lim_{x\to 2}(3x-1)=5$。
查看答案
答案：|(3x−1)−5| = 3|x−2| < ε 当 |x−2| < ε/3，取 δ = ε/3 即可。
练习 2：求 $\int x \ln x \,dx$。
查看答案
答案：分部积分 u = ln x, dv = x dx → $\int x \ln x \,dx$ = (x²/2)ln x − $\int (x^{2}/2)(1/x)\,dx$ = (x²/2)ln x − x²/4 + C。
练习 3：判断 Σ n/(n²+1) 收敛性。
查看答案
答案：发散。n/(n²+1) ~ 1/n，与调和级数同阶（极限比较判别法）。
练习 4：证明无理数的集合不可数。
查看答案
答案：ℝ = 有理数 ∪ 无理数。有理数可数，若无理数也可数则 ℝ 可数——矛盾（ℝ 不可数）。
练习 5：求 f(x) = x³ − 3x 在 [0,3] 的最大值与最小值。
查看答案
答案：f′ = 3x²−3 = 0 → x=1（x=−1 不在区间）。f(0)=0, f(1)=−2, f(3)=18。最大 18（x=3），最小 −2（x=1）。
练习 6：证明 sin x 的泰勒展开在实数轴上处处收敛到 sin x。
查看答案
答案：余项 Rₙ = sin⁽ⁿ⁺¹⁾(c) xⁿ⁺¹/(n+1)!，|sin⁽ⁿ⁺¹⁾| ≤ 1，故 |Rₙ| ≤ |x|ⁿ⁺¹/(n+1)! → 0 对任意固定 x。
练习 7：证明 $\mathbb{Q}\subset[0,1]$ 的勒贝格测度为 $0$。
查看答案
答案：枚举 $\mathbb{Q}\cap[0,1]=\{q_1,q_2,\dots\}$，用开区间 $I_n=(q_n-\epsilon/2^n,q_n+\epsilon/2^n)$ 覆盖，总长 $\le2\epsilon$。令 $\epsilon\to0$ 得测度为 $0$。
练习 8：求高斯函数 $f(x)=e^{-\pi x^2}$ 的傅里叶变换。
查看答案
答案：$\hat f(\xi)=e^{-\pi\xi^2}$——高斯函数是傅里叶变换的不动点。这也解释了它为何达到 Heisenberg 不等式的等号。
练习 9：用 Banach 不动点定理证明 $\cos x=x$ 在 $[0,1]$ 有唯一解。
查看答案
答案：$T(x)=\cos x$ 在 $[0,1]$ 上 $|T'(x)|=|\sin x|\le\sin1<1$，是收缩映射。从 $x_0=0$ 迭代收敛到不动点 $x^*\approx0.739$。
练习 10：解释为什么 $\mathbf{1}_\mathbb{Q}$ 黎曼不可积但勒贝格可积。
查看答案
答案：黎曼上下达布和：上和 $=1$（每个区间有有理点）、下和 $=0$（每个区间有无理点），不等。勒贝格：$\mathbb{Q}$ 测度 $0$，故 $\mathbf{1}_\mathbb{Q}=0$ a.e.，积分 $=0$。
练习 11：证 $\widehat{f*g}=\hat f\,\hat g$。
查看答案
答案：$\widehat{f*g}(\xi)=\iint f(x-y)g(y)e^{-2\pi i(x-y)\xi}e^{-2\pi iy\xi}\,dy\,dx=\hat f(\xi)\hat g(\xi)$（Fubini）。
练习 12：证 $u(x)=|x|^{1/2}$ 在 $(-1,1)$ 上属于 $H^s$ 当且仅当 $s<1$。
查看答案
答案：$Du\sim|x|^{-1/2}$ 在 $L^2$ 附近发散，但 $|x|^{1/2}\in L^2$。用 $|D^s u|^2\sim|x|^{1-2s}$ 积分 $\int|x|^{1-2s}dx$ 收敛当 $1-2s>-1$，即 $s<1$。临界 $s=1$ 是 Sobolev 嵌入阈值。
