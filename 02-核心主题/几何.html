1. 公理体系与三角形 几何从五条公设开始

定义（欧几里得五公设）：① 两点可连一直线；② 线段可任意延长；③ 以任意圆心半径可作圆；④ 所有直角相等；⑤ 平行公设：过直线外一点恰有一条平行线。第五公设最不「显然」——两千年后它成了非欧几何的入口。
定理（三角形内角和）：三角形内角和为 180°。
证明要点：过顶点作对边的平行线（用到平行公设），内错角相等，三个角拼成平角。非欧几何中此定理不成立——这正是「平行公设独立于其余公理」的证明手段之一。
定理（全等判据）：SAS、ASA、SSS、AAS（两边夹角、两角夹边、三边、两角一对边）。
直觉：这些判据回答「最少需要多少信息才能确定一个三角形」。SSA 不成立：已知两边与其中一边对角可能有两个三角形。
定理（相似判据）：AA（两角相等）⇒ 相似；SAS、SSS 比例版同理。
推论：平行线截三角形两边成比例（基本比例定理）——它是泰勒斯测量金字塔高度的原理。
例：泰勒斯测金字塔：同一时刻，若自己的影长=身高，则金字塔影长=金字塔高。这利用了相似三角形的等比性质。

2. 勾股定理的多种证明 三百种证明里挑三种思路

定理（勾股定理）：直角三角形两直角边 a、b 与斜边 c 满足 a² + b² = c²。
证明一（面积拼图，欧几里得《原本》I.47 的现代版）：以斜边为边作正方形，用「两直角三角形面积之和」补图：四个全等的直角三角形可拼成 c² 的大正方形（边长 a+b），内部留出 c² 的空正方形；同时拼出 a²+b² 的两个小正方形。
证明二（相似，Baskara）：作斜边上的高，得两个小直角三角形与大三角形相似，由比例 a² = c·p、b² = c·q（p+q=c）相加即得。
证明三（代数，坐标）：两向量 (a,b) 与 (−b,a) 垂直且等长，其端点距离平方 = a²+b²。
定义（勾股三元组）：满足 a²+b²=c² 的正整数。本原组公式：a=m²−n², b=2mn, c=m²+n²。
例：(3,4,5)、(5,12,13)、(8,15,17) 是最小的三个本原三元组。8²+15²=64+225=289=17² ✓

3. 圆：圆周角与幂 圆周上的角度定理家族

定理（泰勒斯定理）：直径所对的圆周角是直角。
证明要点：连接圆心与圆周上点，得两个等腰三角形，两底角之和为 90°（外角定理）。
定理（圆周角定理）：同弧上的圆周角相等，且等于圆心角的一半。
证明要点：圆心在角内时用等腰三角形外角定理；角跨弧时用加法。
定理（相交弦定理 / 割线定理 / 切线幂）：圆内两弦交于 P，则 PA·PB = PC·PD；圆外点 P 的割线满足 PA·PB = 常数（幂），切线长² = 幂。
证明要点：同一圆幂下，用相似三角形（圆周角定理保证角相等）证明比例式。
定理（托勒密定理）：圆内接四边形对角线乘积 = 两组对边乘积之和：AC·BD = AB·CD + BC·AD。
证明要点：在对角线上取点 E 使 ∠BAE=∠CAD，构造两组相似三角形，比例相乘相加即得。托勒密用它计算弦表（三角学的雏形）。
例：正五边形边长为 a、对角线为 d，托勒密定理给出 d² = a² + ad，即 d/a = φ（黄金比）。圆内接正五边形藏着黄金比例。

4. 解析几何与圆锥曲线 坐标系把几何变成代数

定义（笛卡尔坐标）：平面上的点 ↔ 有序数对 (x, y)；曲线 ↔ 方程。几何问题翻译成方程求解——这就是解析几何的纲领。
定义（圆锥曲线）：平面截圆锥所得的曲线族：圆、椭圆、抛物线、双曲线。统一方程：Ax² + Bxy + Cy² + Dx + Ey + F = 0。
定理（圆锥曲线的焦点定义）：椭圆 = 到两焦点距离之和为常数；双曲线 = 距离之差为常数；抛物线 = 到焦点与到准线距离相等。
例：抛物线 y² = 4px 的焦点在 (p, 0)，准线 x = −p。行星轨道（开普勒第一定律）是椭圆——太阳在焦点上。
定理（二次曲线分类）：判别式 B² − 4AC < 0 为椭圆型，= 0 为抛物型，> 0 为双曲型。
直觉：这是「坐标旋转归一化」的结论——适当旋转坐标系后 B 项消失，方程化成标准形。
例：求抛物线 y² = 8x 的焦点与准线。
查看答案
答案：4p = 8 → p = 2，焦点 (2, 0)，准线 x = −2。

5. 变换与对称 几何对象在变换下的不变性质

定义（等距变换）：保持距离的变换：平移、旋转、反射、滑移反射。两个图形合同 ⇔ 一个可由等距变换映到另一个。
分类定理：平面的等距变换恰好是这四种——反射是「原子」，其余由反射复合生成。
定义（相似变换）：距离按同一比例缩放：放大、缩小。两个图形相似 ⇔ 相似变换互映。
定理（对称群）：图形的对称构成群。正 n 边形的对称群是二面体群 Dₙ（2n 个元素）；正二十面体的对称群有 120 个元素（A₅）。
直觉：「保持图形不变的所有变换」在复合下封闭——这就是群论在几何中的起源，也是晶体学的基础（230 个空间群）。
例：正三角形的对称群 D₃ 有 6 个元素：3 个旋转 + 3 个反射。它同构于 S₃（3 个符号的置换群）。

6. 非欧几何 换掉平行公设，世界依然自洽

定理（双曲几何存在性）：过直线外一点可作无数条平行线，三角形内角和 < 180°。
模型（庞加莱圆盘）：把「直线」定义为圆盘内与边界正交的圆弧，则可验证全部欧氏公理除平行公设外成立——平行公设独立于其余公理（Bolyai、Lobachevsky，1820s）。
定理（椭圆几何存在性）：过直线外一点无平行线，三角形内角和 > 180°。
模型（球面几何）：球面上的「直线」是大圆：任何两个大圆都相交（无平行），球面三角形内角和确实大于 180°。
定理（黎曼几何与广义相对论）：黎曼把「度量」内化到流形：曲率随点变化，光沿测地线走。爱因斯坦用弯曲时空解释引力——欧几里得几何的「唯一真理」地位被黎曼几何取代。
直觉：在小尺度上双曲/球面几何都接近欧氏——所以日常测量不受影响；在大尺度/强引力下才显差异。
例：球面三角形：赤道上取两点 A、B（经度差 90°），再取北极 N，则三角形 ANB 的三个角都是 90°，内角和 270° > 180°。

7. 多面体与欧拉公式 拓扑的第一个定理

定理（欧拉公式）：任何凸多面体 V − E + F = 2。
证明要点：把多面体表面「吹成球面」，三角剖分后用归纳删三角形——V−E+F 是拓扑不变量（这就是第 4 章「意外连接」页中的拓扑证明）。
定理（柏拉图立体分类）：正多面体恰有 5 个：正四面体、正六面体（立方体）、正八面体、正十二面体、正二十面体。
证明要点：每个顶点汇合 r 个正 p 边形，由 V−E+F=2 与计数（pF = 2E = rV）推出 (p−2)(r−2) < 4 的整数解只有 (3,3),(3,4),(4,3),(3,5),(5,3)。
例：正十二面体：V=20, E=30, F=12，V−E+F = 20−30+12 = 2 ✓ 对偶关系：立方体 ↔ 正八面体，正十二面体 ↔ 正二十面体，正四面体自对偶。

8. 分形几何 无穷细节的几何

定义（自相似）：整体与部分相似。科赫雪花：每条线段替换为 4 段（每段长 1/3），无限迭代——周长趋于无穷而面积有限。
定义（豪斯多夫维数）：若把图形放大 k 倍需要 N 份小拷贝拼成，则维数 d = log N / log k。科赫雪花 d = log 4 / log 3 ≈ 1.26——介于线与面之间。
例：线段：放大 3 倍需 3 份 → d=1；正方形：放大 3 倍需 9 份 → d=2。分形允许非整数维。
定理（曼德博集合）：迭代 z ← z² + c（从 z=0 出发），c 使得迭代有界的所有复数值构成曼德博集合——一个边界无限复杂、自相似的分形。
直觉：集合边界每放大一次都出现新的细节——它是「简单规则产生复杂结构」的标志性对象。去可视化页亲手缩放。
例：Sierpinski 三角形：每次去掉中心倒三角，d = log 3 / log 2 ≈ 1.585。

9. 深度专题：欧氏几何的公理体系 从欧几里得到希尔伯特

《几何原本》的五条公设在严格性上并不完整：欧几里得默认了「介于」「合同」「连续」等未定义概念。希尔伯特 1899 年在《几何基础》中用五组公理完成了欧氏几何的公理化。

希尔伯特五组公理： ① 关联公理（I）：两点确定唯一直线；直线上至少两点；不共线三点存在； ② 顺序公理（II）：点 $B$ 介于 $A,C$ 之间记作 $A*B*C$，保证直线上的「中间性」； ③ 合同公理（III）：线段可搬移、角可搬移、SAS 合同； ④ 平行公理（IV）：过直线外一点至多一条平行线； ⑤ 连续公理（V）：阿基米德公理 + 完备性公理（直线上点与实数一一对应）。
定理（三角形内角和）：在公理 I–IV 下，三角形内角和 $\le \pi$；加上平行公理后等于 $\pi$。
证明思路：由平行公理的等价形式「过 $A$ 作 $BC$ 的平行线」，利用内错角相等把三个内角拼成一个平角。若删去 IV，得到的绝对几何中内角和仍 $\le\pi$；黎曼几何中则严格 $>\pi$。
定理（公理独立性）：第五组连续公理中阿基米德公理不与 I–IV 独立吗？——非阿基米德几何（希尔伯特的例）证明 I–IV 本身相容，可在其上构造出「无穷小线段」而不引入矛盾。这说明平行公设才是欧氏/非欧的分水岭，而非连续性。
例：从公理证「对顶角相等」。设两直线交于 $O$，$A,B$ 在一直线两侧，$C,D$ 在另一直线两侧。由直线上点的顺序，$\angle AOC$ 与 $\angle BOD$ 分别与 $\angle COB$ 互补（合同公理 III 的邻补角定理），故 $\angle AOC=\pi-\angle COB=\angle BOD$。整个证明不涉及「角度数值」，纯由合同关系推出。

10. 深度专题：微分几何入门 曲率与测地线

定义（曲面第一/第二基本形式）：参数曲面 $\mathbf r(u,v)$ 的第一基本形式度量弧长： $$I = E\,du^2 + 2F\,du\,dv + G\,dv^2, \quad E=\mathbf r_u\!\cdot\!\mathbf r_u,\ F=\mathbf r_u\!\cdot\!\mathbf r_v,\ G=\mathbf r_v\!\cdot\!\mathbf r_v.$$ 第二基本形式度量弯曲：$II = L\,du^2+2M\,du\,dv+N\,dv^2$，其中 $L=\mathbf r_{uu}\!\cdot\!\mathbf n$，$\mathbf n$ 为单位法向量。
定义（主曲率、高斯曲率、平均曲率）：在每点，法曲率 $k_n$ 随切方向转动；其两个极值 $k_1,k_2$ 称主曲率。高斯曲率 $K=k_1 k_2 = (LN-M^2)/(EG-F^2)$，平均曲率 $H=(k_1+k_2)/2$。
高斯绝妙定理（Theorema Elegantissima）：$K$ 只依赖第一基本形式 $I$，即只依赖曲面上的内蕴度量，与曲面如何嵌入 $\mathbb R^3$ 无关。
意义：高斯曲率是「曲面自己」的几何——纸平面（$K=0$）无论怎么折都不能贴到球（$K=1/R^2$）上而不撕裂或拉伸，这就是地图不能完美平面化的数学原因。
定义（测地线）：曲面上局部长度最短的曲线，其测地曲率恒为零。局部坐标下满足欧拉–拉格朗日方程 $$\frac{d^2 u^k}{ds^2} + \Gamma^k_{ij}\frac{du^i}{ds}\frac{du^j}{ds}=0,$$ 其中 $\Gamma^k_{ij}$ 由 $E,F,G$ 及其一阶导数算出（克里斯托费尔符号）。
例：球面 $r=R$ 上的测地线是大圆。球面参数化 $\mathbf r(\theta,\varphi)=R(\sin\theta\cos\varphi,\sin\theta\sin\varphi,\cos\theta)$，第一基本形式 $I=R^2 d\theta^2 + R^2\sin^2\theta\,d\varphi^2$。沿 $\varphi=\text{const}$ 的经线，切向量 $d\mathbf r/ds$ 与法向量平行，法曲率 $k_n=1/R$，测地曲率为 $0$，故经线是测地线。由旋转对称，一切过极点的大圆都是测地线。两大圆在两个对径点相交——「平行线」在球面上会「相交两次」，这正是球面三角内角和 $>\pi$ 的几何来源。
验证：北半球一条经线上两点 $(\theta_1,\varphi),(\theta_2,\varphi)$ 的弧长 $=R|\theta_2-\theta_1|$，沿纬线绕行的长度 $=2\pi R\sin\theta$，在 $\theta=\pi/2$ 时才等于赤道大圆——直观确认大圆最短。

11. 深度专题：庞加莱圆盘模型 非欧几何的严格模型

定义（庞加莱圆盘）：单位开圆盘 $\mathbb D=\{z\in\mathbb C:|z|<1\}$，配以双曲度量 $$ds^2 = \frac{4\,|dz|^2}{(1-|z|^2)^2}.$$ 两点 $z,w$ 的双曲距离为 $$d(z,w)=2\,\operatorname{artanh}\left|\frac{z-w}{1-\bar z w}\right|.$$
定理：此模型满足除平行公设外的全部希尔伯特公理，且过直线外一点可作无穷多条「平行线」。
证明思路：模型中的「直线」是与单位圆正交的圆弧（或直径）。给定一条「直线」$L$ 和圆外一点 $p$，过 $p$ 可作无穷多条与 $L$ 不相交的正交圆弧——这就是罗巴切夫斯基几何的具体实现，证明非欧几何相对相容（若欧氏几何相容则非欧几何相容）。
定理（双曲三角形内角和）：双曲三角形内角和严格小于 $\pi$，且面积 $=\pi-(\alpha+\beta+\gamma)$。
意义：与球面 $K=1$ 时「面积 $=\alpha+\beta+\gamma-\pi$」对偶，这正是高斯曲率 $K=-1$ 时 Gauss–Bonnet 公式的特例。
例：测地距离的直接计算。求圆心到点 $r\in(0,1)$ 的双曲距离。沿直径积分： $$d(0,r)=\int_0^r \frac{2\,dt}{1-t^2} = \ln\frac{1+r}{1-r}.$$ 当 $r\to 1^-$，距离 $\to +\infty$——圆盘「边界」在双曲意义下无穷远。再验证 $d(0,r)=2\operatorname{artanh} r$，与定义公式一致（令 $z=0,w=r$：$2\operatorname{artanh}|r|$）。

12. 深度：射影几何与对偶原理 把「平行」从几何里删掉，世界更对称

定义（射影平面） 实射影平面 $\mathbb{P}^2$ 把欧氏平面添上一条「无穷远直线」，使任意两条直线恰相交于一点。等价地，$\mathbb{P}^2$ 是 $\mathbb{R}^3\setminus\{0\}$ 在 $v\sim\lambda v$（$\lambda\ne0$）下的商。
定理（对偶原理） 在 $\mathbb{P}^2$ 中，每条关于点与线的命题 $P$ 都对偶于把「点」与「线」互换、把「过」与「在...上」互换后得到的命题 $P^*$，且 $P$ 成立当且仅当 $P^*$ 成立。
直觉：齐次坐标下点 $(x_0,x_1,x_2)$ 与线 $[l_0,l_1,l_2]$ 的关联条件 $\sum l_i x_i=0$ 关于对换点/线完全对称。所以 $P$ 的证明逐字翻译即得 $P^*$ 的证明。
例（德沙格定理） 若两三角形对应顶点连线共点，则对应边交点共线（德沙格定理），其对偶是自身的逆——这种自对偶性揭示了二维与三维射影空间的深刻结构。
注：德沙格定理在高维射影空间可证（用三维的投影），但在 $\mathbb{P}^2$ 内不能从射影公理独立证明——这催生了「非德沙格平面」的反例研究。

13. 深度：微分几何初步——曲率与挠率 沿曲线走一步，方向变多少

定义（Frenet 标架） 弧长参数化曲线 $\gamma(s)$，单位切向量 $T=\gamma'$，法向 $N=T'/\|T'\|$，副法向 $B=T\times N$。三量 $\kappa=\|T'\|$（曲率）、$\tau=-B'\cdot N$（挠率）完全确定曲线（至刚体运动）。
定理（Frenet–Serret 公式） $$T' = \kappa N, \quad N' = -\kappa T + \tau B, \quad B' = -\tau N.$$
推导：$T'=\kappa N$ 是定义；$N\perp T$ 且 $\|N\|=1$ 给 $N'\perp N$，故 $N'=aT+bB$；由 $T'\cdot N=\kappa$ 与 $(T\cdot N)'=0$ 得 $a=-\kappa$；$b$ 由 $B$ 的定义推得 $b=\tau$；$B'=-\tau N$ 由 $B=T\times N$ 求导得到。
例：圆 $\gamma(s)=(R\cos(s/R),R\sin(s/R),0)$ 的 $\kappa$ 与 $\tau$。
解：$T=(-\sin(s/R),\cos(s/R),0)$，$T'=\frac{1}{R}(\cos,\sin,0)=\frac{1}{R}N$，故 $\kappa=1/R$。$B=(0,0,1)$ 常向量，$B'=0$，故 $\tau=0$——圆是平面曲线。

14. 深度：双曲几何的庞加莱模型 在圆盘里画直线，但直的是弯的

定义（庞加莱圆盘） 开圆盘 $\mathbb{D}=\{z:|z|<1\}$ 中，「测地线」（双曲直线）是与边界 $\partial\mathbb{D}$ 正交的圆弧或直径。庞加莱度量 $ds=\frac{2|dz|}{1-|z|^2}$ 使每条测地线长度无限。
定理（双曲平行公理） 过「直线」外一点存在无穷多条不与该直线相交的「直线」——与欧氏平行公理相反。
构造：设测地线 $L$ 与外点 $P$。作两条与 $L$ 在端点处「平行」（端点相同但不相交）的测地线，它们与 $L$ 均无交点；这两条之间还容得下无穷多条。
定理（高斯曲率恒为 $-1$） 庞加莱圆盘在度量 $ds$ 下高斯曲率 $K\equiv-1$。
注：这把「负曲率」几何实现为具体的复分析对象——$\mathrm{PSL}(2,\mathbb{R})$ 的作用保持 $ds$，成为双曲几何与模形式理论的桥梁。

15. 深度：黎曼几何与高斯–博涅定理 曲率与拓扑的深刻联系

定义（黎曼度量） 光滑流形 $M$ 上的黎曼度量 $g$ 是每点切空间上的正定对称双线性形式。$(M,g)$ 称黎曼流形。度量决定长度 $L(\gamma)=\int\sqrt{g_{\gamma}\dot\gamma\cdot\dot\gamma}\,dt$、面积元、体积形式等。
定义（截面曲率） 对切平面 $\sigma=\mathrm{span}(X,Y)$，截面曲率 $K(\sigma)=\frac{\langle R(X,Y)Y,X\rangle}{|X|^2|Y|^2-\langle X,Y\rangle^2}$，$R$ 为曲率张量。直觉：「沿 $\sigma$ 切出的测地三角形的内角和」偏离 $\pi$ 由 $K$ 决定。
定理（高斯–博涅局部） 紧有界区域 $D\subset M$，边界 $\partial D$ 由分段光滑测地线组成，则 $$\int_D K\,dA + \sum_i\alpha_i = 2\pi\chi(D),$$ 其中 $\alpha_i$ 为外角，$\chi$ 为 Euler 示性数。
思路：用活动标架把 $dA$ 表成 $\omega_1\wedge\omega_2$，结构方程给出 $d\omega_{12}=K\omega_1\wedge\omega_2$，Stokes 定理把边界贡献化为 $\int K\,dA$ 加角修正。
定理（高斯–博涅整体） 紧曲面 $M$ 无边界时 $\int_M K\,dA = 2\pi\chi(M)$。故 $\chi(M)$ 由曲率积分决定——这是「曲率决定拓扑」的最早范例。
例：球面 $S^2$，$K\equiv1$，$\int K\,dA=4\pi=2\pi\cdot2$，$\chi(S^2)=2$。环面 $T^2$ 上 $\int K\,dA=0=2\pi\cdot0$，$\chi=0$——但 $T^2$ 的 $K$ 有正有负。
例：计算双曲面 $\{(x,y,z):x^2+y^2-z^2=1\}$ 的截面曲率符号。
解：参数化为 $r(u,v)=(\cosh u\cos v,\cosh u\sin v,\sinh u)$，第一基本形式 $g=\cosh(2u)\,du^2+\cosh^2u\,dv^2$（$E=\sinh^2u+\cosh^2u=\cosh 2u$，$G=\cosh^2u$，$F=0$）。旋转面曲率公式给 $$K=-\frac{r''z'-r'z''}{r\bigl((r')^2+(z')^2\bigr)^2}=-\frac{\cosh^2u-\sinh^2u}{\cosh u\cdot\cosh^2(2u)}=-\frac1{\cosh u\cdot\cosh^2(2u)}<0,$$处处为负。面积元 $dA=\cosh u\sqrt{\cosh 2u}\,du\,dv$，故 $K\,dA=-\operatorname{sech}^{3/2}(2u)\,du\,dv$ 在整个曲面上可积（总曲率为有限负值；非紧整体高斯–博涅定理需对端（end）附加条件）。

16. 深度：代数几何初步——簇与概形 用方程画几何，用几何读方程

定义（仿射簇） 给定域 $k$ 与多项式族 $S\subset k[x_1,\dots,x_n]$，$S$ 的公共零点集 $$V(S)=\{P\in\mathbb{A}^n_k: f(P)=0,\,\forall f\in S\}$$ 称仿射簇。$\mathbb{A}^n_k$ 为仿射 $n$ 空间。$S$ 生成的理想 $I=(S)$ 决定同一簇，$V$ 与 $I$ 是 Galois 联系。
定理（Hilbert 零点定理） 若 $k$ 代数闭，则 $V(I)=\emptyset$ 当且仅当 $I=(1)$。更精确地：$I(V(J))=\sqrt{J}=\{f:f^m\in J\text{ 对某 }m\}$。这建立 $\{\text{簇}\}\leftrightarrow\{\text{根式理想}\}$ 的一一对应（仿射情形）。
思路：Hilbert 用「基定理」证多项式理想有限生成，再用「Rabinowitsch 技巧」化一般情形到无解情形。
定理（Bézout 定理） 在 $\mathbb{P}^2_k$ 上，次数 $m,n$ 的两条无公共分量曲线恰在 $mn$ 个点（计重数）相交。
意义：把「几何相交数」化为「代数乘积」——这是代数几何的中心思想。射影化保证有交点（无穷远补上）。
例：椭圆 $x^2/a^2+y^2/b^2=1$ 与直线 $y=c$ 的交点。
解：代入得 $x^2=a^2(1-c^2/b^2)$。$|c|<b$ 时两实交点 $(\pm a\sqrt{1-c^2/b^2},c)$；$c=\pm b$ 时重根（切线）；$|c|>b$ 时无实交点，但在 $\mathbb{C}$ 上仍有两个（共轭）交点——Bézout 保证恰 2 个（计重数）。
