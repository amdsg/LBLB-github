1. 一阶方程的基本解法 分离、线性、恰当

定义：一阶方程 dy/dx = f(x,y)。可分离：f = g(x)h(y)，两边积分。线性：y′ + p(x)y = q(x)。
定理（积分因子法）：线性方程 y′ + p(x)y = q(x) 乘以积分因子 μ = $e^{\int p dx}$ 后化为 (μy)′ = μq，积分即得解。
证明要点：选 μ 使 μy′ + μpy = (μy)′，即 μ′ = μp——微分方程变成导数链式法则，一步求积。
定理（恰当方程）：M dx + N dy = 0 是恰当方程（存在 F 使 dF = M dx + N dy）⟺ Mᵧ = Nₓ。
证明要点：混合偏导相等（克莱罗定理）。解为 F(x,y) = C。
例：求 y′ = 2x 且 y(0) = 1。
查看答案
答案：y = x² + C，y(0) = 1 → C = 1，y = x² + 1。
例：求 y′ + y = $e^{-x}$ 的通解。
查看答案
答案：μ = eˣ，(eˣy)′ = 1 → eˣy = x + C → y = $xe^{-x}$ + $Ce^{-x}$。

2. 存在唯一性定理 微分方程什么时候「有解」且「只有一解」

定理（皮卡-林德勒夫定理）：若 f 连续且对 y 满足利普希茨条件（|f(x,y₁)−f(x,y₂)| ≤ L|y₁−y₂|），则初值问题 y′ = f(x,y)、y(x₀) = y₀ 在 x₀ 附近有唯一解。
证明要点（皮卡迭代）：定义迭代 yₙ₊₁(x) = y₀ + $\int f(x,y_{n})\,dx$；用压缩映射定理（巴拿赫不动点）证明迭代收敛到唯一解——泛函分析第一次进入微分方程。
定理（解对初值的连续依赖）：初值微小变化 → 解在有限区间内微小变化。
意义：这是「物理系统可预测」的数学保证，也是数值方法可靠的前提。
例：y′ = √y 过 (0,0) 不唯一：y ≡ 0 与 y = x²/4 都是解——因为 √y 在 0 处不满足利普希茨条件。

3. 二阶线性方程与振动 弹簧、摆与电路

定义：ay″ + by′ + cy = 0（常系数齐次）。特征方程 a r² + b r + c = 0。
定理（特征方程法）：特征根 r₁ ≠ r₂：y = C₁e^(r₁x) + C₂e^(r₂x)；重根 r：y = (C₁ + C₂x)$e^{rx}$；共轭复根 α±βi：y = $e^{αx}$(C₁cos βx + C₂sin βx)。
证明要点：试解 y = $e^{rx}$ 代入得特征方程；重根时第二解 $xe^{rx}$（降阶法）。
定理（谐振子）：x″ + ω²x = 0 的解为 x = A cos(ωt + φ)——周期 T = 2π/ω 与振幅无关（等时性）。
应用：钟摆小角度近似、弹簧、LC 电路都归于此。阻尼项 → 特征根变复/变实 → 衰减振动或过阻尼。
定理（非齐次与共振）：y″ + ω²y = F₀cos(Ωt)：Ω = ω 时振幅线性增长（共振）；否则解 = 齐次解 + 特定特解。
例：军队过桥踏步频率等于桥固有频率时桥会塌——共振的工程教训。
例：求 y″ − 3y′ + 2y = 0 的通解。
查看答案
答案：r²−3r+2 = 0 → r = 1, 2，y = C₁eˣ + C₂e²ˣ。

4. 常系数方程组与矩阵 把多个方程看成向量方程

定义：x′ = Ax（A 为常数矩阵，x 为向量）。试解 x = $ve^{λt}$：Av = λv——解由特征值、特征向量给出。
定理（矩阵指数）：x(t) = $e^{At}$x(0)，其中 $e^{At}$ = Σ (At)ⁿ/n!。
证明要点：与标量 e 的级数完全平行；对角化时 $e^{At}$ = $Pe^{Dt}$P⁻¹，$e^{Dt}$ 是对角元 $e^{λ^{i}t}$。
定理（特征值判定）：Re(λᵢ) < 0 全部 → 解趋于 0（稳定）；有 Re > 0 → 发散（不稳定）；实部为 0 → 临界（振荡）。
例：x′ = [[0,1],[−1,0]]x：特征值 ±i，解是圆周运动（中心型）。
例：求 x′ = [[1,0],[0,2]]x 的通解。
查看答案
答案：x = (C₁eᵗ, C₂e²ᵗ)——对角阵直接解耦。

5. 拉普拉斯变换 把微分方程变成代数方程

定义：L{f}(s) = ∫₀^∞ f(t)$e^{-st}$ dt。核心性质：L{f′} = sL{f} − f(0)——求导变乘法。
定理（变换表）：L{1} = 1/s；L{$e^{at}$} = 1/(s−a)；L{sin ωt} = ω/(s²+ω²)；L{tⁿ} = n!/sⁿ⁺¹。
证明要点：直接积分（分部积分处理 tⁿ）。
定理（解初值问题的流程）：① 两边拉氏变换 → 代数方程；② 解出 L{y}；③ 部分分式分解 + 反变换表 → y(t)。
优势：自动处理初值、处理分段输入（阶跃、脉冲 δ）、处理非齐次项，无需先求通解再定常数。工程首选。
例：用拉氏变换解 y′ + y = 1，y(0) = 0。
查看答案
答案：sL{y} + L{y} = 1/s → L{y} = 1/(s(s+1)) = 1/s − 1/(s+1) → y = 1 − $e^{-t}$。

6. 数值方法 算不出解析解，就步步逼近

定义（欧拉法）：yₙ₊₁ = yₙ + h·f(xₙ, yₙ)——用切线前进一步，步长 h。局部误差 O(h²)，全局 O(h)。
定理（龙格-库塔法）：经典四阶 RK4 在每个步长内做 4 次斜率估计加权平均，全局误差 O(h⁴)。
意义：工程与科学计算的事实标准（如 Python scipy 的 ode45 变体）。
定理（数值稳定性）：刚性方程（特征值实部大负）需要隐式方法（如隐式欧拉、后向差分），显式方法会数值爆炸。
例：y′ = −100y：显式欧拉要求 h < 0.02 才稳定——隐式方法无此限制。
例：欧拉法解 y′ = y、y(0) = 1、h = 0.5，两步后 y ≈ ?
查看答案
答案：y₁ = 1 + 0.5×1 = 1.5；y₂ = 1.5 + 0.5×1.5 = 2.25（真实 e¹ = 2.718，误差约 17%——欧拉法粗糙，但原理简单）。

7. 稳定性与相图 不解方程也知长期行为

定义（相图）：把 (x, x′) 画成平面，解是轨道。平衡点 = 不动点（x′ = 0）。稳定节点 / 鞍点 / 螺旋 / 中心按特征值分类。
定理（李雅普诺夫稳定性）：若存在正定函数 V 使 V′ < 0，则平衡点渐近稳定——不需要解方程就能判定稳定性。
意义：非线性系统（摆、种群）的稳定性分析靠它；「能量下降 → 系统收敛」。
定理（洛特卡-沃尔泰拉模型）：捕食者-被捕食者系统有周期解：x′ = x(a−by), y′ = y(−c+dx)。
例：加拿大猞猁与雪兔毛皮收购量记录的 10 年周期振荡——相图是围绕平衡点的闭合圈。
例：逻辑斯蒂方程 dx/dt = rx(1−x/K)：平衡点 0（不稳定）与 K（稳定）——种群趋于环境容量 K。

8. 偏微分方程 多元世界的方程

定义（三大经典方程）：热传导 uₜ = k uₓₓ；波动 uₜₜ = c²uₓₓ；拉普拉斯 Δu = 0。分别描述扩散、传播与平衡。
定理（分离变量法）：设 u = X(x)T(t)，代入 PDE 化为两个 ODE，用边界条件定特征值（Sturm–Liouville 问题），叠加级数得解。
例：两端固定的弦振动 u(x,t) = Σ sin(nπx/L)(Aₙcos(ωₙt) + Bₙsin(ωₙt))——傅里叶级数正是分离变量法的自然产物。
定理（纳维-斯托克斯方程）：流体运动方程——其三维光滑解的存在性是七个千禧难题之一，2026-09 仍有「声称证明但未复核」的事件（见前沿页）。
难处：非线性 + 粘性 + 高维相互作用；湍流现象至今是数学物理最深的开放问题之一。
例：一维热传导在无穷直线上的解：u(x,t) = (1/√(4πkt))∫ f(ξ)$e^{-(x-ξ)^{2}/(4kt)}$dξ——初始温度被高斯核「抹平」。

9. 深度专题：Picard 存在唯一性定理严格证明 逐次逼近法

定理（Picard–Lindelöf）：设 $f(x,y)$ 在矩形 $R=[x_0-a,x_0+a]\times[y_0-b,y_0+b]$ 上连续，且对 $y$ 满足 Lipschitz 条件： $$|f(x,y_1)-f(x,y_2)|\le L|y_1-y_2|.$$ 则初值问题 $y'=f(x,y),\ y(x_0)=y_0$ 在区间 $|x-x_0|\le h$ 上存在唯一解，其中 $h=\min\{a,b/M\}$，$M=\max_R|f|$。
证明思路（压缩映射原理）：方程等价于积分方程 $y(x)=y_0+\int_{x_0}^x f(t,y(t))\,dt$。构造 Picard 迭代 $y_{n+1}(x)=y_0+\int_{x_0}^x f(t,y_n(t))\,dt$，$y_0(x)\equiv y_0$。在 $C([x_0-h,x_0+h])$ 上赋予加权范数 $\|y\|_\lambda=\sup e^{-2\lambda L|x-x_0|}|y(x)|$，积分算子 $T$ 满足 $$\|Ty-Tz\|_\lambda\le \tfrac1{2\lambda}\|y-z\|_\lambda,$$ 取 $\lambda>1$ 即压缩，故有唯一不动点。这同时给出存在性与唯一性。
例：$y'=y^2,\ y(0)=1$ 的 Picard 迭代与爆裂时间。积分方程 $y(x)=1+\int_0^x y(t)^2\,dt$。迭代：$y_0=1$；$y_1=1+\int_0^x 1\,dt=1+x$；$y_2=1+\int_0^x(1+t)^2dt=1+x+x^2+\tfrac13 x^3$；$y_3=1+x+x^2+x^3+\tfrac{2}{3}x^4+\cdots$。精确解为 $y=1/(1-x)$，其 Taylor 级数 $\sum_{n\ge0}x^n$ 在 $|x|<1$ 收敛。
意义：迭代式正是几何级数逐项展开；解在 $x=1$ 处爆破，Picard 定理保证 $h<1$ 区间内唯一，超出后无法延拓到全局——非线性方程的解可以有限时间「逃向无穷」。
例：Lipschitz 条件不满足的反例。$y'=2\sqrt{|y|},\ y(0)=0$。$f$ 连续但在 $y=0$ 不满足 Lipschitz（$|\sqrt y_1-\sqrt y_2|/|y_1-y_2|=1/\sqrt{|\cdot|}\to\infty$）。解不唯一：$y\equiv 0$ 与 $y(x)=\begin{cases}0&x\le c\\(x-c)^2&x>c\end{cases}$（任意 $c\ge 0$）都是解——这正是 Lipschitz 条件不可或缺的反例。

10. 深度专题：线性系统稳定性与李雅普诺夫方法 不解方程也知长期行为

定义（李雅普诺夫稳定 / 渐近稳定）：平衡点 $x_e$ 称为稳定的，若 $\forall\varepsilon>0,\exists\delta>0$ 使 $|x(0)-x_e|<\delta\Rightarrow |x(t)-x_e|<\varepsilon\ (\forall t\ge0)$；若进一步 $x(t)\to x_e$，称渐近稳定。
定理（线性系统特征值判据）：线性系统 $\dot x=Ax$ 的零解渐近稳定 $\iff$ $A$ 的所有特征值实部 $<0$；稳定（但不渐近）$\iff$ 所有特征值实部 $\le 0$，且实部为 $0$ 的特征值对应的 Jordan 块都是 $1\times 1$ 的（半单）。
证明思路：用 Jordan 标准形 $A=PJP^{-1}$，解 $x(t)=e^{At}x_0=P e^{Jt}P^{-1}x_0$。每个 Jordan 块贡献 $e^{\lambda t}t^k$ 项；$\operatorname{Re}\lambda<0$ 时指数衰减压过多项式增长；$\operatorname{Re}\lambda=0$ 时若 $k\ge1$ 则 $t^k$ 使解无界。
定理（李雅普诺夫直接法）：若存在连续可微正定函数 $V(x)$（$V(0)=0$，$V(x)>0$ 当 $x\neq0$）使沿轨线 $\dot V=\nabla V\cdot f(x)\le 0$，则零解稳定；若 $\dot V<0$（$x\neq0$），则渐近稳定。
证明思路：$V$ 是「能量」，$\dot V\le 0$ 意味着能量不增，故轨线被闭曲面 $V=c$ 包住，无法远离原点。这无需解出方程。
例：阻尼谐振子的稳定性。系统 $\ddot x + 2c\dot x + k x=0$（$c,k>0$）。相平面 $(x,y=\dot x)$ 下 $\dot x=y,\ \dot y=-kx-2cy$。取能量 $V(x,y)=\tfrac12 y^2+\tfrac12 k x^2$（总机械能），则 $$\dot V = y\dot y + kx\dot x = y(-kx-2cy)+kxy = -2c y^2\le 0.$$ 由拉萨尔不变集原理，轨线收敛到 $\dot V=0$ 的最大不变集 $\{y=0\}$，而 $\{y=0\}$ 中只有 $x=0$ 是平衡点，故零解渐近稳定。
对照：无阻尼 $c=0$ 时 $\dot V\equiv 0$，轨线在 $V=$ 常数的椭圆上周期运动——李雅普诺夫稳定但不渐近稳定。特征值 $-c\pm\sqrt{c^2-k}$ 的实部严格 $<0$ 与上面分析一致。

11. 深度：稳定性与 Lyapunov 函数 不用解方程，就能判断解是否稳定

定义（Lyapunov 稳定） 平衡点 $x^*$（$f(x^*)=0$）稳定，若初值近时解一直近；渐近稳定，若还收敛到 $x^*$。
定理（Lyapunov 直接法） 若存在正定 $V$（$V(x^*)=0$，$V>0$ 否则）且 $\dot V=\nabla V\cdot f\le0$（半负定），则 $x^*$ 稳定；若 $\dot V<0$（$x\ne x^*$），则渐近稳定。
直觉：$V$ 是「广义能量」，能量单调下降必有极限；极限处 $\dot V=0$，故 $f=0$——平衡点。
例：$\dot x=-V'(x)$（梯度流）。取 Lyapunov 函数即势函数 $V(x)$，$\dot V=V'\dot x=-|V'|^2\le0$。任何极小点都是渐近稳定平衡——机器学习梯度下降的理论根据。

12. 深度：Sturm–Liouville 边值问题 把边值问题变成「正交基的特征值」

定义（S-L 问题） $(py')'+(\lambda r-q)y=0$，$y(a)=y(b)=0$（或其他边界）。自伴算子 $L=\frac1r\left[-\frac{d}{dx}(p\frac{d}{dx})+q\right]$。
定理（谱定理） S-L 问题有可数无穷实特征值 $\lambda_1<\lambda_2<\dots\to\infty$，对应特征函数 $\{y_n\}$ 在加权 $L^2$ 中完备正交：$\int_a^b r y_my_n=\delta_{mn}$。任意 $f\in L^2_r$ 可展为 Fourier 级数 $f=\sum c_n y_n$。
注：这是「傅里叶级数」的极大推广——$\sin nx/\cos nx$、Legendre、Hermite、Laguerre 多项式都是 S-L 特征函数。量子力学中薛定谔算子正是 S-L 算子。

13. 深度：PDE 的分类与特征线 二阶 PDE 三大类型：椭圆、抛物、双曲

定理（二阶线性 PDE 分类） $Au_{xx}+2Bu_{xy}+Cu_{yy}+\dots=0$ 按判别式 $B^2-AC$ 分类：$>0$ 双曲（波方程），$=0$ 抛物（热方程），$<0$ 椭圆（拉普拉斯方程）。三种类型解的性质截然不同。
直觉：双曲有「有限传播速度」（信息沿特征线传播）；抛物有「无限传播但指数衰减」；椭圆「整体瞬时影响」（边界决定内部）。
例：波方程 $u_{tt}=c^2u_{xx}$（双曲，特征线 $x\pm ct$）；热方程 $u_t=\alpha u_{xx}$（抛物）；拉普拉斯 $u_{xx}+u_{yy}=0$（椭圆，解为调和函数，最大值原理成立）。

14. 深度：动力系统与李雅普诺夫稳定性 什么时候解会「待在附近」

定义（李雅普诺夫稳定） 平衡点 $x^*$：① 稳定——$\forall\epsilon>0,\exists\delta>0$ 使 $\|x_0-x^*\|<\delta\Rightarrow\|\phi_t(x_0)-x^*\|<\epsilon$（$\forall t\ge0$）；② 渐近稳定——还要求 $\phi_t(x_0)\to x^*$。
定义（李雅普诺夫函数） $V:U\to\mathbb R$ 在 $x^*$ 正定，$V(x^*)=0$；$\dot V(x)=\nabla V\cdot f(x)$。若 $\dot V\le0$ 则 $x^*$ 稳定；$\dot V<0$（$x\ne x^*$）则渐近稳定。
定理（李雅普诺夫基本定理） 系统 $\dot x=f(x)$ 的平衡点 $x^*$ 渐近稳定当且仅当存在 $V$ 使 $V$ 正定、$\dot V$ 负定。$V$ 全局正定且径向无界 + $\dot V$ 负定 $\Rightarrow$ 全局渐近稳定。
思路：沿轨线 $V(\phi_t(x_0))$ 单调减，极限 $c\ge0$；若 $c>0$ 由 $\dot V<0$ 给 $V$ 继续减——矛盾，故 $c=0$ 即 $\phi_t\to x^*$。
定理（Hartman–Grobman 线性化） 双曲平衡点（$Df(x^*)$ 特征值实部非零）附近，非线性流与线性流拓扑共轭。即稳定性完全由线性化 $\dot y=Df(x^*)y$ 决定。
意义：中心（纯虚特征值）是非线性项决定的「临界」情形，需用 $V$ 或中心流形分析。
例：阻尼摆 $\ddot\theta+\sin\theta=0$ 在最低点的稳定性。
解：状态 $(\theta,\omega)$，$\dot\theta=\omega$, $\dot\omega=-\sin\theta$。$V=\frac12\omega^2+1-\cos\theta$（动能+势能），$\dot V=\omega(-\sin\theta)+\sin\theta\cdot\omega=0$——保守。最低点 $\theta=0$ Lyapunov 稳定但非渐近（能量守恒）。加阻尼 $\dot\omega=-\sin\theta-\gamma\omega$ 给 $\dot V=-\gamma\omega^2<0$，渐近稳定。

15. 深度：偏微分方程初步——分类与典型例子 二阶 PDE 的三大类

定义（二阶线性 PDE 分类） 一般形式 $Au_{xx}+2Bu_{xy}+Cu_{yy}+\dots=0$，判别 $\Delta=B^2-AC$： $\Delta>0$ 双曲（波动）；$\Delta=0$ 抛物（热传导）；$\Delta<0$ 椭圆（拉普拉斯）。
定理（波动方程 D'Alembert） $u_{tt}=c^2u_{xx}$ 的一般解 $u(x,t)=F(x-ct)+G(x+ct)$（行波叠加）。初值 $u(x,0)=\varphi(x), u_t(x,0)=\psi(x)$ 给 $$u(x,t)=\frac{\varphi(x-ct)+\varphi(x+ct)}2+\frac1{2c}\int_{x-ct}^{x+ct}\psi(s)\,ds.$$
思路：换元 $\xi=x-ct,\eta=x+ct$ 把 PDE 化为 $u_{\xi\eta}=0$，积分两次得 $F(\xi)+G(\eta)$。
定理（热传导方程极值原理） $u_t=u_{xx}$ 在 $\bar\Omega_T$ 连续，则最大值在 $\partial\Omega_T$（边界或初始时刻）取到。由此推出唯一性与稳定性。
意义：与波动的有限传播速度不同，热传导「瞬间扩散」——信息瞬时到达所有点。极值原理给出定性把握。
例：用分离变量求 $u_t=u_{xx}$, $u(0,t)=u(L,t)=0$, $u(x,0)=\varphi(x)$ 的解。
解：试 $u=X(x)T(t)$ 得 $T'/T=X''/X=-\lambda$。$X(0)=X(L)=0$ 给 $\lambda_n=(n\pi/L)^2$, $X_n=\sin(n\pi x/L)$, $T_n=e^{-n^2\pi^2t/L^2}$。叠加 $u=\sum b_ne^{-n^2\pi^2t/L^2}\sin(n\pi x/L)$，$b_n=\frac2L\int_0^L\varphi\sin(n\pi x/L)dx$。高频模衰减快——平滑化。

查看答案
答案：y = 3e^(2t)——指数增长/衰减模型。
练习 4：系统 x′ = [[−1,0],[0,2]]x 稳定吗？
查看答案
答案：特征值 −1、2：一个实部为正 → 不稳定（鞍点）。
练习 5：拉氏变换 L{t} = ?
查看答案
答案：1/s²（L{tⁿ} = n!/sⁿ⁺¹，n=1）。
练习 6：欧拉法（h = 1）解 y′ = −y、y(0) = 1 到 t = 1，误差多大？
查看答案
答案：y₁ = 1 − 1 = 0；真实 e⁻¹ ≈ 0.368，误差 0.368（100%）——欧拉法大步长极不准，需小步长或高阶方法。
练习 7：$\dot x=y,\dot y=-x$ 用 Lyapunov 函数判稳定性。
查看答案
答案：取 $V=x^2+y^2$，$\dot V=2x\dot x+2y\dot y=2xy-2xy=0$。能量守恒，Lyapunov 稳定（非渐近）。
练习 8：$y+\lambda y=0,\,y(0)=y(\pi)=0$ 的特征值？
查看答案
答案：$y=\sin(\sqrt\lambda x)$，边界要求 $\sin(\sqrt\lambda\pi)=0\Rightarrow\sqrt\lambda=n\in\mathbb{N}^+$，$\lambda_n=n^2$。特征函数 $\sin nx$ 是傅里叶正弦基。
练习 9：$u_{tt}=u_{xx}$ 的特征线是什么？
查看答案
答案：$x\pm t=\text{const}$——信息沿这两族直线传播。通解 $u(x,t)=F(x-t)+G(x+t)$（d\,Alembert）。
练习 10：为什么椭圆方程解整体光滑而双曲方程可能有奇点？
查看答案
答案：椭圆（拉普拉斯）：解在内部解析（椭球平均），奇点只能在边界。双曲（波）：奇点沿特征线传播——$u$ 在 $(x_0,t_0)$ 的奇性来自特征线 $\pm(x-x_0)=t-t_0$ 上的初值奇性。
练习 11：证明系统 $\dot x=-x^3$ 的原点全局渐近稳定。
查看答案
答案：$V=x^2/2$ 给 $\dot V=x\dot x=-x^4<0$（$x\ne0$）。$V$ 径向无界，故全局渐近稳定。解 $x(t)=x_0(1+2x_0^2t)^{-1/2}\to0$。
练习 12：热传导方程 $u_t=u_{xx}$ 的行波解 $u(x,t)=\varphi(x-ct)$ 满足什么 ODE？
查看答案
答案：代入：$-c\varphi'=\varphi''$，解 $\varphi=A+Be^{-cx}$。只有指数型行波解，对应基本解 $e^{-c(x-ct)}$；与波动的任意形状行波对比鲜明。
