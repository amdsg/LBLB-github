1. 整除与算术基本定理 一切从「能整除吗」开始

定义（整除）：整数 a 整除 b（记 a | b），若存在整数 k 使 b = ak。整除关系是数论的地基——它把整数组织成「倍数-因数」的层级。
定义（带余除法）：对任意整数 a 与正整数 b，存在唯一整数 q、r 满足 a = qb + r 且 0 ≤ r < b。q 称商，r 称余数。这是所有「算法」的起点：欧几里得算法正是反复用带余除法。
定理（欧几里得算法）：gcd(a, b) = gcd(b, a mod b)。反复应用可快速求最大公约数。
证明要点：设 a = qb + r，则 a 与 b 的公因子集合恰等于 b 与 r 的公因子集合——因为任何整除 b、r 的数也整除 a = qb + r，反之亦然。于是最大公约数不变。
例：gcd(252, 105) = gcd(105, 42) = gcd(42, 21) = gcd(21, 0) = 21。
定理（贝祖等式）：存在整数 x、y 使 ax + by = gcd(a, b)。
证明要点：欧几里得算法反推即可构造 x、y；这也证明「ax + by 能取到的所有值恰是 gcd(a,b) 的倍数」。
定理（算术基本定理）：每个大于 1 的整数都能唯一地写成素数之积（不计顺序）。
证明要点：存在性用归纳；唯一性需先证「若 p | ab 且 p 为素数，则 p | a 或 p | b」（欧几里得引理，由贝祖等式一步推出）。随后对两个素因子分解逐项配对即可。
例：把 360 分解为素数之积。
解：360 = 36×10 = 2²·3² · 2·5 = 2³·3²·5。素因子指数 (3, 2, 1) 唯一确定 360 的约数个数 τ(360) = (3+1)(2+1)(1+1) = 24。

由算术基本定理立即可得约数个数公式：若 n = p₁^a₁ … pₖ^aₖ，则约数个数 τ(n) = (a₁+1)…(aₖ+1)，约数和 σ(n) = ∏(pᵢ^(aᵢ+1)−1)/(pᵢ−1)。

2. 同余及其运算 把整数按「余数」分类，得到一张有限运算表

定义（同余）：a ≡ b (mod m) 当且仅当 m | (a−b)，即 a、b 除以 m 余数相同。同余是数论的核心语言。
定理（同余的四则运算）：若 a ≡ b (mod m)、c ≡ d (mod m)，则 a+c ≡ b+d、a−c ≡ b−d、ac ≡ bd (mod m)。
证明要点：设 a = b + km、c = d + lm，则 a+c = b+d + (k+l)m；ac = bd + (bl+dk+k lm)m。
定理（消去律）：若 ac ≡ bc (mod m) 且 gcd(c, m) = 1，则可消去 c：a ≡ b (mod m)。
证明要点：m | c(a−b)，又 gcd(c,m)=1，故 m | (a−b)。注意若 gcd(c,m)>1 消去律不成立：2×1 ≡ 2×4 (mod 6) 但 1 ≢ 4。
定理（中国剩余定理）：若 m₁, m₂, …, mₖ 两两互素，则同余方程组 x ≡ aᵢ (mod mᵢ) 在模 M = m₁m₂…mₖ 下有唯一解。
证明要点：令 Mᵢ = M/mᵢ，因 gcd(Mᵢ, mᵢ) = 1 存在逆元 yᵢ 使 Mᵢyᵢ ≡ 1 (mod mᵢ)。则 x = Σ aᵢMᵢyᵢ 满足全部方程；唯一性由「差为 M 的倍数」推出。这是中国古代「物不知数」问题的现代形式。
例：求解 x ≡ 2 (mod 3)，x ≡ 3 (mod 5)，x ≡ 2 (mod 7)。
解：M=105。M₁=35（35≡2 mod 3，逆元 2），M₂=21（21≡1 mod 5，逆元 1），M₃=15（15≡1 mod 7，逆元 1）。x = 2·35·2 + 3·21·1 + 2·15·1 = 140+63+30 = 233 ≡ 23 (mod 105)。验证：23≡2 (mod 3)、≡3 (mod 5)、≡2 (mod 7) ✓
定义（逆元）：a 在模 m 下的逆元是满足 ax ≡ 1 (mod m) 的 x，存在当且仅当 gcd(a, m) = 1。逆元由贝祖等式给出——这是 RSA 解密的基础运算。

3. 费马小定理与欧拉定理 素数的「指数魔法」

定理（费马小定理）：若 p 为素数且 p ∤ a，则 $a^{p-1}$ ≡ 1 (mod p)。
证明要点（组合论证）：考虑 a 个字母的 p 位项链（允许旋转重合）。非单色项链每条恰有 p 个旋转——总项链数 aᵖ 减去单色的 a 条，故 p | (aᵖ − a)，即 aᵖ ≡ a (mod p)，约去 a 得 $a^{p-1}$ ≡ 1。
证明要点（群论）：模 p 非零剩余构成 p−1 阶群，拉格朗日定理直接给出 $a^{p-1}$ = 1。
定义（欧拉函数）：φ(n) = 1 到 n 中与 n 互素的整数个数。若 n = ∏pᵢ^aᵢ，则 φ(n) = n∏(1−1/pᵢ)。
定理（欧拉定理）：gcd(a, n) = 1 时 a^φ(n) ≡ 1 (mod n)。
证明要点：把与 n 互素的 φ(n) 个数乘上 a 仍得同一集合（置换论证），所有乘积相除即得。
定理（威尔逊定理）：(p−1)! ≡ −1 (mod p) 当且仅当 p 是素数。
证明要点：若 p 为素数，1 到 p−1 中除 1 与 p−1 外每个数都与它的逆元配对相乘为 1，故 (p−1)! ≡ 1·(p−1) ≡ −1。反向：若 p 为合数则 (p−1)! 含 p 的因子，不可能 ≡ −1。
例：用费马小定理求 2¹⁰⁰ 除以 101 的余数。
解：101 是素数，2¹⁰⁰ ≡ 1 (mod 101)。实际计算：2¹⁰ = 1024 ≡ 14，2⁵⁰ = (2¹⁰)⁵ ≡ 14⁵。14²=196≡95，14⁴≡95²=9025≡36，14⁵≡36×14=504≡100≡−1，故 2⁵⁰≡−1，2¹⁰⁰≡1 ✓

4. 二次剩余与二次互反律 高斯称为「黄金定理」的结果

定义（二次剩余）：a 是模奇素数 p 的二次剩余，若存在 x 使 x² ≡ a (mod p)。模 p 的非零剩余恰有一半是二次剩余，一半不是——它们正是由 x² 当 x 跑遍 1…(p−1)/2 生成。
定理（欧拉判据）：$a^{(p-1)/2}$ ≡ +1 (mod p) 当且仅当 a 是模 p 的二次剩余；否则 ≡ −1。
证明要点：若 a = x² 则 $a^{(p-1)/2}$ = $x^{p-1}$ ≡ 1；反方向由「x² ≡ a 有解当且仅当 $x^{p-1}$ ≡ 1」的计数（一半元素是 p−1 阶方程的根）。
定理（二次互反律）：对相异奇素数 p、q，记勒让德符号 (p/q)（p 是否模 q 的二次剩余，取 ±1），则 (p/q)(q/p) = (−1)^((p−1)(q−1)/4)。
直觉：「p 是否模 q 剩余」与「q 是否模 p 剩余」高度相关：除非两者都 ≡ 3 (mod 4)，否则答案相同。高斯一生给出 8 种证明——它意外地把两个素数的「互相剩余」关系完全表出，是现代代数数论的种子。
例：判断 7 是否是模 29 的二次剩余。
解：(7/29) = (29/7)·(−1)^((7−1)(29−1)/4) = (29/7)·(−1)^42 = (29/7)。29 ≡ 1 (mod 7)，故 (29/7) = (1/7) = 1。所以 7 是模 29 的二次剩余（检验：11²=121 ≡ 5，再算 5·?——事实上 8² = 64 ≡ 6，9²=81≡23…直接算得 6² = 36 ≡ 7 ✓，x=6）。

5. 素数分布 素数「随机」却服从精确统计

记 π(x) 为不超过 x 的素数个数。高斯 15 岁就猜测 π(x) ≈ x/ln x——1896 年由 Hadamard 与 de la Vallée Poussin 独立证明（用黎曼 ζ 函数的解析性质）。

定理（素数定理）：lim π(x) / (x/ln x) = 1。
证明要点（复分析路径）：把 ζ(s) = Σ1/nˢ 解析延拓到复平面，证明 ζ 在 Re(s) = 1 上无零点（Hadamard/de la Vallée Poussin），再通过 Mellin 变换把素数计数函数与 ζ 的极点联系起来。
定理（狄利克雷定理）：等差数列 a, a+m, a+2m, …（gcd(a,m)=1）中含有无穷多个素数。
直觉：素数不会长期避开任何「合法」的算术级数——这是用 L 函数证明的：每个 Dirichlet 特征对应的 L 函数在 s=1 处非零，推出相应级数的素数无穷多。

孪生素数猜想（有无穷多对相差 2 的素数）仍未证明，但 2013 年张益唐首次证明存在无穷多对素数差 < 7×10⁷，经 Polymath 项目压缩到 246；2026 年又被改进到 240 → 212 → 186（见前沿页）。哥德巴赫猜想：每个大于 2 的偶数 = 两素数之和；弱版本（奇数 = 三素数之和）已由 Helfgott（2013）证明。

例：π(10⁹) = 50,847,534，而 10⁹/ln(10⁹) ≈ 48,254,942——素数定理的相对误差约 5%，且随 x 增大趋于 0。

6. 丢番图方程 找整数解的方程——最古老也最坚硬

定义：丢番图方程是只关心整数解的（多项式）方程。x²+y² = z²（勾股数）是最经典的例子。
定理（勾股数公式）：x²+y²=z² 的全体本原解为 x = m²−n²，y = 2mn，z = m²+n²（m>n，一奇一偶，gcd(m,n)=1）。
证明要点：从 x² = z²−y² = (z−y)(z+y) 出发，利用 gcd(z−y, z+y) = 2 分奇偶讨论；或用高斯整数环 ℤ[i] 的唯一分解直接分解 x²+y² = (x+iy)(x−iy)。
定理（佩尔方程）：x² − Dy² = 1（D 非平方）有无穷多解，全部由最小解 (x₁, y₁) 的幂生成：xₖ + yₖ√D = (x₁+y₁√D)ᵏ。
证明要点：先用狄利克雷抽屉原理证明存在非平凡解（连分数法），再用「最小解生成所有解」的群论论证（单位群）。
定理（费马大定理）：xⁿ + yⁿ = zⁿ（n ≥ 3）无正整数解。
证明要点（怀尔斯 1995，断代工程）：假设有解则构造不可模的椭圆曲线（Frey 曲线），而谷山-志村-韦伊定理（现称模性定理）说所有半稳定椭圆曲线都模——矛盾。怀尔斯与泰勒补上了模性定理的关键一环。整个证明约 150 页，是 20 世纪数论巅峰。
例：求 x² − 2y² = 1 的最小正整数解。
解：试 y=1: x²=3 无整数解；y=2: x²=9 → x=3。最小解 (3, 2)，其余解由 (3+2√2)ᵏ 展开得到：(17, 12)、(99, 70)……

7. 数论应用：RSA 与校验 数论不是象牙塔——它保护着你的每笔交易

RSA 公钥密码（Rivest–Shamir–Adleman，1977）：

密钥生成：① 取两大素数 p、q，令 n = pq；② 计算 φ(n) = (p−1)(q−1)；③ 选加密指数 e（gcd(e, φ(n)) = 1）；④ 求 d 使 ed ≡ 1 (mod φ(n))（用贝祖等式）。公钥 (n, e)，私钥 d。
加解密：加密 c = mᵉ (mod n)；解密 m = cᵈ (mod n)。正确性由欧拉定理：cᵈ = $m^{ed}$ ≡ $m^{1+kφ(n)}$ ≡ m (mod n)。
安全性：攻击者知道 n、e，但分解 n 为大素数之积在计算上不可行（数百位十进制数）——「大数分解难」是 RSA 的护城河。
例（玩具版）：p=61, q=53 → n=3233, φ=3120；取 e=17，则 d=2753（17×2753−1 是 3120 的倍数）。加密 m=65：65¹⁷ mod 3233 = 2790；解密 2790²⁷⁵³ mod 3233 = 65 ✓

校验码：身份证末位是模 11 的校验位；ISBN-10 用加权和模 11；信用卡 Luhn 算法用模 10。它们都是「检测单个数字错误」的同余设计。

9a. 深度：中国剩余定理的构造性证明 从存在性到显式算法

定理（CRT） 设 $m_1, m_2, \dots, m_k$ 两两互素（$\gcd(m_i, m_j) = 1$ 当 $i \neq j$），$M = m_1 m_2 \cdots m_k$。则同余方程组 $$x \equiv a_1 \!(\bmod m_1),\; \dots,\; x \equiv a_k \!(\bmod m_k)$$ 在模 $M$ 下有唯一解。
构造性证明： 令 $M_i = M / m_i$。因 $\gcd(M_i, m_i) = 1$，由 Bézout，存在 $M_i$ 模 $m_i$ 的逆元 $y_i$：$M_i y_i \equiv 1 \!(\bmod m_i)$。取 $$x = a_1 M_1 y_1 + a_2 M_2 y_2 + \cdots + a_k M_k y_k.$$ 对每个 $i$：当 $j \neq i$ 时 $m_i \mid M_j$（因 $M_j = M/m_j$ 含因子 $m_i$），故 $a_j M_j y_j \equiv 0 \!(\bmod m_i)$；当 $j = i$ 时 $a_i M_i y_i \equiv a_i \cdot 1 \!(\bmod m_i)$。于是 $x \equiv a_i \!(\bmod m_i)$。唯一性：若 $x, x'$ 皆解，则 $x - x' \equiv 0 \!(\bmod m_i)$ 对所有 $i$，因 $m_i$ 两两互素，$M \mid (x-x')$，即模 $M$ 唯一。
例：解 $x \equiv 2 \!(\bmod 3)$，$x \equiv 3 \!(\bmod 5)$，$x \equiv 2 \!(\bmod 7)$。 $M = 105$。$M_1 = 35$，模 3 逆元 $y_1$：$35 \equiv 2$，$2 \cdot 2 = 4 \equiv 1$，故 $y_1 = 2$。$M_2 = 21$，模 5：$21 \equiv 1$，$y_2 = 1$。$M_3 = 15$，模 7：$15 \equiv 1$，$y_3 = 1$。 $$x = 2\cdot 35\cdot 2 + 3\cdot 21\cdot 1 + 2\cdot 15\cdot 1 = 140 + 63 + 30 = 233.$$ 取模 105：$233 \equiv 23 \!(\bmod 105)$。检验：$23 \bmod 3 = 2$ ✓，$23 \bmod 5 = 3$ ✓，$23 \bmod 7 = 2$ ✓。
注：这正是《孙子算经》「物不知数」原题：答 23。算法复杂度由扩展欧几里得算法 $O(\log \min(m_i, m_j))$ 决定。

9b. 深度：威尔逊定理与素性判别 $(p-1)! \equiv -1$ 为什么等价于「$p$ 是素数」

定理（Wilson 1770） $p$ 是素数当且仅当 $$(p-1)! \equiv -1 \pmod p.$$
证明思路： 「⇒」（$p$ 素）：在 $\mathbb{Z}_p$ 中，每个 $a \in \{1,\dots,p-1\}$ 有唯一逆元 $a^{-1}$。满足 $a = a^{-1}$（即 $a^2 \equiv 1$）的解只有 $a \equiv \pm 1$（因 $a^2 - 1 = (a-1)(a+1) \equiv 0$，域中无零因子）。其余元素两两配对 $(a, a^{-1})$，乘积 $1$。故 $(p-1)! \equiv 1 \cdot (-1) \equiv -1 \pmod p$。 「⇐」（$(n-1)! \equiv -1 \! (\bmod n)$ → $n$ 素）：若 $n$ 合数且 $d \mid n$、$1 \lt d \lt n$，则 $d \mid (n-1)!$，故 $(n-1)! \equiv 0 \pmod d$，但 $-1 \not\equiv 0 \pmod d$，矛盾。
例：用威尔逊定理检验 $p = 7$ 与 $n = 8$。 $p = 7$：$6! = 720$，$720 \bmod 7$：$7 \cdot 102 = 714$，余 $6 \equiv -1 \pmod 7$ ✓。配对：$(2,4)$、$(3,5)$（因 $2\cdot 4=8\equiv 1$，$3\cdot 5=15\equiv 1$），剩 $1, 6$，乘积 $1 \cdot 6 = 6 \equiv -1$。 $n = 8$：$7! = 5040$，$5040 \bmod 8 = 0$（因 $2,4 \mid 7!$），不 $\equiv -1 \equiv 7 \pmod 8$。故 8 不是素数。
算法意义：威尔逊定理是充要素性判别，但计算 $(n-1)!$ 需要 $O(n)$ 次乘法，远不如试除法——它在理论上优美，在工程上被费马小定理、Miller–Rabin 等概率判别取代。

9c. 深度：数论函数与默比乌斯反演 把「求和」与「反演」变成一对精确工具

定义（数论函数） 数论函数 $f:\mathbb{N}\to\mathbb{C}$ 满足 $f(1)=1$ 且在不少应用中具有「积性」：$\gcd(m,n)=1 \Rightarrow f(mn)=f(m)f(n)$。常见的有约数个数 $\tau(n)$、约数和 $\sigma(n)$、欧拉函数 $\varphi(n)$、默比乌斯函数 $\mu(n)$。
定义（默比乌斯函数） $$\mu(n)=\begin{cases}1, & n=1,\\ (-1)^k, & n\text{ 为 }k\text{ 个相异素数之积},\\ 0, & n\text{ 含平方因子}.\end{cases}$$ 直觉：$\mu$ 是「素因子计数器」——含平方因子的数被它判零，否则按素因子个数取 $\pm1$。
定理（默比乌斯反演） 若 $F(n)=\sum_{d\mid n} f(d)$，则 $$f(n)=\sum_{d\mid n}\mu(d)\,F\!\left(\frac{n}{d}\right).$$
证明：代入 $F$ 的定义交换求和： $$\sum_{d\mid n}\mu(d)\sum_{e\mid n/d} f(e) = \sum_{e\mid n} f(e)\sum_{d\mid n/e}\mu(d).$$ 由 $\sum_{d\mid m}\mu(d) = [m=1]$（仅当 $m=1$ 时为 1），仅 $e=n$ 项存活，得 $f(n)$。
例：用默比乌斯反演从 $\sum_{d\mid n}\varphi(d)=n$ 恢复 $\varphi(n)$。
解：令 $F(n)=n$，$f=\varphi$，反演给出 $$\varphi(n)=\sum_{d\mid n}\mu(d)\frac{n}{d}=n\sum_{d\mid n}\frac{\mu(d)}{d}.$$ 对 $n=p^k$：$\varphi(p^k)=p^k - p^{k-1}$（只有 $d=1,p$ 贡献）。积性推出一般公式 $\varphi(n)=n\prod_{p\mid n}(1-1/p)$。

9d. 深度：连分数与最佳有理逼近 每个无理数都自带一棵逼近树

定义（简单连分数） 实数 $x$ 的简单连分数展开 $$x = a_0 + \cfrac{1}{a_1 + \cfrac{1}{a_2 + \cdots}}, \quad a_0\in\mathbb{Z},\ a_i\in\mathbb{N}^+.$$ 记 $[a_0;a_1,a_2,\dots]$。截断到 $a_k$ 得第 $k$ 个渐近分数 $p_k/q_k=[a_0;\dots,a_k]$。
定理（最佳逼近） 渐近分数满足 $$\left|x - \frac{p_k}{q_k}\right| < \frac{1}{q_k q_{k+1}} < \frac{1}{q_k^2},$$ 且 $p_k/q_k$ 是分母 $\le q_k$ 的所有分数中最接近 $x$ 的。
证明思路：递推 $p_k=a_k p_{k-1}+p_{k-2}$、$q_k=a_k q_{k-1}+q_{k-2}$ 保证相邻渐近分数之差 $1/(q_k q_{k+1})$；由 $\{p_k/q_k\}$ 的交错性（偶项递增、奇项递减）与无误差界推出最优性。
例：求 $\pi$ 的前几个渐近分数。
解：$\pi=[3;7,15,1,292,\dots]$。 $p_0/q_0=3/1$；$p_1/q_1=22/7$（约 3.1429）；$p_2/q_2=333/106$（约 3.14151）；$p_3/q_3=355/113$（约 3.141593，误差 $<10^{-6}$）。这正是祖冲之的「密率」。

9e. 深度：原根、离散对数与 Diffie–Hellman 从「谁生成全部剩余」到公钥交换

定义（阶与原根） 模 $n$ 下 $a$ 的阶 $\mathrm{ord}_n(a)$ 是使 $a^k\equiv1\pmod n$ 的最小 $k>0$。若 $\mathrm{ord}_n(a)=\varphi(n)$，称 $a$ 为模 $n$ 的原根。
定理（原根存在性） 模 $n$ 存在原根当且仅当 $n\in\{1,2,4,p^k,2p^k\}$（$p$ 奇素数）。特别地，每个素数 $p$ 恰有 $\varphi(p-1)$ 个原根。
思路：$\mathbb{Z}_p^\times$ 是 $p-1$ 阶循环群——这需要先证有限域的乘法群循环。设 $a$ 是 $p-1$ 阶元，则 $a^0,a^1,\dots,a^{p-2}$ 遍历全部非零剩余。
定义（离散对数） 给定原根 $g$ 和 $h\equiv g^x\pmod p$，求 $x=\log_g h \pmod{p-1}$ 称离散对数问题（DLP）。
应用（Diffie–Hellman 密钥交换，1976） Alice 选私钥 $a$，公开 $A=g^a\pmod p$；Bob 选 $b$，公开 $B=g^b\pmod p$。共享密钥 $K=B^a\equiv(g^b)^a\equiv g^{ab}\equiv A^b\pmod p$。
安全性：窃听者知 $p,g,A,B$，需解 DLP 求 $a$ 或 $b$。当 $p$ 为数百位素数且 $p-1$ 无小因子时，DLP 被认为困难——这是现代公钥密码的支柱之一（与 RSA 互为补充）。

9f. 深度：椭圆曲线与模形式初步 从丢番图方程到费马大定理的桥梁

定义（椭圆曲线） 设 $K$ 为特征 $\ne 2,3$ 的域，椭圆曲线是由 Weierstrass 方程 $$y^2 = x^3 + ax + b, \quad a,b\in K,\; \Delta = -16(4a^3+27b^2)\ne 0$$ 给出的非奇异代数曲线 $E$。$\Delta\ne0$ 保证无尖点/节点。
定义（群律） $E$ 上的点集 $E(K)$ 配以「弦切律」构成 Abel 群：过两点 $P,Q$ 的直线交 $E$ 于第三点 $R$，定义 $P+Q$ 为 $R$ 关于 $x$ 轴的对称点 $-R$。单位元为「无穷远点」$\mathcal{O}$。
定理（Mordell–Weil） 当 $K$ 是数域时，$E(K)$ 是有限生成的 Abel 群：$E(K)\cong E(K)_{\text{tors}}\oplus\mathbb{Z}^r$。$r$ 称为 $E$ 的秩。
思路：「弱 Mordell–Weil」证 $E(K)/2E(K)$ 有限（用 descent），再由「高度函数」$\hat h(P)$（满足 $\hat h(2P)\approx 4\hat h(P)$）推出无限部分为格。
定理（费马大定理的证明路径） 费马方程 $x^n+y^n=z^n$（$n\ge3$）对应椭圆曲线 $y^2=x(x-a^n)(x+b^n)$。Frey–Serre–Ribet 证明：若费马有解，则此椭圆曲线的 $j$ 不变量为「病态」——模形式 $\Delta$ 不存在（Modularity Theorem：每条有理椭圆曲线被权 2 新形式对应），矛盾。
意义：Ribet (1986) 证 Frey 曲线「半稳定则模」，Wiles–Taylor (1995) 证半稳定椭圆曲线模——FTT 得证。
例：求 $E: y^2=x^3-x$ 在 $\mathbb{Q}$ 上的挠子群。
解：有理点 $\{(0,0),(1,0),(-1,0),\mathcal{O}\}$，这是 $\mathbb{Z}/2\times\mathbb{Z}/2$。$(0,0)+(1,0)$ 的弦交 $E$ 于 $(-1,0)$（$x(x-1)(x+1)$），对称后仍为 $(-1,0)$。Lutz–Nagell 定理：挠点的坐标为整数且 $y^2\mid\Delta$，穷举即得。

9g. 深度：解析数论与素数定理 用复分析数清素数

定义（黎曼 ζ 函数） $\zeta(s)=\sum_{n=1}^\infty n^{-s}=\prod_p(1-p^{-s})^{-1}$（$\Re s>1$，Euler 乘积），解析延拓到 $\mathbb{C}\setminus\{1\}$，$s=1$ 为一阶极点。
定理（素数定理 PNT, Hadamard–de la Vallée Poussin 1896） 记 $\pi(x)=\#\{p\le x\}$，则 $$\pi(x)\sim\frac{x}{\ln x}\quad(x\to\infty),$$ 即 $\lim_{x\to\infty}\pi(x)\ln x/x=1$。
思路：$\zeta(s)$ 在 $\Re s=1$ 上无零点 $\Rightarrow$ $\psi(x)=\sum_{n\le x}\Lambda(n)\sim x$（$\Lambda$ 为 Mangoldt 函数）$\Rightarrow$ PNT。关键是用 Perron 公式把 $\pi$ 表示成 $\zeta$ 的围道积分。
定理（黎曼假设，未解） $\zeta(s)$ 的非平凡零点 $\rho$ 全在 $\Re s=1/2$ 上。等价地 $\pi(x)=\mathrm{Li}(x)+O(\sqrt{x}\ln x)$。
现状：已知 $10^{13}$ 个零点在临界线上，但 Hardy (1914) 仅证有无穷多零点在 $\Re s=1/2$ 上。RH 蕴含 PNT 的最佳余项、素数间隙 $O(\sqrt{p}\ln p)$ 等。
例：用 Euler 乘积证 $\sum_p 1/p$ 发散。
解：$\ln\zeta(s)=\sum_p\sum_{k\ge1}\frac{1}{kp^{ks}}$（$s>1$）。$s\to1^+$ 时 $\zeta(s)\sim\frac1{s-1}$ 发散，而 $\sum_{k\ge2}\sum_p 1/(kp^{ks})$ 收敛（$\le\sum_n 1/n^2$），故 $\sum_p 1/p\to\infty$。Euler 1748 年借此证了素数无穷。

9. 练习与自测 先自己做，再点开答案

练习 1：证明 gcd(a, b) = gcd(a, a+b)。
查看答案
答案：a 与 b 的公因子集合 = a 与 a+b 的公因子集合（整除 b 的数必整除 a+b，反之整除 a+b 与 a 的数必整除 b），故最大公约数相等。
练习 2：求 7¹⁰⁰⁰ 除以 11 的余数。
查看答案
答案：11 是素数，费马小定理 7¹⁰ ≡ 1 (mod 11)。1000 = 100×10，故 7¹⁰⁰⁰ = (7¹⁰)¹⁰⁰ ≡ 1。
练习 3：解同余方程组 x ≡ 1 (mod 4)，x ≡ 2 (mod 3)。
查看答案
答案：M=12。M₁=3（逆元 3），M₂=4（逆元 1）。x = 1·3·3 + 2·4·1 = 17 ≡ 5 (mod 12)。
练习 4：判断 3 是否是模 17 的二次剩余（用欧拉判据）。
查看答案
答案：3⁸ mod 17：3²=9，3⁴=81≡13，3⁸=13²=169≡16≡−1。故 3 不是模 17 的二次剩余。
练习 5：求 200 的约数个数。
查看答案
答案：200 = 2³×5²，τ(200) = (3+1)(2+1) = 12。
练习 6：用中国剩余定理说明「每 3 天检查一次、每 5 天喂一次鱼，第几天同时做？」的模型。
查看答案
答案：即 x ≡ 0 (mod 3) 且 x ≡ 0 (mod 5) → x ≡ 0 (mod 15)，每 15 天重合一次。若再加「每 7 天换水」，则每 lcm(3,5,7)=105 天三者重合。
练习 7：计算 $\mu(30)$。
查看答案
答案：$30=2\cdot3\cdot5$ 为三个相异素数之积，故 $\mu(30)=(-1)^3=-1$。
练习 8：用默比乌斯反演证明 $\sum_{d\mid n}\mu(d)=\begin{cases}1&n=1\\0&n>1\end{cases}$。
查看答案
答案：令 $F(n)=\sum_{d\mid n}\mu(d)$。注意 $F$ 是积性的且 $F(p^k)=1-1=0$（$k\ge1$），故 $F(n)=\prod F(p_i^{a_i})=0$（$n>1$）。
练习 9：求 $\sqrt{2}$ 的连分数展开并证明其周期为 1。
查看答案
答案：$\sqrt{2}=[1;\overline{2}]$。由 $\sqrt{2}-1=\frac{1}{2+(\sqrt{2}-1)}$ 得递归 $x=1/(2+x)$，解出 $x=\sqrt{2}-1$，周期 1。渐近分数 $1, 3/2, 7/5, 17/12, 41/29, \dots$ 即佩尔方程 $x^2-2y^2=\pm1$ 的解。
练习 10：求模 11 的所有原根。
查看答案
答案：$\varphi(11)=10$，$10=2\cdot5$。检验 $2$ 的阶：$2^5=32\equiv10\not\equiv1$，$2^{10}\equiv1$，故 $\mathrm{ord}_{11}(2)=10$，$2$ 是原根。原根共 $\varphi(10)=4$ 个：$2,6,7,8$（即 $2^1,2^9,2^4,2^3\pmod{11}$）。
练习 11：椭圆曲线 $E: y^2=x^3-x$ 上，计算 $P=(0,0)+P$。
查看答案
答案：切线在 $(0,0)$ 处：$y=\pm\sqrt{x^3-x}$，$x=0$ 处切线竖直，交 $E$ 于 $\mathcal{O}$，故 $2P=\mathcal{O}$，即 $(0,0)$ 是 2 阶元。
练习 12：用 PNT 估计 $\pi(10^{10})$ 并与精确值 $455052511$ 比较。
查看答案
答案：$\pi(10^{10})\approx 10^{10}/\ln(10^{10})\approx 10^{10}/23.03\approx 4.34\times10^8$，误差约 5%。用 $\mathrm{Li}$ 更准：$\mathrm{Li}(10^{10})\approx 4.55\times10^8$，与精确值极接近。

公约数中最大者 / 公倍数中最小者；ab = gcd·lcm。
同余类
模 m 下余数相同的整数集合，构成模 m 剩余类。

模 p 下能生成全部非零剩余的元（其阶为 p−1）。

(a/p) 表示 a 是否模 p 的二次剩余（1 / −1 / 0）。

已知 $g^x\pmod p$ 与 $g,p$ 求 $x$；Diffie–Hellman 的安全基石。
