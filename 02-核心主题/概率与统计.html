1. 概率公理与计数 柯尔莫哥洛夫的三条公理

定义（概率空间）：(Ω, ℱ, P)：样本空间 Ω、事件 σ-代数 ℱ、概率测度 P，满足：① P(Ω) = 1；② 可列可加：互斥事件并的概率 = 概率之和；③ P ≥ 0。
定理（基本计数原理）：加法原理（互斥分类求和）与乘法原理（分步相乘）。
例：从 26 个字母中取 4 个不重复排列数 = 26·25·24·23 = 358,800。
定理（组合恒等式）：C(n,k) = n!/(k!(n−k)!)；C(n,k) = C(n−1,k) + C(n−1,k−1)（帕斯卡恒等式）；二项定理 (a+b)ⁿ = Σ C(n,k)aᵏbⁿ⁻ᵏ。
证明要点：帕斯卡恒等式按「第 n 个元素选/不选」分类；二项定理是乘法原理的展开。
例：一副牌 52 张取 5 张，多少种不同的手牌？
查看答案
答案：C(52,5) = 2,598,960 种。

2. 条件概率与贝叶斯定理 新信息如何更新信念

定义（条件概率）：P(A|B) = P(A∩B)/P(B)。给定 B 已发生，样本空间缩小到 B。
定理（全概率公式）：若 B₁,…,Bₖ 分割 Ω，则 P(A) = Σ P(A|Bᵢ)P(Bᵢ)。
定理（贝叶斯定理）：P(Bᵢ|A) = P(A|Bᵢ)P(Bᵢ) / Σ P(A|Bⱼ)P(Bⱼ)。
证明要点：把 P(A∩Bᵢ) 用两种方式写：P(A|Bᵢ)P(Bᵢ) = P(Bᵢ|A)P(A)，再代入全概率公式。
定理（独立）：A、B 独立 ⟺ P(A∩B) = P(A)P(B)。独立 ≠ 互斥；独立是「信息无关」，互斥是「不能同发」。
例（蒙提霍尔问题）：三扇门后有一辆车，选一扇后主持人开一扇空门，换门胜率？
查看答案
答案：换门胜率 2/3。贝叶斯：初选正确概率 1/3，主持人必开空门（不提供新信息），不换仍 1/3，换 = 1 − 1/3 = 2/3。
例（贝叶斯医学检验）：发病率 0.1%，检验灵敏度 99%、假阳性 1%。阳性者真正患病的概率？
查看答案
答案：P(病|阳) = 0.99×0.001 / (0.99×0.001 + 0.01×0.999) ≈ 9%。阳性 ≠ 患病——这是最反直觉也最重要的统计素养。

3. 随机变量与分布 把随机性数值化

定义（随机变量）：X: Ω → ℝ 的可测函数。离散型取值可数；连续型有概率密度 f(x)，P(X ∈ A) = ∫_A f。
定理（重要分布族）：
分布用途期望方差
伯努利(p)单次成败pp(1−p)
二项 B(n,p)n 次独立试验npnp(1−p)
泊松(λ)稀有事件计数λλ
均匀 U(a,b)等可能连续(a+b)/2(b−a)²/12
正态 N(μ,σ²)自然误差聚合μσ²
指数(λ)无记忆等待时间1/λ1/λ²
推导例：泊松(λ) = 二项当 n→∞、p = λ/n 时极限：P(X=k) = C(n,k)(λ/n)ᵏ(1−λ/n)ⁿ⁻ᵏ → $e^{-λ}$λᵏ/k!。
例：某路口每分钟平均过 2 辆车（泊松），1 分钟内恰好过 3 辆的概率？
查看答案
答案：P = e⁻²·2³/3! = 8e⁻²/6 ≈ 0.180。

4. 期望、方差与矩 分布的「重心」与「分散度」

定义（期望）：E[X] = Σ xᵢP(X=xᵢ)（离散）；E[X] = $\int x f(x)\,dx$（连续）。方差 Var(X) = E[(X−μ)²] = E[X²] − μ²。
定理（期望线性）：E[aX+bY] = aE[X] + bE[Y]——无需独立性。
证明要点：期望就是加权平均，和式可交换。
定理（方差公式）：X、Y 独立时 Var(X+Y) = Var(X) + Var(Y)。
证明要点：展开 E[(X+Y)²]−E[X+Y]²，交叉项用独立性 E[XY] = E[X]E[Y] 消去。
定理（马尔可夫/切比雪夫不等式）：P(X ≥ a) ≤ E[X]/a（X ≥ 0）；P(|X−μ| ≥ kσ) ≤ 1/k²。
证明要点：马尔可夫：E[X] ≥ a·P(X≥a)；切比雪夫代入 Y = (X−μ)²。无需分布假设——「只知道均值方差也能限制概率」。
例：X ~ N(0,1)，P(|X| ≥ 3) ≤ 1/9（切比雪夫），实际 ≈ 0.0027——切比雪夫很保守但普遍适用。

5. 大数定律与中心极限定理 随机性的两条「收敛」定理

定理（弱大数定律）：X₁,…,Xₙ 独立同分布，均值 μ，则样本均值 X̄ₙ → μ（依概率）。
证明要点（切比雪夫）：Var(X̄ₙ) = σ²/n → 0，切比雪夫给出 P(|X̄ₙ−μ| ≥ ε) → 0。蒙特卡洛方法就靠它：随机数平均值收敛到期望。
定理（中心极限定理）：X̄ₙ 标准化后趋于标准正态：√n(X̄ₙ−μ)/σ ⇒ N(0,1)。
证明要点（特征函数）：X 的特征函数在 0 附近展开 φ(t) = 1 + iμt − σ²t²/2 + o(t²)，取 n 次方后趋于 $e^{-t^{2}/2}$（标准正态的特征函数）——勒维连续定理完成极限交换。
定理（棣莫弗-拉普拉斯）：二项分布 B(n,p) 的标准化近似正态：P(a ≤ X ≤ b) ≈ Φ((b−np)/$\sqrt{npq}$) − Φ((a−np)/$\sqrt{npq}$)。
经验法则：np ≥ 10 且 n(1−p) ≥ 10 时近似良好。
例：掷硬币 1000 次，正面数在 450–550 之间的概率约？
查看答案
答案：μ=500, σ=√(1000·½·½)≈15.8。P(450≤X≤550) ≈ Φ(3.16)−Φ(−3.16) ≈ 0.9984。

6. 参数估计与置信区间 从样本反推总体

定义（点估计）：用样本统计量估计总体参数。矩估计：样本矩 = 总体矩；极大似然估计（MLE）：最大化似然函数 L(θ) = ∏f(xᵢ;θ)。
定理（MLE 的不变性）：若 θ̂ 是 θ 的 MLE，则 g(θ̂) 是 g(θ) 的 MLE。
意义：MLE 在大样本下渐近有效（达到克拉美-罗下界）——它是统计推断的主力。
定理（置信区间）：总体均值的 95% 置信区间为 X̄ ± 1.96σ/√n（σ 已知）。
解读：重复抽样 100 次，约 95 个区间覆盖真值——置信区间描述的是「方法」，不是「这一次的概率」。
例：n = 100，样本均值 50，σ = 10，求 95% 置信区间。
查看答案
答案：50 ± 1.96×10/√100 = 50 ± 1.96 → (48.04, 51.96)。

7. 假设检验 用数据「拒绝」或「无法拒绝」

定义（检验框架）：原假设 H₀（现状）vs 备择假设 H₁；显著性水平 α（第 I 类错误率，常取 0.05）；p 值 = 「H₀ 为真时出现当前数据或更极端数据的概率」。p < α → 拒绝 H₀。
定理（两类错误）：第 I 类错误（拒真）率 α；第 II 类错误（取伪）率 β，检验功效 = 1−β。
例：α 与 β 此消彼长——样本量 n 增大可同时降低两者。
定理（常见检验）：t 检验（均值，σ 未知）、χ² 检验（拟合优度/独立性）、F 检验（方差比/ANOVA）。
t 统计量：t = (X̄−μ₀)/(s/√n)，自由度 n−1——戈塞特（Guinness 啤酒厂）1908 年发明。
例：检验一枚硬币是否公平：掷 100 次得 60 次正面，p 值多少？
查看答案
答案：X~B(100,0.5)，P(X≥60) ≈ 0.028（双侧 p ≈ 0.057）。双侧 p > 0.05，在 α=0.05 下不拒绝公平假设。

常见陷阱：p 值不是「H₁ 为真的概率」；多重比较需要校正（Bonferroni）；「不显著 ≠ 无效应」（可能功效不足）。

8. 相关、回归与反直觉悖论 相关不是因果

定义（皮尔逊相关系数）：r = Cov(X,Y)/(σ_X σ_Y)，范围 [−1,1]。
定理（最小二乘回归）：y = a + bx 最小化 Σ(yᵢ−a−bxᵢ)² 的解：b = Cov(X,Y)/Var(X)，a = ȳ − b x̄。
证明要点：对 a、b 求导令为零（正规方程），或几何投影到列空间。
定理（辛普森悖论）：分组看有趋势，合并看趋势反转。
例：两个科室各自 A 药治愈率都更高，但合并数据 B 药更高——因为 B 药更多用于轻症。混淆变量（病情）必须分层分析。
例：冰淇淋销量与溺水人数高度相关（r ≈ 0.9）——共同原因：夏天。相关 ≠ 因果。

9. 深度专题：大数定律与中心极限定理证明思路 随机样本为何服从正态

定理（切比雪夫弱大数定律）：$\{X_n\}$ 两两不相关、期望 $\mu$ 相同、方差一致有界，则 $\bar X_n=\frac1n\sum_{i=1}^n X_i \xrightarrow{P}\mu$。
证明思路：$\mathbb E\bar X_n=\mu$，$\operatorname{Var}\bar X_n=\sigma^2/n$。切比雪夫不等式 $P(|\bar X_n-\mu|\ge\varepsilon)\le \sigma^2/(n\varepsilon^2)\to 0$。无需独立同分布，仅需二阶矩有界——这是弱大数定律的最小条件。
定理（Kolmogorov 强大数定律）：独立同分布 $X_i$ 且 $\mathbb E|X_1|<\infty$，则 $\bar X_n\to\mu$ 几乎处处。
证明思路：截断法 + Borel–Cantelli 引理。令 $Y_i=X_i\mathbf 1_{\{|X_i|\le i\}}$，则 $\sum P(X_i\neq Y_i)=\sum P(|X_1|>i)<\infty$（由 $\mathbb E|X_1|<\infty$ 推出），故 $X_i\neq Y_i$ 仅发生有限次。再用 Kronecker 引理控制 $\sum(Y_i-\mathbb E Y_i)/n\to 0$。
定理（Lindeberg–Lévy 中心极限定理）：i.i.d. $X_i$，$\mathbb E X_i=\mu$，$0<\operatorname{Var}X_i=\sigma^2<\infty$，则 $$\frac{\sum_{i=1}^n X_i-n\mu}{\sigma\sqrt n}\ \xrightarrow{d}\ N(0,1).$$
证明思路（特征函数法）：设标准化变量 $\xi_i=(X_i-\mu)/\sigma$ 的特征函数为 $\varphi(t)$。由 Taylor 展开 $\varphi(t)=1-\tfrac12 t^2+o(t^2)$（用到二阶矩有限）。和的特征函数为 $\varphi(t/\sqrt n)^n$，取对数： $$n\log\varphi(t/\sqrt n)=n\left(-\frac{t^2}{2n}+o(1/n)\right)\to -\frac{t^2}{2},$$ 即标准正态的特征函数。由 Lévy 连续性定理，分布收敛到 $N(0,1)$。
例：二项分布的正态近似。$X_n\sim B(n,p)$，它是 $n$ 个独立 Bernoulli$(p)$ 之和，$\mu=np$，$\sigma^2=np(1-p)$。CLT 给出 $$P\left(a\le \frac{X_n-np}{\sqrt{np(1-p)}}\le b\right)\approx \Phi(b)-\Phi(a).$$ 取 $n=100$，$p=0.5$，求 $P(X\ge 60)$。标准化：$(60-50)/\sqrt{25}=2$，连续性修正后用 $(59.5-50)/5=1.9$，得 $1-\Phi(1.9)\approx 0.0287$。
验证：精确二项计算 $\sum_{k=60}^{100}\binom{100}{k}(1/2)^{100}\approx 0.0284$，与 CLT 近似吻合。这就是「$n$ 次独立试验频率渐近正态」的数学根据。

10. 深度专题：极大似然估计与假设检验的严格框架 从数据到推断

定义（似然函数与 MLE）：样本 $X_1,\dots,X_n\sim f(x;\theta)$，似然 $L(\theta)=\prod_{i=1}^n f(X_i;\theta)$。极大似然估计 $\hat\theta_{\text{MLE}}=\arg\max_\theta L(\theta)$，通常解得分方程 $\partial_\theta\log L=0$。
定理（MLE 的渐近性质）：正则条件下（可交换求导与积分、Fisher 信息 $I(\theta)>0$）， $$\sqrt n(\hat\theta_{\text{MLE}}-\theta)\xrightarrow{d} N\!\left(0,\,I(\theta)^{-1}\right).$$ 且 $\hat\theta$ 渐近有效（达到 Cramér–Rao 下界）。
证明思路：得分函数 $S=\partial_\theta\log L$ 满足 $\mathbb E S=0$、$\operatorname{Var}S=nI(\theta)$，由 CLT $S\to N(0,nI)$。在 $\hat\theta$ 处 Taylor 展开 $0=S(\hat\theta)\approx S(\hat\theta_0)+S'(\hat\theta_0)(\hat\theta-\hat\theta_0)$，结合信息等式 $\mathbb E S'=-nI$，即得渐近正态。
定理（N–P 引理）：在简单原假设 $H_0$ 对简单备择 $H_1$ 的检验中，给定显著性水平 $\alpha$，似然比检验 $\{L_0/L_1<c\}$（$c$ 由 $\alpha$ 确定）是势最大的检验。复合假设下用广义似然比 $\Lambda=\max_{H_0}L/\max_{\text{全部}}L$，在 $H_0$ 下 $-2\log\Lambda\to\chi^2_k$。
例：正态均值的 MLE 与置信区间。$X_i\sim N(\mu,\sigma^2)$，$\sigma^2$ 已知。$\log L=-\frac n2\log(2\pi\sigma^2)-\frac1{2\sigma^2}\sum(X_i-\mu)^2$，得分 $=\frac1{\sigma^2}\sum(X_i-\mu)=0$ 给出 $\hat\mu=\bar X$。信息 $I(\mu)=n/\sigma^2$，故 $\bar X\sim N(\mu,\sigma^2/n)$，$95\%$ 置信区间为 $$\bar X\pm 1.96\,\frac{\sigma}{\sqrt n}.$$ 若 $\sigma^2$ 未知，用 $S^2=\frac1{n-1}\sum(X_i-\bar X)^2$ 代替，并改用 $t$ 分布 $t_{n-1}$ 临界值。
假设检验：检验 $H_0:\mu=\mu_0$。统计量 $Z=(\bar X-\mu_0)/(\sigma/\sqrt n)\sim N(0,1)$。若观测 $|Z|>1.96$，在水平 $\alpha=0.05$ 下拒绝 $H_0$。$p$ 值 $=2(1-\Phi(|Z|))$——它衡量「在 $H_0$ 下观测到当前或更极端数据的概率」，而非「$H_0$ 为真的概率」。

11. 深度：大偏差与 Chernoff 界 把「平均值偏离期望」的概率指数级压下去

定义（矩母函数） 随机变量 $X$ 的矩母函数 $M_X(t)=\mathbb{E}[e^{tX}]$。若 $M_X$ 在 $t>0$ 有限，则对 $a>\mathbb{E}[X]$， $$\Pr(X\ge a)\le\inf_{t>0}\frac{M_X(t)}{e^{ta}}.$$ 这是 Chernoff 界的核心——用最优化参数 $t$ 把界指数级压缩。
定理（Chernoff 界，独立伯努利和） 设 $X=\sum_{i=1}^n X_i$，$X_i\sim\mathrm{Bernoulli}(p_i)$ 独立，$\mu=\mathbb{E}[X]=\sum p_i$。对 $\delta\in(0,1)$， $$\Pr(X\ge(1+\delta)\mu)\le\exp\!\left(-\frac{\delta^2\mu}{3}\right),\quad \Pr(X\le(1-\delta)\mu)\le\exp\!\left(-\frac{\delta^2\mu}{2}\right).$$
思路：对 $e^{tX}$ 用马尔可夫不等式 $\Pr(X\ge a)\le M_X(t)/e^{ta}$，代入伯努利的 $M_X(t)=\prod(p_ie^t+1-p_i)$，用 $1+x\le e^x$ 放缩，最后对 $t$ 求最优。
例：$n=10^6$ 次独立掷硬币，期望正面数 $\mu=5\times10^5$。$\Pr(X\ge5.5\times10^5)\le e^{-5\times10^4\cdot0.01/3}=e^{-500/3}\approx10^{-72}$。
解读：偏离期望 $10\%$ 的概率比宇宙年龄还小——大偏差理论给出指数级小概率的精确控制。

12. 深度：马尔可夫链与平稳分布 随机游走的长期行为由转移矩阵的最大特征值决定

定义（马尔可夫链） 状态空间 $S$ 上的马尔可夫链由转移矩阵 $P=(p_{ij})$ 决定，$p_{ij}=\Pr(X_{n+1}=j\mid X_n=i)$，满足「无记忆性」：未来只依赖当前。平稳分布 $\pi$ 满足 $\pi P=\pi$、$\sum\pi_i=1$。
定理（遍历定理） 不可约、非周期、有限状态马尔可夫链有唯一平稳分布 $\pi$，且对任意初始分布 $\mu_0$，$\mu_0 P^n\to\pi$（指数收敛）。收敛速度由 $P$ 的第二大特征值 $\lambda_2$ 决定：$\|\mu_0 P^n-\pi\|\le C|\lambda_2|^n$。
思路：转移矩阵 $P$ 是随机矩阵（行和为 1），最大特征值为 1，对应特征向量 $\pi$。佩隆–弗罗贝尼乌斯定理保证 $|\lambda_2|<1$（不可约 + 非周期），故高次幂压缩其余分量。
例（PageRank） Google 的网页排名 = 转移矩阵 $P=(1-d)\frac{\mathbf{1}\mathbf{1}^T}{N}+d\cdot\tilde P$ 的平稳分布 $\pi$（$d\approx0.85$），其中 $\tilde P$ 是链接矩阵。阻尼系数 $d$ 保证 $P$ 不可约非周期，平稳分布唯一存在。

13. 深度：贝叶斯推断与先验 把「未知参数」当随机变量，用数据更新认知

定义（贝叶斯框架） 参数 $\theta$ 有先验 $\pi(\theta)$，观测 $X$ 的似然 $p(X\mid\theta)$，则后验 $$\pi(\theta\mid X)=\frac{p(X\mid\theta)\pi(\theta)}{\int p(X\mid\theta')\pi(\theta')\,d\theta'}\propto p(X\mid\theta)\pi(\theta).$$ 分母（边缘似然）是归一化常数，常难以计算。
定理（共轭先验） 若先验 $\pi$ 与后验同属一个参数族，称共轭。例：伯努利似然 $\Rightarrow$ Beta 先验；泊松似然 $\Rightarrow$ Gamma 先验；高斯似然（已知方差）$\Rightarrow$ 高斯先验。
例（伯努利–Beta） $X_i\sim\mathrm{Bernoulli}(\theta)$，先验 $\theta\sim\mathrm{Beta}(\alpha,\beta)$。后验 $\theta\mid X\sim\mathrm{Beta}(\alpha+\sum X_i,\beta+n-\sum X_i)$——只需更新两个参数（成功数 + 票数），无需积分。
例：抛硬币 10 次得 7 正面。先验 Beta(1,1)（均匀），后验 Beta(8,4)，后验均值 $8/12=2/3$。这与 MLE $7/10$ 不同——贝叶斯把先验「拉」向 1/2，小样本时更稳健。

14. 深度：大偏差理论简介 估计「极端事件」的概率

定义（速率函数） 函数 $I:\mathcal X\to[0,\infty]$ 称速率函数，若下水平集 $\{x:I(x)\le a\}$ 闭。好的速率函数还要求所有下水平集紧。
定义（大偏差原理 LDP） 随机变量族 $\{X_\lambda\}_{\lambda>0}$ 在 $\mathcal X$ 上满足速率为 $\lambda$ 的大偏差原理，若存在速率函数 $I$ 使 $$-\inf_{x\in F}I(x)\le\liminf_\lambda\frac1\lambda\ln P(X_\lambda\in F)\le\limsup_\lambda\frac1\lambda\ln P(X_\lambda\in F)\le-\inf_{x\in\bar F}I(x)$$ 对所有闭 $F$ 与开 $G$（下界用开集形式）。直觉：$P(X_\lambda\approx x)\approx e^{-\lambda I(x)}$。
定理（Cramér） iid $X_i$ 服从分布 $\mu$，$\bar X_n=(X_1+\cdots+X_n)/n$，则 $\bar X_n$ 满足速率 $n$ 的 LDP，速率函数 $$I(x)=\sup_{\theta\in\mathbb{R}}\bigl[\theta x-\ln\mathbb{E}e^{\theta X_1}\bigr]$$ （$\ln\mathbb{E}e^{\theta X}$ 为累积生成函数 $\Lambda(\theta)$ 的 Legendre 变换）。
思路：指数 Markov 不等式 $P(\bar X_n\ge a)\le e^{-n(\theta a-\Lambda(\theta))}$ 给上界，取 sup 得 $-I$；下界用指数倾斜测度 $d\mu_\theta=e^{\theta x}d\mu/\mathbb{E}e^{\theta X}$ 在 Cramér 条件下达到。
例：正态 $N(0,1)$ 的 $\bar X_n$ 的大偏差速率。
解：$\Lambda(\theta)=\theta^2/2$，$I(x)=\sup_\theta(\theta x-\theta^2/2)=x^2/2$。故 $P(\bar X_n\ge a)\approx e^{-na^2/2}$——正是 Hoeffding/Chernoff 界的高斯特例。

15. 深度：马尔可夫链与平稳分布 记忆只有一步

定义（马尔可夫链） 取值于可数状态空间 $S$ 的随机序列 $\{X_n\}$ 满足 Markov 性：$P(X_{n+1}=j\mid X_n=i,X_{n-1},\dots)=P(X_{n+1}=j\mid X_n=i)=:p_{ij}$。转移矩阵 $P=(p_{ij})$ 行随机（$p_{ij}\ge0$, $\sum p_{ij}=1$）。
定义（不可约、正常返、非周期） 不可约：任意 $i\to j$（可达）；正常返：$\mathbb{E}_iT_i<\infty$（$T_i=\inf\{n\ge1:X_n=i\}$）；非周期：$\gcd\{n:p_{ii}^{(n)}>0\}=1$。
定理（遍历定理） 不可约正常返非周期链存在唯一平稳分布 $\pi$（$\pi P=\pi$，$\sum\pi=1$），且对任意 $f\in L^1(\pi)$ $$\frac1n\sum_{k=1}^n f(X_k)\to\mathbb{E}_\pi f\quad\text{a.s.}$$
思路：耦合方法构造另一条从平稳 $\pi$ 出发的链 $Y$，证明两链必相遇且相遇后同分布；遍历来自强极限律。
定理（细致平衡与可逆性） 若存在 $\pi$ 满足 $\pi_i p_{ij}=\pi_j p_{ji}$（细致平衡），则 $\pi$ 是平稳分布，链 $\pi$-可逆。MCMC 的核心：用细致平衡构造目标分布。
意义：Metropolis–Hastings 算法从任意提议核 $q_{ij}$ 构造可逆链：$p_{ij}=q_{ij}\min(1,\pi_jq_{ji}/(\pi_iq_{ij}))$，平稳分布恰为想要的 $\pi$。
例：赌徒在 $\{0,1,\dots,N\}$ 上以 $p$ 走 +1、$q=1-p$ 走 -1，0 与 $N$ 吸收。求从 $i$ 破产的概率。
解：设 $h_i$ 为从 $i$ 到 0 的概率，$h_0=1,h_N=0$，$h_i=ph_{i+1}+qh_{i-1}$。解 $h_i=A+B(q/p)^i$。$p\ne q$ 时 $h_i=\frac{(q/p)^N-(q/p)^i}{(q/p)^N-1}$；$p=q=1/2$ 时 $h_i=1-i/N$。赌场优势即 $p<q$ 时 $h_i\to1$。

练习 7：用 Chernoff 界估计 $\Pr(X\ge60)$，$X\sim\mathrm{Bin}(100,0.5)$。
查看答案
答案：$\mu=50$，$\delta=0.2$。$\Pr(X\ge60)\le\exp(-0.04\cdot50/3)=e^{-2/3}\approx0.51$（界较松；精确值约 $0.028$，Chernoff 在大 $n$ 才紧凑）。

查看答案
答案：$\pi P=\pi\Rightarrow\pi_1=0.6\pi_2/0.7$... 解 $\pi=(6/13,7/13)$。验证 $\pi P=(6/13,7/13)$✓。
练习 9：Beta(2,2) 先验 + 5 次成功 3 次失败的后验？
查看答案
答案：后验 Beta(2+5, 2+3)=Beta(7,5)，均值 $7/12\approx0.583$。MLE 为 $5/8=0.625$——先验的「拉」效应。
练习 10：为什么 MLE 在小样本可能给出 $\theta=0$ 或 $1$ 的极端估计？
查看答案
答案：MLE 只看数据：$n$ 次全失败 $\Rightarrow\hat\theta=0$。贝叶斯加先验保证后验有平滑，避免极端——这是贝叶斯方法的核心优势之一。
练习 11：iid $\mathrm{Bernoulli}(p)$，$\bar X_n$ 的 Cramér 速率函数 $I(x)$ 是什么？
查看答案
答案：$\Lambda(\theta)=\ln(pe^\theta+q)$，$I(x)=x\ln(x/p)+(1-x)\ln((1-x)/q)$（KL 散度 $D(x\|p)$）。
练习 12：证明双随机矩阵（行、列都随机）的链以 $\pi_i=1/N$ 为平稳分布。
查看答案
答案：细致平衡不成立，但 $\sum_i p_{ij}=1$ 给 $\pi P=\pi$：$(\pi P)_j=\sum_i\frac1N p_{ij}=\frac1N\cdot1=\pi_j$。故均匀分布平稳。
