数学的「字典」：代数、三角、微积分、线性代数与概率的核心公式，一页收齐。随用随查，为做题与阅读提供速援。

「公式是压缩过的知识——用时展开，闲时品味。」

代数与指数对数

(a±b)² = a² ± 2ab + b²完全平方公式
a² − b² = (a+b)(a−b)平方差
aⁿ·aᵐ = aⁿ⁺ᵐ； (aⁿ)ᵐ = aⁿᵐ； (ab)ⁿ = aⁿbⁿ指数法则
a⁻ⁿ = 1/aⁿ； $a^{1/n}$ = ⁿ√a负指数与根式
log(ab) = log a + log b； log(a/b) = log a − log b； log aᵏ = k log a对数法则
logₐ b = ln b / ln a换底公式
一元二次：x = (−b ± √(b²−4ac)) / 2a求根公式；判别式 Δ = b²−4ac

三角恒等式

sin²θ + cos²θ = 1； 1 + tan²θ = sec²θ毕达哥拉斯恒等式
sin(a±b) = sin a cos b ± cos a sin b和差角
cos(a±b) = cos a cos b ∓ sin a sin b和差角
sin 2θ = 2 sin θ cos θ； cos 2θ = cos²θ − sin²θ倍角
sin a cos b = ½[sin(a+b) + sin(a−b)]积化和差
sin A/a = sin B/b = sin C/c正弦定理
c² = a² + b² − 2ab cos C余弦定理

微积分

d/dx xⁿ = n xⁿ⁻¹； d/dx eˣ = eˣ； d/dx ln x = 1/x基本导数
d/dx sin x = cos x； d/dx cos x = −sin x三角导数
(uv)′ = u′v + uv′乘积法则
(u/v)′ = (u′v − uv′)/v²商法则
d/dx f(g(x)) = f′(g(x))·g′(x)链式法则
$\int x^{n} \,dx$ = xⁿ⁺¹/(n+1) + C (n≠−1)幂积分
$\int 1/x \,dx$ = ln|x| + C； $\int e^{x} \,dx$ = eˣ + C基本积分
$\int u \,dv$ = uv − $\int v \,du$分部积分
∫₀^∞ $e^{-x^{2}}$ dx = √π/2高斯积分
Σₙ₌₁^∞ 1/n² = π²/6巴塞尔问题（欧拉）

线性代数

det[[a,b],[c,d]] = ad − bc2×2 行列式
A⁻¹ = (1/det A)·adj(A)逆矩阵
(AB)ᵀ = BᵀAᵀ； (AB)⁻¹ = B⁻¹A⁻¹转置与逆的运算
Av = λv特征方程 det(A−λI)=0
A = UΣVᵀ奇异值分解
最小二乘：x̂ = (AᵀA)⁻¹Aᵀb法方程

概率与统计

P(A∪B) = P(A) + P(B) − P(A∩B)加法法则
P(A|B) = P(A∩B)/P(B)条件概率
P(A|B) = P(B|A)P(A)/P(B)贝叶斯定理
E[X] = Σ x p(x)； Var(X) = E[X²] − E[X]²期望与方差
C(n,k) = n!/(k!(n−k)!)； P(n,k) = n!/(n−k)!组合与排列
P(X=k) = C(n,k)pᵏ(1−p)ⁿ⁻ᵏ二项分布
f(x) = 1/(σ√(2π))·$e^{-(x-μ)^{2}/2σ^{2}}$正态分布密度

几何与常用数值

S = πr²； C = 2πr； V球 = 4/3 πr³圆与球
V柱 = πr²h； V锥 = ⅓πr²h柱与锥
S梯形 = ½(a+b)h； S三角 = ½ab sin C面积公式
π ≈ 3.14159； e ≈ 2.71828； √2 ≈ 1.41421； φ ≈ 1.61803常用常数
1 rad = 180°/π ≈ 57.2958°弧度换算
n! ≈ √(2πn)(n/e)ⁿ斯特林公式

Gamma 与 Beta 函数

公式说明
$\Gamma(s)=\int_0^\infty x^{s-1}e^{-x}dx$阶乘推广，$\Gamma(n+1)=n!$
$\Gamma(s+1)=s\Gamma(s)$递推关系
$\Gamma(1/2)=\sqrt{\pi}$由 Gauss 积分得出
$B(p,q)=\int_0^1 x^{p-1}(1-x)^{q-1}dx=\frac{\Gamma(p)\Gamma(q)}{\Gamma(p+q)}$Beta 函数

三角恒等式精选

$\sin 3\theta=3\sin\theta-4\sin^3\theta$$\cos 3\theta=4\cos^3\theta-3\cos\theta$
$\sin\alpha+\sin\beta=2\sin\frac{\alpha+\beta}{2}\cos\frac{\alpha-\beta}{2}$和差化积
$\tan\frac{\theta}{2}=\frac{\sin\theta}{1+\cos\theta}=\frac{1-\cos\theta}{\sin\theta}$万能公式基础
$\prod_{k=1}^{n-1}\sin\frac{k\pi}{n}=\frac{n}{2^{n-1}}$正弦乘积恒等式

常见求和公式

$\sum_{k=1}^n k=\frac{n(n+1)}{2}$$\sum_{k=1}^n k^2=\frac{n(n+1)(2n+1)}{6}$
$\sum_{k=1}^n k^3=\left[\frac{n(n+1)}{2}\right]^2$$\sum_{k=0}^n\binom{n}{k}=2^n$
$\sum_{k=1}^\infty\frac{1}{k^2}=\frac{\pi^2}{6}$$\sum_{k=1}^\infty\frac{(-1)^{k+1}}{k}=\ln 2$
